# vault 方法与工具术语表

| 术语 | 解释 |
|---|---|
| 主源 | 直接记录事实或规则的原始文档/源码；派生文件引用它但不替代它。 |
| 派生稿 | 由脚本、Defuddle、Canvas 或人工整理从主源加工出的文件。 |
| 构建产物 | `.o`、`.bin`、`.hex`、build 目录等工具输出，默认是可运行性证据而非正文来源。 |
| 规范源 | `distillation/skills/` 中经过审计的 Skill 唯一维护位置。 |
| 客户端副本 | 安装到 `~/.codex/skills/`、`~/.claude/skills/`、`~/.zcode/skills/` 的同步文件。 |
| 来源边界 | 对结论标注源码事实、文档声称、教学模型、派生计算、实测记录或待验证。 |
| 断点续跑 | 用 `PIPELINE_STATE.md` 记录已完成阶段、待办和验证状态，避免重复蒸馏。 |
