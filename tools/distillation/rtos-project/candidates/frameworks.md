# RTOS 框架候选

- `r01` 周期任务/事件任务/ISR 三分法。
- `r02` 外设→DMA→ISR→同步对象→任务→业务状态链路。
- `r03` 目标→反馈→控制器→执行器→反馈闭环。
- `r04` 产品痛点→架构→关键链路→贡献→边界的项目叙事。
- `r05` Reset_Handler→SystemInit→main→同步对象→任务→调度器→业务的启动闭环。
- `r06` 异常现场→最后有证据节点→配置/栈/锁/IRQ 分类→二分回归的运行时故障决策链。
- `r07` 固件预处理→DMA 搬运→ISR 通知→任务校验→Flash 写入→向量检查→APP 跳转的升级链。
