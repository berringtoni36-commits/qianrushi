# RTOS 反例候选

- 在 ISR 里直接计算速度、排序或打印。
- 在信号量尚未创建前启动会释放信号量的定时器，可能 HardFault。
- 把任务栈大小当成字节而不是 32 位字。
- 把 IAP 设计存在说成默认启用且已实测。
- 把 `configCHECK_FOR_STACK_OVERFLOW=0` 说成项目已自动捕获栈溢出。
- 把 CRC32 说成安全签名，或把单 APP 地址规划说成 A/B 回滚。
- 认为 `configASSERT` 的 `printf` 就等于完整异常现场保存。
- “创建了 `g_dataMutex`”不等于所有 `g_systemState` 访问都受保护：必须逐函数列出读写者、锁覆盖和多字段一致性；`System_GetState()` 返回裸指针时尤其不能把接口当成安全快照。
- 把 `volatile`、单次对齐读写或一个临界区误当成完整的任务间同步；它们不能自动提供多字段快照、读改写原子性或互斥。
