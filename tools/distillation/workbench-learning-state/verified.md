# 学习工作台方法论三重验证

## 通过候选

### WB-01｜正交学习状态 + 来源指针驱动复习

- **类型**：学习状态管理 / 主动回忆框架。
- **V1 跨文档**：`工作台/学习总账.md` 定义 `mastery` 与 `review_flag`；`工作台/八股进度.base` 按状态和主线筛选；`工作台/学习日志.md` 规定只追加真实学习；`工作台/资料地图.md` 规定工作台只做入口、答案仍以原始资料为准。
- **V2 预测力**：当新增一个项目题组、来源链接失效、用户说“我都学过但答不出”或某条目需要跨域复习时，可以先检查字段和来源，再决定回忆动作，而不是按题号或文件修改时间排序。
- **V3 独特性**：把 `mastery`、`review_flag`、`last_studied` 和 `source` 拆成互不替代的合同，并明确“看过不等于掌握、状态不等于答案、来源存在不等于内容正确”。这比普通待办清单更适合可追溯的技术学习。
- **结论**：通过，升格为 `embedded-learning-state-and-active-recall`。

## 降级候选

### WB-R01｜固定每日配额和倒计时

- **结论**：降级为工作台设计边界，不做 Skill。
- **理由**：工作台原文明确不设置倒计时、每日配额或自动任务；该规则不具备跨域方法论必要性，也不能证明适合用户的时间安排。

### WB-R02｜按文件顺序自动复习

- **结论**：降级为实现细节，不做 Skill。
- **理由**：文件排序不包含掌握证据、项目相关性或失败记录；预测力和独特性不足。
