# 学习工作台术语表

| 术语 | 本域定义 | 不能混同 |
|---|---|---|
| `mastery` | 条目的学习掌握声明：`未学`、`学过`、`掌握` | 文件存在、看过答案、完成题数 |
| `review_flag` | 条目是否进入回看队列：`待回看`、`已回看` | 掌握等级、最近学习日期 |
| `last_studied` | 最近一次真实学习行为的日期 | 文件修改时间、审计生成时间 |
| 状态记录 | 工作台中保存字段和来源链接的条目文件 | 原始答案、项目源码 |
| 主源 | 被 `source` 指向的原始文档、项目文档或章节 | 状态条目、派生 TSV |
| 来源指针 | 从工作台记录回到主源的 Obsidian 链接 | 内容复制、结论验证 |
| 学过 | 看过但还不能稳定复述的记录状态 | 掌握、独立完成 |
| 掌握 | 能脱稿解释并应对基本追问的记录状态 | 硬件实测、个人贡献证明 |
| 主动回忆 | 先遮住答案，要求口述、推导、写代码或回答追问 | 再读一遍笔记 |
| 行为证据 | 可观察的独立复述、代码实现、反例解释或项目映射 | “感觉会了” |
| 复习优先级 | 根据状态、待回看、项目相关性和失败证据排序的建议 | 自动生成的事实、强制计划 |
| 派生审计 | 从原始工作台生成的 TSV/Markdown 检查结果 | 对原记录的修改 |
| 记录完整性 | 状态值合法、record_id 唯一、标题存在、来源可解析 | 内容正确性、掌握真实性 |
