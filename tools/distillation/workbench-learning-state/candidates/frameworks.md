# 学习工作台候选框架

## WB-01 正交状态—来源—行为证据闭环

```yaml
title: 正交状态—来源—行为证据闭环
type: learning-state-framework
source_files:
  - 工作台/学习总账.md
  - 工作台/八股进度.base
  - 工作台/学习日志.md
  - 工作台/资料地图.md
  - 工作台/条目记录/150题-001.md
source_symbols:
  - mastery
  - review_flag
  - last_studied
  - source
  - formula.mastery_score
  - formula.needs_review
```

### 方法

将“状态声明”“回看队列”“最近行为”“原始来源”和“实际表现”分开收集；先审计记录，再回到来源，最后用无提示行为决定是否升级状态。

### 触发信号

- “我学过很多但感觉不会。”
- “帮我看一下哪些嵌入式内容该复习。”
- “这个状态能不能代表掌握？”
- “工作台来源有没有失效或重复？”

### 不应升格的相邻内容

- 固定日期计划、倒计时和每日配额。
- 某一道技术题的答案或某个项目的故障根因。
- 只依赖文件顺序、完成数量或模型自评的排序。
