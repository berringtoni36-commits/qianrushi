# Linux 教程术语候选

| 术语 | 本域用法 | 边界 |
|---|---|---|
| fd | 进程持有的整数资源句柄，用于访问文件、管道、终端和 Socket | 不等于底层 open file description |
| ABI/符号 | 编译、链接和运行时解析的接口证据 | 库文件存在不代表符号或 ABI 兼容 |
| 临界区 | 访问共享状态的最小代码范围 | 不等于所有线程函数 |
| framing | 应用层恢复消息边界的规则 | TCP 本身不提供消息边界 |
| 就绪 | fd 当前具备某种 I/O 操作条件 | 不保证一次调用消费完数据 |
| LT/ET | epoll 的水平/边缘触发模式 | ET 要求非阻塞 fd 和持续读到 `EAGAIN` 的消费习惯 |
| 进程池/线程池 | 复用执行实体处理任务 | 要同时定义队列、退出、回收和背压 |
