# Linux 教程候选原则

- `l04`：构建故障先分阶段。依据：GCC 四阶段、库链接/加载和 GDB 章节；规则：先确认是预处理、编译、链接、加载还是运行期。
- `l05`：临界区先缩小再加锁。依据：线程同步章节多次强调先识别共享资源和最小临界区；规则：锁覆盖共享状态的完整读改写，不把无关 I/O 放进锁内。
- `l06`：TCP 应用层必须自定义消息边界。依据：TCP 粘包章节、Socket 读写章节；规则：使用固定长度、长度前缀、分隔符或自描述协议，并循环处理部分读写。
- `l07`：多路复用只报告就绪，不替代消费循环。依据：select/poll/epoll 章节；规则：收到就绪后仍检查返回值、短读、EOF、错误和剩余缓冲。
