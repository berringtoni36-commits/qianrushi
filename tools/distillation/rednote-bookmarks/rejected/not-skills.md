# RedNote 未升级为规范 Skill 的内容

| 候选 | 原因 |
|---|---|
| 某个作者的完整学习路线 | 依赖个人背景、目标岗位和时间窗口；可作案例，不是通用执行方法 |
| “某行业门槛低/某公司一定给面/薪资平均值” | 样本、时间、地域和选择偏差未充分公开，不能当市场事实 |
| 第三方工具功能清单 | 版本和平台依赖强，未在本机独立测试 |
| 热榜 Star、安装量和成本下降数字 | 指标可能时效短、可操纵或口径不完整 |
| 图片里的题单、流程图和宣传语 | OCR/图片内容缺少可追溯正文或代码验证 |
| 非嵌入式生活、健康、Mac 和教育史内容 | 与首轮嵌入式知识目标无关，保留归档但不生成 Skill |
