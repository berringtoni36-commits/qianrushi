# RedNote 外部参考术语表

| 术语 | 本域含义 | 事实等级/边界 |
|---|---|---|
| 外部参考 | 作者不是用户、内容不是项目主源的第三方材料 | 可提供线索，不自动成为事实 |
| 专辑索引 | RedNote 导出按收藏夹生成的链接清单 | 派生关系，不重复计数 |
| 口述输出 | 用自己的话解释概念并接受追问 | 学习方法建议，不等于测量过的效果 |
| 项目映射 | 把知识点连接到真实项目中的文件、函数和故障 | 必须回到用户项目证据 |
| 事实边界 | 区分自己做过、团队做过、文档声称和待验证内容 | 面试表达的安全护栏 |
| 录音复盘 | 记录面试对话并提取问题、弱点和后续行动 | 要考虑录音授权、隐私和工具真实能力 |
| Skill | 可被 Agent 触发的任务说明和执行流程 | 推荐/安装前要审查来源和权限 |
| 安装量/Star | 第三方帖子常用的工具热度指标 | 时效强、可操纵，不能代替安全或质量审计 |
| 自托管 | 服务在自己的设备或服务器上运行 | 仍需检查网络暴露、凭证、遥测和更新机制 |
| JD | Job Description，岗位描述 | 用于确定学习优先级，不能替代官方岗位信息 |
| 八股 | 高频技术问答和面试知识点 | 需要机制、边界、项目映射，不只背定义 |
| 间隔复习 | 按时间间隔重复回忆，如 1/3/7 天 | 可作为个人计划；帖子中的效果数字未经独立验证 |
