## 6. 可迁移模式与不可迁移事实

当前可安全保留的四类模式与 [`verified.md`](tools/distillation/rednote-bookmarks/verified.md) 对齐：

1. 知识框架 → 口述 → 错题/追问 → 项目映射 → 间隔回忆；
2. JD/简历要点 → 个人动作 → 结果证据 → 可追问细节；
3. 面试录音/转写 → 问题与原回答 → 缺口 → 版本复盘；
4. Skill 推荐 → 来源、版本、权限、测试、数字口径和安全复核。

上述是外部参考中跨条目重复出现的工作流，不是作者效果数据，也不是用户已经掌握或执行过的事实。作者的学历、项目、面试场次、offer、薪资、产品体验和帖子图片数字一律回到外部参考层。
