# LeetCode Hot 100 学习体系 — 高密度精华

## 做题不是识别题名

拿到新题先读数据范围、输入结构、允许的操作和目标。问自己：需要快速查找还是顺序维护？窗口是否有单调条件？链表是否需要统一头节点边界？树/图是在求遍历、层数、连通性还是依赖关系？是否存在可复用的子问题和状态？候选模板只是起点，适用条件和不变量才决定能否落地。

## 推导的最小闭环

二分要写清楚区间语义和 `check(mid)` 的单调性；滑窗要写清扩张、收缩和窗口内计数含义；回溯要写选择列表、路径、结束条件和去重；DP 要写状态、初值、转移、遍历顺序、答案位置；贪心要说明局部选择的安全性，说明不了就先构造反例。小规模手算比直接粘代码更能暴露边界错误。

## 学习闭环

每题按“学模板—读题—独立想—写代码—总结”推进。卡住时先给最小提示，不立即看完整答案；看过题解只能记录为“看过”或“提示后 AC”。总结至少留下题型、关键不变量/状态、复杂度、一个易错点和与相邻题的差异。之后遮住答案口述或重写，按薄弱专题安排间隔复习。
