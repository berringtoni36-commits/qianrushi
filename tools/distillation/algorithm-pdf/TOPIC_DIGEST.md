## 分章节学习入口

### I 基础算法（p1–13）

- p1–2 可定位排序、逆序对和归并思路；p2 的归并流程图是独立 image asset，必须回看图形关系。
- p3–4 可定位整数二分、浮点二分和分数运算；`check` 的单调性、区间闭开和精度仍需独立推导。
- p5–8 是高精度加减乘除，含分数/大整数模板；可用作 C++ 骨架，不可绕过符号、进位、除数和溢出测试。
- p8–10 是一/二维前缀和与差分；p11–13 涵盖离散化、位运算、双指针和区间合并。

这些页主要有文本和代码证据，适合进入“候选模板”学习材料；不应把代码块的存在当作已经验证了边界或复杂度。

### II 数据结构（p14–36）

- p14–20：单/双链表、栈、队列、循环队列、单调栈/单调队列。
- p21–23：KMP 的不同下标与 string 版本；应以模式串不变量和边界样例复核。
- p24–29：二叉树遍历、BST、Trie；p28–29 文字/代码可定位。
- p30–33：并查集、堆/堆排序和一般 Hash。
- p34–36：STL 容器、操作和复杂度表；p34 表格是图片，p35–36 文本是有限速查证据。

### III 搜索与图论（p37–64）

- p37–44：图存储、树/图遍历、全排列、树重心、N 皇后、BFS 迷宫/八数码和拓扑排序。
- p45–53：朴素/堆优化 Dijkstra、Bellman-Ford、SPFA、Floyd；p47–49、p53 的复杂度/说明有公式空洞，p48 另有图和迭代表。
- p54–59：最短路归类、Prim、Kruskal 和最小生成树；适用场景与复杂度必须回源或独立验证。
- p60–64：二分图染色、匹配和匈牙利算法；p61 图像证明“图存在”，不证明匹配模板正确。

### IV 数学知识（p65–87）

- p65–68：试除法、质因数分解、埃氏筛、线性筛、约数个数/约数和；p67–68 图片直接承载公式。
- p69–71：幂级数、GCD/LCM、欧拉函数及容斥推导；p69 图片、p70–71 向量数学对象使文本出现大量空洞。
- p72–76：快速幂、扩展欧几里得、CRT/EXCRT、高斯消元；p73–74 公式/证明在图片中，p75 页顶方程组在文本中不可见。
- p77–83：组合数、递推/逆元/Lucas、质因子法和线性筛组合数；p77–78 的杨辉三角与组合记号为图像。
- p84–87：容斥和 Nim/台阶 Nim/集合 Nim/SG；p86–87 结论式有空洞。

数学章节只能作为“主题与回源清单”。公式级内容当前均不能升级为已审计证据。

### V 动态规划（p88–103）

- p88 是闫式 DP 的分类图和背包入口；p89 的 01 背包有两张图/表，图中状态集合和转移式没有进入文本快照。
- p90–92 是 01/完全/多重/分组背包及优化；滚动数组的循环方向需结合状态依赖验证。
- p93–96 是数字三角形、LIS、LIS 二分优化、LCS、编辑距离；p93、p96 有 DP 图像，p94 的部分方程在文本中可见但仍未独立证明。
- p97–99 是区间 DP、整数划分、数位统计 DP；p97、p99 的图像承载状态/分类解释。
- p100–103 是状态压缩 DP、Hamilton 路径、树形 DP、记忆化搜索；p101–103 的“状态转移方程”块在 PyMuPDF 文本中有空洞。

可把这些页转成“状态设计练习入口”，但不能把图中集合、属性、转移关系或复杂度抄成已核实结论。

### VI 贪心（p104–108）

- p104 先出现记忆化搜索代码和贪心定义；p105–107 是区间选点、最大不相交区间和区间分组，p105/107 有图像。
- p108 是 Huffman 树/合并果子，代码文本和示例叙述可定位；最优性证明仍需独立完成。

p105–106 的区间变量/端点文本有空洞，不能从抽取稿推断闭区间约定。

### VII 杂项（p109–119）

- p109 是排序不等式/排队打水；人数、水龙头数、时间变量及计算公式在文本中有空洞，源页可见但本轮未转录。
- p110–111 是 Trie + AC 自动机；p112–113 是树状数组/逆序对，p114–116 是线段树和懒标记。
- p117–119 是树上倍增与 LCA，包括 BFS 建表、查询和应用。

这一章适合做“高级模板导航”，不应把长代码连续出现等同于已编译、已测试或已证明。

### 附录（p120–121）

p120 根据数据范围列出指数、平方/立方、`O(n log n)`、线性等复杂度和候选算法；公式在 PDF 中可见但抽取文本有空洞。p121 是来源/作者说明并带有一条高精度/FFT 复杂度信息，同样不适合作为完整数学说明。

## 使用边界

### 可以进入学习材料

1. 章节—页码—主题索引和回源链接。
2. 文本中可定位的 C++ 模板作为候选骨架。
3. “看到题目结构后先选候选范式，再检查状态、不变量、边界、类型和复杂度”的学习流程；方法论继续使用统一 Skill。
4. assets 作为“需要看图”的复习清单，而不是已经转写的正文。

### 不能写成已完成事实

1. “已完整阅读/理解 121 页 PDF”。
2. 从 PyMuPDF 空白处补写精确公式、上下标、复杂度或变量含义而不回看源页。
3. 把图片箭头、表格单元格、手写推导和版面邻接关系当作文本证据。
4. 仅凭模板抽取稿宣称代码正确、复杂度成立或已通过题目测试。

最低升级条件是：有效 OCR 或人工逐页渲染核对，记录页码/结论/截图或转录，并对代码进行与约束匹配的编译和样例测试。
