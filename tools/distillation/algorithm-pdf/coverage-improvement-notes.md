## 证据分层

### 文本层事实

`E1-TEXT` 只支持从 `算法基础课模板大全-C++版本.pymupdf.md` 定位章节名、主题标题、可见文字和代码候选片段。它不支持以下升级：模板正确、复杂度成立、代码已编译、样例已通过、不变量已证明、列布局/缩进已复原。

### 图片/公式缺口

`E1-IMAGE` 表示矩阵和 asset 清单能证明栅格文件存在，但图片文字、箭头、流程、图表单元格和示意关系没有完整进入快照。`E1-GAP` 进一步表示文本层出现变量/公式/复杂度空洞，或图片/表格承载了不能由文本恢复的内容。缺口登记中的 asset 路径是文件存在证据，不是图片内容的验证。

### 推断

“推断”只用于给学习材料建立回源入口，例如“可定位 Dijkstra 模板”“可作为区间 DP 复习页”。它不把主题邻接、标题或代码连续出现推导成算法正确性，也不把矩阵标签推导成图中具体结论。

### 未验证项

主题卡逐页保留了边界、状态/不变量、复杂度、编译/样例、公式和版面等未验证项。尤其是 p39、p47–p49、p53、p55、p58、p61、p70–p71、p75、p86–p87、p101–p103、p105–p106、p109、p120–p121，不应从抽取稿的空白处补写精确公式。

## 覆盖改进优先级

1. **先补数学和复杂度证据**：回源核对 p67–p87 的约数、欧拉函数、CRT、消元、组合数、容斥和 Nim 公式；同时核对 p47、p49、p53、p55、p58、p61 的复杂度表达式。每条转录需带原页、公式上下标和独立推导/测试状态。
2. **再补 DP 状态图和转移**：重点是 p88–p103 的分类图、01 背包图表、数字三角形、编辑距离、区间 DP、数位 DP、状态压缩和树形 DP。只记录图中确实可见的节点/箭头，并区分图片转录与独立推导。
3. **补图论图示与适用边界**：p38、p40、p48、p61 需要人工核对搜索树、棋盘/二分图、Bellman-Ford 草稿等图示；Dijkstra、Bellman-Ford、SPFA、Prim、Kruskal 的复杂度和权值前提应独立验证。
4. **补低风险但易漏的表格/示意**：p2 归并图、p34 STL 表、p105 区间示意、p107 区间分组图，以及 p120–p121 的复杂度/来源附录。表格应按单元格记录，不能只抄标题。
5. **最后做代码证据升级**：对进入学习材料的模板，按题面约束分别编译、运行边界样例和反例；结果应另行记录为独立测试证据，不能回填成 PDF 原文事实，也不能引用未记录的历史测试结果。

## 后续升级规则

- 公式或图片只有在人工逐页回看原始 PDF 后，才能新增“源页可见”的转录；若要使用 OCR，必须另行取得有效凭证并记录 OCR 版本、页码和人工核对结果。本轮明确不做 OCR。
- 每次升级保留 `page_start/page_end`、缺口类型、证据等级、原始路径和验证动作；未复核的内容继续留在 `E1-IMAGE` 或 `E1-GAP`。
- 代码测试只证明某个独立测试样例/约束下的行为，不自动证明 PDF 中的讲解、公式或全部边界。
- 不把 `evidence-matrix.tsv` 的 `normalized-match` 或“文本页非空”解释为完整视觉阅读；文本层一致性和公式/图片完整性是两条不同证据链。
