# 算法 PDF 完整性与证据覆盖复核

## 结论

原始资料是 `archive/acwing/算法基础课模板大全-C++版本.pdf`，共 121 页。当前可可靠交付的是“逐页文本定位 + C++ 模板线索”这一有限证据层：121/121 页有非空 PDF 文本层，现有 PyMuPDF 快照的 121 个页标记连续，按去空白文本与原 PDF 逐页比较为 121/121 页一致。

这不等于完整理解 PDF。公式、复杂度、行间数学、图片文字、图示关系和版面顺序没有经过 OCR 或逐页人工复核。当前不应引用抽取稿中的空白公式位置、图片推导或精确版面结论，也不应声称已经完整阅读并验证了整本 PDF。主题可进入学习材料，但只能标成“有限文本/模板证据”，并回到原 PDF、题目约束、编译和样例测试完成验证。

```python
import re, pymupdf
doc = pymupdf.open("archive/acwing/算法基础课模板大全-C++版本.pdf")
md = open("distillation/algorithm-pdf/算法基础课模板大全-C++版本.pymupdf.md", encoding="utf-8").read()
assert doc.page_count == 121
markers = list(re.finditer(r"(?m)^## 第 (\d+) 页$", md))
assert [int(m.group(1)) for m in markers] == list(range(1, 122))
for i, marker in enumerate(markers):
    end = markers[i + 1].start() if i + 1 < len(markers) else len(md)
    body = re.sub(r"^## 第 \d+ 页\s*", "", md[marker.start():end], count=1)
    assert "".join(body.split()) == "".join((doc[i].get_text("text") or "").split())
```

## 证据等级与学习准入

矩阵中的等级含义：

- `E1-TEXT`：页码和文本层可定位；适合提取主题名、代码候选和有限文字说明。未证明模板正确。
- `E1-IMAGE`：在 `E1-TEXT` 之外有对应栅格 asset；图像存在但未完整转录、未逐图验证。
- `E1-GAP`：已发现公式/变量/图文关系在文本证据中有空洞，或公式富集内容仅在图像中；必须回源页复核。
- 本轮没有 `E2`（独立 OCR + 人工逐页核对）或“完整 PDF 理解”等级。

可以进入学习材料的内容：章节/题型索引、代码模板候选、数据结构与算法名称、从页码回到原 PDF 的定位信息。进入学习材料时必须保留“有限文本/模板证据”标签，并补上约束、不变量、复杂度、边界和编译测试。

不能冒充完整 PDF 理解的内容：任何精确公式、公式推导、图片中的文字或箭头关系、表格单元格、复杂度结论、页面排版顺序，以及仅依据抽取稿判断模板正确性的结论。算法方法论继续使用 LeetCode 域的统一 Skill；本域不新增规范 Skill。

## 剩余风险

1. OCR 凭证仍不可用；没有独立文字识别结果可以与 PyMuPDF 交叉比对。
2. 22 个 assets 没有被 Markdown 引用，阅读快照时容易漏掉图示和公式。
3. PDF 文本层的阅读顺序可用于定位，但不能证明列布局、代码缩进、公式上下标、表格边界和图片与正文的对应关系。
4. PDF 中的 C++ 模板没有在本轮统一编译、运行或按题目约束测试；整数范围、初始化、复杂度和边界仍需逐模板验证。
5. `source-register.md` 是来源登记，不是本轮页级覆盖矩阵；本报告和 TSV 才记录本轮派生物、页级缺口和统计口径。
