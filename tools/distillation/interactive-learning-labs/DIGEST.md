# 交互学习实验 — 高密度精华

交互资料的价值不在于“把文档做成网页”，而在于把一个抽象机制变成可观察状态：输入是什么、系统经过哪些步骤、输出如何变化、哪些数字是模型算出的、哪些结果来自真实源码或测量。

Linux 物理内存实验是较完整的范例：它既有伙伴系统分配/合并状态，也有 `calculateFragmentation` 的指数计算、三组可复现场景、CLI 选项、fault 列表和 quiz。测试覆盖路线数量、预期指数、CLI flag、故障和知识主题，因此能验证教学模型的结构，而不是只确认页面存在。

RTOS 动画把任务时间线、电机闭环和 IAP 放进同一界面，但它主动区分安全模型与当前源码模型，并提示 `ifopen=0`、CRC 失败和擦除风险。视觉实验把输入帧、LIME、模型耗时和性能优化阶段分开，同时声明教学计算与项目真实处理结果的差异。

因此使用实验时必须经过三问：这个结论来自哪个 source/符号？页面展示的数字是模型、样例还是实测？对应测试是否覆盖了边界？Canvas 只帮助理解关系，不能取代主 Markdown、源码和测量记录。

算法 PDF 当前仅完成本地文本抽取。由于中文 OCR 凭证返回 401，公式和图片不能视为完整读取；它可以作为算法模板的候选证据，但不能用来支撑精确公式结论，直到人工或有效 OCR 复核。
