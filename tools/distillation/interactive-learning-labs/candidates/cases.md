# 交互实验候选案例

- `xc01` 伙伴系统实验：`calculateFragmentation`、三种 scenario 和测试断言共同验证 order、free pages、unusable/extfrag 的教学计算。
- `xc02` 源码故障实验：`faults` 列出时间 key、路径/import、硬编码 order、counts 快照等风险，并给出修复方向。
- `xc03` RTOS 交互：`iapEvaluate` 将安全模型和当前源码路径并列展示，明确 `ifopen` 和 CRC 失败行为边界。
- `xc04` 视觉交互：输入帧、LIME 前后图、模型耗时和 ARM 优化阶段在页面中分层展示，且声明哪些数值是教学计算。
