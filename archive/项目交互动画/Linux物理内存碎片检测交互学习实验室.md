## 你可以操作什么

- 播放、暂停、单步追踪 `Python → BCC → bpf() → 探针 → BPF map → curses`。
- 切换 `get_page_from_freelist` kprobe 状态路线和 `mm_page_alloc_extfrag` tracepoint 事件路线。
- 在 64 页伙伴系统沙盘中申请、释放、拆分、合并页块，并主动制造外部碎片。
- 修改 order 0～10 的空闲块数，严格按照当前 `fraginfo.c` 整数公式手算两个碎片指数。
- 组合真实 CLI 参数，观察不同模式对应的教学终端输出。
- 注入时间节流、路径、import、order 硬编码和事件聚合故障，完成 VCQ 与综合自测。

> [!info] 仿真边界
> 页面是**离线教学仿真**，不会在 Windows 中调用 Linux/BCC/eBPF。示例值是确定性教学数据；代码语义、公式和已知缺口以当前项目源码审计为准。

## 推荐学习顺序

1. **项目全链路**：先区分控制流和数据流。
2. **伙伴系统**：亲手观察“总空闲页足够但连续块不足”。
3. **探针与 Map**：理解两个观察点和内核态/用户态通信。
4. **指数计算**：完成三个标准场景的手算。
5. **命令与终端**：理解参数如何改变加载路线与展示方式。
6. **排障验收**：不看提示解释源码事实边界。
