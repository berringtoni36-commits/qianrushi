## 1. 哈希表

### 核心知识点

哈希表是算法面试中最基础也最常用的数据结构。它的核心价值是**将查找时间从 O(n) 降低到 O(1)**。

**四大应用场景：**

| 场景 | 说明 | 典型题目 |
|------|------|----------|
| 查找 | 快速判断元素是否存在 | 两数之和 |
| 去重 | 判断元素是否重复出现 | 存在重复元素 |
| 计数 | 统计元素出现次数 | 字母异位词分组 |
| 分组 | 按某种规则将元素分组 | 最长连续序列 |

**C++ 中的哈希表工具：**

```cpp
int hashTemplate(const vector<int>& nums, int target) {
    unordered_map<int, int> seen;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        if (seen.count(target - nums[i])) return i;
        seen[nums[i]] = i;
    }
    return -1;
}
```
### 模板代码

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> pos;
        for (int i = 0; i < nums.size(); ++i) {
            int need = target - nums[i];
            if (pos.count(need)) return {pos[need], i};
            pos[nums[i]] = i;
        }
        return {};
    }
};
```

## 2. 双指针

### 核心知识点

双指针的核心思想是**利用两个指针的相对运动来减少搜索空间**，将 O(n^2) 降低到 O(n)。

**两种经典模式：**

1. **对撞指针（左右指针）**：两个指针从两端向中间移动，适用于有序数组
2. **快慢指针**：两个指针同向移动但速度不同，适用于链表和数组中的位置关系

### 模板代码

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int ans = 0, left = 0, right = height.size() - 1;
        while (left < right) {
            ans = max(ans, min(height[left], height[right]) * (right - left));
            if (height[left] < height[right]) ++left;
            else --right;
        }
        return ans;
    }
};
```

## 3. 滑动窗口

### 核心知识点

滑动窗口本质上是**双指针的变体**，用于解决连续子数组/子串问题。

**labuladong 三问判断法：**
1. 什么时候扩大窗口？（右指针移动的条件）
2. 什么时候缩小窗口？（左指针移动的条件）
3. 答案在什么时候更新？（扩大时还是缩小时）

### 模板代码

```cpp
class Solution {
public:
    vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        deque<int> q;
        vector<int> ans;
        for (int i = 0; i < nums.size(); ++i) {
            while (!q.empty() && nums[q.back()] <= nums[i]) q.pop_back();
            q.push_back(i);
            if (q.front() <= i - k) q.pop_front();
            if (i >= k - 1) ans.push_back(nums[q.front()]);
        }
        return ans;
    }
};
```

## 4. 前缀和

### 核心知识点

前缀和的核心思想是**预处理一个前缀和数组，使得任意区间的和可以在 O(1) 时间内求出**。

- `prefix[i] = nums[0] + nums[1] + ... + nums[i-1]`
- 区间和 `sum(nums[i..j]) = prefix[j+1] - prefix[i]`

**进阶用法**：前缀和 + 哈希表，用于解决"和为K的子数组"类问题。

### 模板代码

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> count{{0, 1}};
        int ans = 0, sum = 0;
        for (int x : nums) {
            sum += x;
            ans += count[sum - k];
            ++count[sum];
        }
        return ans;
    }
};
```

## 5. 单调队列 / 单调栈

### 核心知识点

- **单调队列**：队列内元素单调递增或递减，用于解决**滑动窗口中的最值问题**
- **单调栈**：栈内元素单调递增或递减，用于解决**下一个更大/更小元素问题**

### 模板代码

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> ans(n), st;
        for (int i = n - 1; i >= 0; --i) {
            while (!st.empty() && temperatures[st.back()] <= temperatures[i]) st.pop_back();
            if (!st.empty()) ans[i] = st.back() - i;
            st.push_back(i);
        }
        return ans;
    }
};
```

## 6. 链表操作

### 核心知识点

**三大核心技巧：**
1. **虚拟头节点（dummy node）**：避免对头节点的特殊处理
2. **快慢指针**：找中点、找环、找第k个节点
3. **链表反转**：迭代法和递归法

### 模板代码

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* previous = nullptr;
        while (head) {
            ListNode* next = head->next;
            head->next = previous;
            previous = head;
            head = next;
        }
        return previous;
    }
};
```

## 7. 二叉树

### 核心知识点

二叉树的题目几乎都可以用**递归**解决。递归的关键是明确：**函数的定义是什么（做什么）、base case是什么、递归关系是什么。**

**二叉树分治法**：通过左右子树的信息来推导当前树的信息（如最大深度、直径、LCA等）。

**BST（二叉搜索树）特性**：左 < 根 < 右，中序遍历是有序的。

### 模板代码

```cpp
class Solution {
public:
    int maxDepth(TreeNode* root) {
        if (!root) return 0;
        return max(maxDepth(root->left), maxDepth(root->right)) + 1;
    }
};
```

## 8. 图论

### 核心知识点

图论问题主要包含：
- **DFS/BFS遍历**：搜索所有路径、最短路径
- **并查集**：可处理通用连通性，但当前 Hot 100 题单主线不要求
- **拓扑排序**：有向无环图（DAG）的排序
- **字典树（Trie）**：前缀匹配、词频统计

### 模板代码

```cpp
class Solution {
public:
    bool exist(vector<vector<char>>& board, string word) {
        int m = board.size(), n = board[0].size();
        auto dfs = [&](auto&& self, int i, int j, int k) -> bool {
            if (k == word.size()) return true;
            if (i < 0 || i == m || j < 0 || j == n || board[i][j] != word[k]) return false;
            char c = board[i][j];
            board[i][j] = '#';
            bool ok = self(self, i + 1, j, k + 1) || self(self, i - 1, j, k + 1) ||
                      self(self, i, j + 1, k + 1) || self(self, i, j - 1, k + 1);
            board[i][j] = c;
            return ok;
        };
        for (int i = 0; i < m; ++i)
            for (int j = 0; j < n; ++j)
                if (dfs(dfs, i, j, 0)) return true;
        return false;
    }
};
```

## 9. 回溯算法

### 核心知识点

回溯算法的本质是**穷举所有可能**，通过**剪枝**来减少不必要的搜索。

**回溯通用框架：**
1. 做选择（加入路径）
2. 递归
3. 撤销选择（回溯）

**三种基本模式**：子集、排列、组合

### 模板代码

```cpp
class Solution {
public:
    vector<string> letterCombinations(string digits) {
        if (digits.empty()) return {};
        const vector<string> mp{"abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};
        vector<string> ans;
        string path(digits.size(), 0);
        auto dfs = [&](auto&& self, int i) -> void {
            if (i == digits.size()) return ans.push_back(path);
            for (char c : mp[digits[i] - '2']) path[i] = c, self(self, i + 1);
        };
        dfs(dfs, 0);
        return ans;
    }
};
```

## 10. 二分查找

### 核心知识点

二分查找的难点在于**边界条件的处理**。labuladong提出了一套统一模板来解决各种变体。

**核心原则**：
- 搜索区间用 `[left, right]`（闭区间）
- 循环条件用 `left <= right`
- 根据题目要求选择返回 `left`、`right` 或 `mid`

### 模板代码

```cpp
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        return lower_bound(nums.begin(), nums.end(), target) - nums.begin();
    }
};
```

## 11. 栈

### 核心知识点

栈是一种**后进先出（LIFO）**的数据结构，常用于：
- 括号匹配
- 字符串解码
- 表达式求值
- 单调栈问题

### 模板代码

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;
        for (char c : s) {
            if (c == '(') st.push(')');
            else if (c == '[') st.push(']');
            else if (c == '{') st.push('}');
            else if (st.empty() || st.top() != c) return false;
            else st.pop();
        }
        return st.empty();
    }
};
```

## 12. 堆（优先队列）

### 核心知识点

C++ 使用 `priority_queue` 实现堆。默认比较器产生**大根堆**；需要小根堆时显式使用 `greater<T>`，不依赖“取负数”技巧。

### 模板代码

```cpp
// 大根堆：堆顶是最大值
priority_queue<int> maxHeap;

priority_queue<int, vector<int>, greater<int>> minHeap;
```

维护 Top K 时先明确要淘汰哪一端：保留最大的 K 个元素通常用大小为 K 的小根堆；保留最小的 K 个元素通常用大根堆。

## 13. 贪心算法

### 核心知识点

贪心算法的核心是**每一步都选择局部最优，期望达到全局最优**。

**贪心的关键判断**：贪心选择是否会导致错过全局最优解？如果能证明局部最优一定包含在全局最优中，就可以使用贪心。

### 模板代码

```cpp
class Solution {
public:
    vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> ans;
        for (auto& p : intervals) {
            if (ans.empty() || ans.back()[1] < p[0]) ans.push_back(p);
            else ans.back()[1] = max(ans.back()[1], p[1]);
        }
        return ans;
    }
};
```

## 14. 动态规划

### 核心知识点

**DP解题四步法：**
1. **Base case**：最基本的情况是什么？
2. **状态**：问题中变化的量是什么？
3. **选择**：在每个状态下可以做什么选择？
4. **dp定义**：dp数组/函数的含义是什么？

**代码随想录DP五部曲：**
1. 确定dp数组及下标的含义
2. 确定递推公式
3. dp数组如何初始化
4. 确定遍历顺序
5. 举例推导dp数组（手动验证）

### 模板代码

```cpp
class Solution {
public:
    int climbStairs(int n) {
        int a = 1, b = 1;
        while (n--) tie(a, b) = pair{b, a + b};
        return a;
    }
};
```

```cpp
class Solution {
public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        sort(nums.begin(), nums.end());
        vector<vector<int>> ans;
        for (int i = 0; i + 2 < nums.size(); ++i) {
            if (i && nums[i] == nums[i - 1]) continue;
            if (nums[i] + nums[i + 1] + nums[i + 2] > 0) break;
            if (nums[i] + nums[nums.size() - 2] + nums.back() < 0) continue;

                    for (--right; left < right && nums[right] == nums[right + 1]; --right);
                }
            }
        }
        return ans;

};
```

```cpp
        if (i >= 0) {
```

### 1. [1] 两数之和 (Easy)

**LeetCode 题目：** [打开题目](https://leetcode.cn/problems/two-sum/)
**AcWing 题目：** [打开题目](https://www.acwing.com/activity/content/problem/content/2326/)
**AcWing yxc 代码：** [打开代码](https://www.acwing.com/activity/content/code/content/339799/)
**题目详解：** [[1-两数之和|打开完整题解]]

**题意简述**：给定一个数组和一个目标值，找出数组中和为目标值的两个数的下标。

**思路分析**：使用哈希表记录已遍历过的元素及其下标。对于每个元素 `num`，检查 `target - num` 是否在哈希表中。

**C++代码**：

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> heap;
        for (int i = 0; i < nums.size(); i ++ ) {
            int r = target - nums[i];
            if (heap.count(r)) return {heap[r], i};
            heap[nums[i]] = i;
        }

        return {};
    }
};
```
**复杂度分析**：时间 O(n)，空间 O(n)

**要点/易错点**：不能先把所有元素放入哈希表再查找，因为可能出现同一个元素被使用两次的情况。

### 2. [49] 字母异位词分组 (Medium)

**LeetCode 题目：** [打开题目](https://leetcode.cn/problems/group-anagrams/)
**AcWing 题目：** [打开题目](https://www.acwing.com/activity/content/problem/content/2386/)
**AcWing yxc 代码：** [打开代码](https://www.acwing.com/activity/content/code/content/356303/)
**题目详解：** [[49-字母异位词分组|打开完整题解]]

**题意简述**：将字母异位词（相同字母不同排列）组合在一起。

**思路分析**：异位词排序后得到相同的字符串，以排序结果作为哈希表的key进行分组。

**C++代码**：

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> hash;
        for (auto& str: strs) {
            string nstr = str;
            sort(nstr.begin(), nstr.end());
            hash[nstr].push_back(str);
        }

        vector<vector<string>> res;
        for (auto& item : hash) res.push_back(item.second);

        return res;
    }
};
```
**复杂度分析**：时间 O(n * k * log(k))，其中k是字符串最大长度；空间 O(n * k)

**要点/易错点**：排序后的 `string` 可直接作为 `unordered_map` 的 key；若用 26 位计数数组，需要编码为 `string` 或为 `array<int, 26>` 自定义哈希。

### 3. [128] 最长连续序列 (Medium)

**LeetCode 题目：** [打开题目](https://leetcode.cn/problems/longest-consecutive-sequence/)
**AcWing 题目：** [打开题目](https://www.acwing.com/activity/content/problem/content/2490/)
**AcWing yxc 代码：** [打开代码](https://www.acwing.com/activity/content/code/content/394597/)
**题目详解：** [[128-最长连续序列|打开完整题解]]

**题意简述**：给定未排序的整数数组，找出最长连续元素序列的长度。要求 O(n)。

**思路分析**：将数组放入集合中。对于每个数，如果 `num-1` 不在集合中，说明它是一个连续序列的起点，从该起点开始计数。

**C++代码**：

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> S;
        for (auto x: nums) S.insert(x);

        int res = 0;
        for (auto x: nums) {
            if (S.count(x) && !S.count(x - 1)) {
                int y = x;
                S.erase(x);
                while (S.count(y + 1)) {
                    y ++ ;
                    S.erase(y);
                }
                res = max(res, y - x + 1);
            }
        }

        return res;
    }
};
```
**复杂度分析**：时间 O(n)，虽然有嵌套循环，但每个元素最多被访问两次；空间 O(n)

**要点/易错点**：必须判断 `num-1` 是否在集合中，否则时间复杂度会退化为 O(n^2)。

### 4. [283] 移动零 (Easy)

**LeetCode 题目：** [打开题目](https://leetcode.cn/problems/move-zeroes/)
**AcWing 题目：** [打开题目](https://www.acwing.com/activity/content/problem/content/2663/)
**AcWing yxc 代码：** [打开代码](https://www.acwing.com/activity/content/code/content/456460/)
**题目详解：** [[283-移动零|打开完整题解]]

**题意简述**：将数组中的0移动到末尾，保持非零元素的相对顺序。要求原地操作。

**思路分析**：使用快慢指针。快指针遍历数组，遇到非零元素就与慢指针位置交换。

**C++代码**：


**题目详解：** [[15-三数之和|打开完整题解]]

**题意简述**：找出数组中所有和为0的三元组，不重复。

**思路分析**：排序 + 固定一个数 + 双指针。对于每个 `nums[i]`，在 `nums[i+1..n-1]` 中用对撞指针找两个数使三数之和为0。

```cpp

public:
    vector<vector<int>> threeSum(vector<int>& nums) {
        vector<vector<int>> res;
        sort(nums.begin(), nums.end());
        for (int i = 0; i < nums.size(); i ++ ) {
            if (i && nums[i] == nums[i - 1]) continue;
            for (int j = i + 1, k = nums.size() - 1; j < k; j ++ ) {

                if (nums[i] + nums[j] + nums[k] == 0) {

            }
```

**LeetCode 题目：** [打开题目](https://leetcode.cn/problems/trapping-rain-water/)

**题目详解：** [[42-接雨水|打开完整题解]]

**题意简述**：给定n个非负整数表示柱子高度，计算能接多少雨水。

**思路分析**：
- **方法一（双指针）**：维护左右两侧的最大高度。对于当前位置，能接的水量 = min(左侧最大高度, 右侧最大高度) - 当前高度。
- **方法二（单调栈）**：维护一个单调递减栈，当遇到更高的柱子时，计算凹槽中的水量。

**C++代码**：

```cpp
class Solution {
public:
    int trap(vector<int>& height) {
        stack<int> stk;
        int res = 0;
        for (int i = 0; i < height.size(); i ++ ) {
            int last = 0;
            while (stk.size() && height[stk.top()] <= height[i]) {
                res += (height[stk.top()] - last) * (i - stk.top() - 1);
                last = height[stk.top()];
                stk.pop();
            }

            if (stk.size()) res += (i - stk.top() - 1) * (height[i] - last);
            stk.push(i);
        }

        return res;
    }
};
```
**复杂度分析**：两种方法都是时间 O(n)；方法一空间 O(1)，方法二空间 O(n)

**要点/易错点**：接雨水是经典Hard题，关键理解是"每个位置能接多少水取决于它两侧最高柱子中较矮的那个"。单调栈方法中，注意计算的是横向的水量。

```cpp
public:
    vector<int> spiralOrder(vector<vector<int>>& matrix) {
        vector<int> res;
        int n = matrix.size();
        if (!n) return res;
        int m = matrix[0].size();

        int dx[] = {0, 1, 0, -1}, dy[] = {1, 0, -1, 0};
        vector<vector<bool>> st(n, vector<bool>(m));

        for (int i = 0, x = 0, y = 0, d = 0; i < n * m; i ++ ) {
            res.push_back(matrix[x][y]);
            st[x][y] = true;

            int a = x + dx[d], b = y + dy[d];
            if (a < 0 || a >= n || b < 0 || b >= m || st[a][b]) {
                d = (d + 1) % 4;
                a = x + dx[d], b = y + dy[d];
            }

            x = a, y = b;
        }

        return res;
    }
};
```

**AcWing 题目：** [打开题目](https://www.acwing.com/activity/content/problem/content/2516/)
**AcWing yxc 代码：** [打开代码](https://www.acwing.com/activity/content/code/content/405014/)
**题目详解：** [[146-LRU缓存|打开完整题解]]

**题意简述**：设计一个LRU缓存，支持O(1)的get和put操作。

**思路分析**：哈希表 + 双向链表。

**C++代码**：

```cpp
class LRUCache {
public:
    struct Node {
        int key, val;
        Node *left, *right;
        Node(int _key, int _val): key(_key), val(_val), left(NULL), right(NULL) {}
    }*L, *R;
    unordered_map<int, Node*> hash;
    int n;

    void remove(Node* p) {
        p->right->left = p->left;
        p->left->right = p->right;
    }

    void insert(Node* p) {
        p->right = L->right;
        p->left = L;
        L->right->left = p;
        L->right = p;
    }

    LRUCache(int capacity) {
        n = capacity;
        L = new Node(-1, -1), R = new Node(-1, -1);
        L->right = R, R->left = L;
    }

    int get(int key) {
        if (hash.count(key) == 0) return -1;
        auto p = hash[key];
        remove(p);
        insert(p);
        return p->val;
    }

    void put(int key, int value) {
        if (hash.count(key)) {
            auto p = hash[key];
            p->val = value;
            remove(p);
            insert(p);
        } else {
            if (hash.size() == n) {
                auto p = R->left;
                remove(p);
                hash.erase(p->key);
                delete p;
            }
            auto p = new Node(key, value);
            hash[key] = p;
            insert(p);
        }
    }
};

/**
 * Your LRUCache object will be instantiated and called as such:
 * LRUCache* obj = new LRUCache(capacity);
 * int param_1 = obj->get(key);
 * obj->put(key,value);
 */
```
**复杂度分析**：get和put均为时间 O(1)，空间 O(capacity)

**要点/易错点**：节点必须存储key，因为在淘汰时需要从哈希表中删除对应的key。

```cpp
                }
            }
```

```cpp
public:
    struct Node {
        bool is_end;
        Node *son[26];
        Node() {
            is_end = false;
            for (int i = 0; i < 26; i ++ )
                son[i] = NULL;
        }
    }*root;

    /** Initialize your data structure here. */
    Trie() {
        root = new Node();
    }

    /** Inserts a word into the trie. */
    void insert(string word) {
        auto p = root;
        for (auto c: word) {
            int u = c - 'a';
            if (!p->son[u]) p->son[u] = new Node();
            p = p->son[u];
        }
        p->is_end = true;
    }

    /** Returns if the word is in the trie. */
    bool search(string word) {
        auto p = root;
        for (auto c: word) {
            int u = c - 'a';
            if (!p->son[u]) return false;
            p = p->son[u];
        }
        return p->is_end;
    }

    /** Returns if there is any word in the trie that starts with the given prefix. */
    bool startsWith(string word) {
        auto p = root;
        for (auto c: word) {
            int u = c - 'a';
            if (!p->son[u]) return false;
            p = p->son[u];
        }
        return true;
    }
};
```

```cpp
    int n;
    vector<bool> col, dg, udg;
    vector<vector<string>> ans;
    vector<string> path;

    vector<vector<string>> solveNQueens(int _n) {
        n = _n;

        dg = udg = vector<bool>(n * 2);

            return;

                path[u][i] = 'Q';
```

**题目详解：** [[4-寻找两个正序数组的中位数|打开完整题解]]

**思路分析**：将问题转化为在两个有序数组中找第k小的元素。

```cpp
class Solution {
public:
    double findMedianSortedArrays(vector<int>& nums1, vector<int>& nums2) {
        int tot = nums1.size() + nums2.size();
        if (tot % 2 == 0) {
            int left = find(nums1, 0, nums2, 0, tot / 2);
            int right = find(nums1, 0, nums2, 0, tot / 2 + 1);
            return (left + right) / 2.0;
        } else {
            return find(nums1, 0, nums2, 0, tot / 2 + 1);
        }
    }

    int find(vector<int>& nums1, int i, vector<int>& nums2, int j, int k) {
        if (nums1.size() - i > nums2.size() - j) return find(nums2, j, nums1, i, k);
        if (k == 1) {
            if (nums1.size() == i) return nums2[j];
            else return min(nums1[i], nums2[j]);
        }
        if (nums1.size() == i) return nums2[j + k - 1];
        int si = min((int)nums1.size(), i + k / 2), sj = j + k - k / 2;
        if (nums1[si - 1] > nums2[sj - 1])
            return find(nums1, i, nums2, sj, k - (sj - j));
        else
            return find(nums1, si, nums2, j, k - (si - i));
    }
};
```

**AcWing yxc 代码：** [打开代码](https://www.acwing.com/activity/content/code/content/375419/)
**题目详解：** [[84-柱状图中最大的矩形|打开完整题解]]

**思路分析**：单调栈。对每根柱子找左右第一个比它矮的。

```cpp
class Solution {
public:
    int largestRectangleArea(vector<int>& h) {
        int n = h.size();
        vector<int> left(n), right(n);
        stack<int> stk;

        for (int i = 0; i < n; i ++ ) {
            while (stk.size() && h[stk.top()] >= h[i]) stk.pop();
            if (stk.empty()) left[i] = -1;
            else left[i] = stk.top();
            stk.push(i);
        }

        stk = stack<int>();
        for (int i = n - 1; i >= 0; i -- ) {
            while (stk.size() && h[stk.top()] >= h[i]) stk.pop();
            if (stk.empty()) right[i] = n;
            else right[i] = stk.top();
            stk.push(i);
        }

        int res = 0;
        for (int i = 0; i < n; i ++ ) {
            res = max(res, h[i] * (right[i] - left[i] - 1));
        }

        return res;
    }
};
```
**复杂度分析**：时间 O(n)，空间 O(n)

**要点/易错点**：使用哨兵 `-1` 简化代码。理解宽度计算：弹出后栈顶是左边第一个比它矮的。

### 补充：[763] 划分字母区间

**LeetCode 题目：** [打开题目](https://leetcode.cn/problems/partition-labels/)
**AcWing 题目：** [打开题目](https://www.acwing.com/activity/content/problem/content/3673/)
**AcWing yxc 代码：** [打开代码](https://www.acwing.com/activity/content/code/content/1039493/)
**题目详解：** [[763-划分字母区间|打开完整题解]]

**题意简述**：
给你一个字符串 `s`，你要把这个字符串分割成尽可能多的片段，使得**同一个字母最多出现在一个片段中**。

返回一个表示每个字符串片段的长度的列表。

**示例 1：**
```
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij"。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。
```

**示例 2：**
```
输入：s = "eccbbbbdec"
输出：[10]
```

---

**思路分析**：
**思路讲解：** 分两步走：

**第一步（预处理）：** 遍历一次字符串，用哈希表（或长度为 26 的数组）记录每个字符最后出现的下标。

**第二步（贪心切割）：** 再次遍历字符串，维护：
- `start`：当前片段的起始位置
- `end`：当前片段的右边界（动态扩展）
- 每遇到一个字符 `c`，就将 `end` 更新为 `max(end, last[c])`
- 当 `i == end` 时，说明当前片段结束，记录长度 `end - start + 1`，然后 `start = i + 1` 开始下一个片段

**为什么贪心是对的？** 每个字符的"最后出现位置"是不可妥协的硬约束，在满足约束的前提下，尽早切分（`i == end` 时立即切）能得到最多片段，局部最优（尽早切）就是全局最优（片段最多）。

> **教学解法（原有模板保留）：** 用于理解核心写法；最终提交以 YXC 总文档为准。

**时间复杂度：** O(n)（两次遍历） | **空间复杂度：** O(26) = O(1)

**C++代码**：

```cpp
class Solution {
public:
    vector<int> partitionLabels(string S) {
        unordered_map<int, int> last;
        for (int i = 0; i < S.size(); i ++ ) last[S[i]] = i;
        vector<int> res;
        int start = 0, end = 0;
        for (int i = 0; i < S.size(); i ++ ) {
            end = max(end, last[S[i]]);
            if (i == end) {
                res.push_back(end - start + 1);
                start = end = i + 1;
            }
        }
        return res;
    }
};
```

```cpp
public:
    vector<vector<string>> partition(string s) {
        int n = s.size();
        vector<vector<char>> palindrome(n, vector<char>(n, true));
        for (int i = n - 1; i >= 0; --i)
            for (int j = i + 1; j < n; ++j)
                palindrome[i][j] = s[i] == s[j] && palindrome[i + 1][j - 1];

            for (int j = i; j < n; ++j) if (palindrome[i][j]) {
                path.push_back(s.substr(i, j - i + 1));
                self(self, j + 1);
                path.pop_back();
            }
        };
        dfs(dfs, 0);
```

**题意简述**：实现支持 `.` 和 `*` 的正则表达式匹配。`.` 匹配任意字符，`*` 匹配零个或多个前面的元素。

```cpp
class Solution {
public:
    bool isMatch(string s, string p) {
        int m = s.size(), n = p.size();
        vector<vector<char>> dp(m + 1, vector<char>(n + 1));
        dp[0][0] = true;
        for (int j = 2; j <= n; ++j) if (p[j - 1] == '*') dp[0][j] = dp[0][j - 2];
        for (int i = 1; i <= m; ++i)

                    dp[i][j] = dp[i][j - 2];
                    if (p[j - 2] == '.' || p[j - 2] == s[i - 1]) dp[i][j] |= dp[i - 1][j];
```

### 100. [312] 戳气球 (Hard)

**题意简述**：戳破气球i获得 `nums[i-1] * nums[i] * nums[i+1]` 的金币，求最大金币数。

**思路分析**：区间DP。逆向思考：不是戳破气球，而是最后戳破哪个气球。`dp[i][j]` 表示戳破 `(i, j)` 开区间内所有气球的最大金币数。

```cpp
public:
    int maxCoins(vector<int>& nums) {
        vector<int> a{1};
        a.insert(a.end(), nums.begin(), nums.end());
        a.push_back(1);
        int n = a.size();
        vector<vector<int>> dp(n, vector<int>(n));
        for (int length = 2; length < n; ++length)
            for (int left = 0, right = length; right < n; ++left, ++right)
                for (int last = left + 1; last < right; ++last)
                    dp[left][right] = max(dp[left][right], dp[left][last] + dp[last][right] + a[left] * a[last] * a[right]);
        return dp[0][n - 1];
    }
};
```

**LeetCode 题目：** [打开题目](https://leetcode.cn/problems/find-the-duplicate-number/)

**题意简述**：
给定一个包含 `n + 1` 个整数的数组 `nums`，其数字都在 `[1, n]` 范围内（包括 1 和 n）。可知至少存在一个重复的整数。假设只有一个重复的整数，返回这个重复的数。

你设计的解决方案必须**不修改**数组 `nums` 且只用常量级 `O(1)` 的额外空间。

**示例 1：**
```
输入：nums = [1,3,4,2,2]
输出：2
```

**示例 2：**
```
输入：nums = [3,1,3,4,2]
输出：3
```

**示例 3：**
```
输入：nums = [3,3,3,3,3]
输出：3
```

---

**思路分析**：
**思路讲解：** 将数组看作一个隐式链表——`nums[i]` 表示节点 i 的 next 指针指向 `nums[i]`。因为有重复数字，不同的下标可能指向同一个值，所以这个链表必有环，且环的入口就是重复数。

**第一阶段：找相遇点。** 快指针每次走两步（`fast = nums[nums[fast]]`），慢指针每次走一步（`slow = nums[slow]`），它们在环中相遇。

**第二阶段：找环入口。** 将慢指针重置到起点，快慢指针都每次走一步，再次相遇的位置即为环入口（重复数）。

**为什么环的入口就是重复数？** 因为至少有两个不同的位置 `i` 和 `j` 满足 `nums[i] == nums[j] == 重复数`，这意味着从 `i` 和 `j` 出发都能到达同一个值——在链表中，这就是环的入口。

> **教学解法（原有模板保留）：** 用于理解核心写法；最终提交以 YXC 总文档为准。

**时间复杂度：** O(n) | **空间复杂度：** O(1)

**C++代码**：

```cpp
class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int a = 0, b = 0;
        while (true) {
            a = nums[a];
            b = nums[nums[b]];
            if (a == b) {
                a = 0;
                while (a != b) {
                    a = nums[a];
                    b = nums[b];
                }
                return a;
            }
        }

        return -1;
    }
};
```

```cpp
            else if (r == x) c ++ ;
```

```cpp
            if (nums[i] == 0) swap(nums[i ++ ], nums[j ++ ]);
```

### 105. [166] 分数到小数 (Medium)

**思路分析**：模拟长除法，用哈希表记录余数出现的位置来检测循环节。

```cpp
class Solution {
    unordered_map<int, int> index;
    vector<int>* preorder;
    TreeNode* build(int preLeft, int inLeft, int size) {
        if (!size) return nullptr;
        int value = (*preorder)[preLeft];
        int leftSize = index[value] - inLeft;
        auto root = new TreeNode(value);
        root->left = build(preLeft + 1, inLeft, leftSize);
        root->right = build(preLeft + leftSize + 1, inLeft + leftSize + 1, size - leftSize - 1);
        return root;
    }
public:
    TreeNode* buildTree(vector<int>& preorder, vector<int>& inorder) {
        this->preorder = &preorder;
        for (int i = 0; i < inorder.size(); ++i) index[inorder[i]] = i;
        return build(0, 0, inorder.size());
    }
};
```
**复杂度分析**：时间 O(d)，d为小数位数；空间 O(d)

### 106. [149] 直线上最多的点数 (Hard)

**题意简述**：给定平面上的点，找出同一直线上最多的点数。

**思路分析**：对每个点，计算它与其他所有点的斜率，用哈希表统计同一斜率的点数。

```cpp
int hashTemplate(const vector<int>& nums, int target) {
    unordered_map<int, int> seen;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        if (seen.count(target - nums[i])) return i;
        seen[nums[i]] = i;
    }
    return -1;
}
```
**复杂度分析**：时间 O(n^2)，空间 O(n)

```cpp
class Solution {
```

```cpp
        while (head) {

            head->next = prev;
            prev = head;

    }
```

## 二、各专题之间的联系和递进关系

### 基础层（必须先掌握）

1. **哈希表** -- 一切数据结构的基石，几乎每道题都会用到
2. **双指针** -- 数组/链表操作的必备技能
3. **栈** -- 理解LIFO思想，为单调栈打基础

### 进阶层

4. **滑动窗口** -- 双指针的变体，解决子串/子数组问题
5. **前缀和** -- 与哈希表结合，解决区间和问题
6. **链表** -- 需要熟练掌握指针操作
7. **二叉树** -- 递归思维的集中训练场
8. **二分查找** -- 边界条件处理是核心难点

### 高级层

9. **回溯** -- 系统性穷举，需要理解剪枝
10. **动态规划** -- 最难也最重要，需要大量练习
11. **图论** -- DFS/BFS的高级应用
12. **单调队列/栈** -- 解决最值问题的利器

### 专题间的桥梁关系

- **双指针 --> 滑动窗口**：滑动窗口本质上是双指针的特殊形式
- **哈希表 --> 前缀和**：前缀和+哈希表是经典组合
- **栈 --> 单调栈 --> 单调队列**：逐步递进
- **二叉树(递归) --> 回溯 --> DFS图论**：递归思维是核心
- **DP(一维) --> DP(二维) --> 区间DP**：状态从一维扩展到多维
- **贪心 --> DP**：很多贪心题目也可以用DP解决

### 常见错误提醒

- **去重遗漏**：三数之和、全排列去重等场景
