## 题目描述

给你单链表的头节点 `head`，请你反转链表，并返回反转后的链表。

**示例：**
- 输入：head = [1,2,3,4,5]
- 输出：[5,4,3,2,1]

---

## 🧩 题目详细分析

- **数据范围：** 节点数在 [0, 5000] 范围内，节点值在 [-5000, 5000] 范围内
- **输入特征：** 单向链表，每个节点只有一个 next 指针指向后继
- **核心约束：** 反转后原链表的尾节点变成新链表的头节点，原头节点变成新链表的尾节点（next 指向 nullptr）
- **隐藏条件：** 链表的单向性意味着一旦断开 next 连接就会丢失后续节点，操作前必须先保存
- **边界条件：** 空链表（head 为 nullptr）、只有一个节点的链表

---

## 👶 小白版直白理解

就像一串珠子用线串起来，现在要把这串珠子倒过来。你不能直接整串翻转，只能一颗一颗地拆开重新串。

具体怎么做呢？先准备好一根空线（pre = nullptr），然后从第一颗珠子开始，每取下一颗珠子，就把它串到新线的最前面。这样取完所有珠子后，新线上珠子的顺序就是反的了。

---

## 💡 解题思路

### 思路一：迭代法（三指针翻转，推荐）

**为什么这样想：** YXC 代码的核心操作是 `b->next = a`，但这样会覆盖 `b` 原本的后继。所以必须先用 `c = b->next` 保存剩余链，再依次执行改边、`a = b`、`b = c`。

**关键洞察：** `a` 始终指向「已反转部分的头节点」，`b` 指向「当前待反转节点」，`c` 临时保存 `b` 的原后继。循环结束后还要执行 `head->next = NULL`，把原头节点变成新尾节点。

> **教学解法（原有模板保留）：** 用于理解本题核心写法；最终提交请使用页面顶部的精确 YXC 入口。

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(NULL) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (!head) return NULL;
        auto a = head, b = a->next;
        while (b) {
            auto c = b->next;
            b->next = a;
            a = b;
            b = c;
        }
        head->next = NULL;
        return a;
    }
};
```
### 思路二：递归法

**思路讲解：** 递归地反转 `head->next` 及之后的链表，得到的新链表头节点为 `new_head`。此时 `head->next` 指向反转后的最后一个节点，只需让 `head->next->next = head` 将当前节点接到尾部，再让 `head->next = nullptr` 断掉原连接。递归的终止条件是空或只有一个节点。

**关键洞察：** 递归法的核心是「相信子问题能正确反转」，我们只需要处理当前节点和已反转部分尾部的连接。

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if(!head || !head->next) return head; ListNode* p=reverseList(head->next); head->next->next=head; head->next=nullptr; return p;
    }
};
```
### 思路三：头插法（借助虚拟头节点）

**思路讲解：** 创建一个虚拟头节点 dummy，然后遍历原链表，每遍历一个节点就用头插法插入到 dummy 后面。最后返回 dummy.next。本质上和迭代法一样，但用 dummy 统一了插入逻辑。

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        while (head) {
            auto next = head->next;
            head->next = prev;
            prev = head;
            head = next;
        }
        return prev;
    }
};
```

## ⚠️ 易错点

- **断链问题：** 执行 `b->next = a` 之前，一定先保存 `c = b->next`，否则剩余链丢失
- **递归返回值：** 递归的核心是返回 new_head（即原链表尾节点），不是 head
- **尾节点处理：** 反转后原头节点变成尾节点，要记得将 `head->next` 设为 nullptr，否则形成环
- **空链表和单节点：** 这两种情况直接返回 head，反转前和反转后结果一样
- **YXC 初始化：** 空链表先返回；非空时 `a=head`、`b=a->next`。原头节点的 `next` 暂时保留，循环结束后统一置为 `NULL`
