## 一、本质理解

- **栈（Stack）：** 受限的线性表，LIFO（后进先出），底层是数组或链表
- **堆（Heap / 优先队列）：** 用数组实现的完全二叉树，自动维护最值
- **单调栈（Monotonic Stack）：** 栈中元素保持单调递增或递减，用于找"下一个更大/更小元素"

### 栈的通用模板

```cpp
bool validBrackets(const string& s) {
    unordered_map<char, char> match{{')', '('}, {']', '['}, {'}', '{'}};
    stack<char> st;
    for (char c : s) {
        if (!match.count(c)) st.push(c);
        else {
            if (st.empty() || st.top() != match[c]) return false;
            st.pop();
        }
    }
    return st.empty();
}
```
### 单调栈模板（找下一个更大元素）

```cpp
class Solution {
public:
    vector<int> dailyTemperatures(vector<int>& temperatures) {
        int n = temperatures.size();
        vector<int> ans(n), st;
        for (int i = n - 1; i >= 0; i --) {
            while (!st.empty() && temperatures[st.back()] <= temperatures[i]) st.pop_back();
            if (!st.empty()) ans[i] = st.back() - i;
            st.push_back(i);
        }
        return ans;
    }
};
```
**单调栈变体：**
- 找下一个更大元素 → 单调递减栈（栈底到栈顶递减）
- 找下一个更小元素 → 单调递增栈（栈底到栈顶递增）
- 找上一个更大元素 → 反向遍历

### 柱状图中最大矩形（单调栈经典应用）

```cpp
int largestRectangleArea(vector<int> heights) {
    heights.insert(heights.begin(), 0);
    heights.push_back(0);
    stack<int> st;
    int answer = 0;
    for (int i = 0; i < static_cast<int>(heights.size()); ++i) {
        while (!st.empty() && heights[st.top()] > heights[i]) {
            int height = heights[st.top()]; st.pop();
            answer = max(answer, height * (i - st.top() - 1));
        }
        st.push(i);
    }
    return answer;
}
```

## 三、堆（优先队列）

### C++ 堆操作（priority_queue 模块）

```cpp
void heapTemplate(const vector<int>& values) {
    priority_queue<pair<int, int>> heap;
    for (int i = 0; i < static_cast<int>(values.size()); i ++)
        heap.push({values[i], i});
}
```
### 经典应用：数据流的中位数（双堆）

```cpp
class MedianFinder {
    priority_queue<int> lower;
    priority_queue<int, vector<int>, greater<int>> upper;

public:
    void addNum(int value) {
        if (lower.empty() || value <= lower.top()) lower.push(value);
        else upper.push(value);
        if (lower.size() > upper.size() + 1) {
            upper.push(lower.top()); lower.pop();
        } else if (upper.size() > lower.size()) {
            lower.push(upper.top()); upper.pop();
        }
    }

    double findMedian() const {
        if (lower.size() == upper.size())
            return (static_cast<long long>(lower.top()) + upper.top()) / 2.0;
        return lower.top();
    }
};
```

## 五、易错点与技巧

1. **C++ 没有大根堆**：想要大根堆就存负值，取的时候再转回来
2. **单调栈存索引而非值**：因为很多时候需要索引来计算距离或宽度
3. **柱状图加哨兵**：在 heights 两端加 0，避免栈空判断和最后清空栈
4. **Top K 技巧**：求第 K 大用最小堆（堆大小 = K），求前 K 大也一样
5. **堆的时间复杂度**：push 和 pop 都是 O(log k)，建堆 O(n)

## 六、复杂度总结

| 结构 | 操作 | 时间复杂度 | 空间复杂度 |
|------|------|-----------|-----------|
| 栈 | 入栈/出栈 | O(1) | O(n) |
| 单调栈 | 一次遍历 | O(n) | O(n) |
| 堆 | push/pop | O(log n) | O(n) |
| 堆 | 建堆 | O(n) | O(n) |

## YXC 模板精编

### 单调栈：寻找右侧第一个更大元素

```cpp
vector<int> nextGreaterDistance(const vector<int>& nums) {
    vector<int> answer(nums.size());
    stack<int> indices;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        while (!indices.empty() && nums[indices.top()] < nums[i]) {
            answer[indices.top()] = i - indices.top();
            indices.pop();
        }
        indices.push(i);
    }
    return answer;
}
```

### 单调队列：固定窗口最大值

```cpp
vector<int> maxSlidingWindowTemplate(const vector<int>& nums, int k) {
    deque<int> q;
    vector<int> answer;
    for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
        while (!q.empty() && q.front() <= i - k) q.pop_front();
        while (!q.empty() && nums[q.back()] <= nums[i]) q.pop_back();
        q.push_back(i);
        if (i + 1 >= k) answer.push_back(nums[q.front()]);
    }
    return answer;
}
```

### 堆

```cpp
priority_queue<int> maxHeap;  // 默认大根堆
priority_queue<int, vector<int>, greater<int>> minHeap;
```

- **适用题：** 20、84、155、215、239、295、347、739。
- **复杂度：** 单调栈/队列均为均摊 `O(n)`；堆的插入和弹出为 `O(log n)`。
- **易错点：** 队列存下标才能判断过期；C++ `priority_queue<int>` 默认是大根堆。
