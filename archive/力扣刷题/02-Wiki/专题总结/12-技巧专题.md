## 一、位运算

### 核心性质

| 运算 | 规则 | 用途 |
|------|------|------|
| a ^ 0 = a | 任何数与 0 异或不变 | 保留原值 |
| a ^ a = 0 | 任何数与自身异或为 0 | 消除成对出现的数 |
| a ^ b ^ a = b | 异或满足交换律和结合律 | 找唯一出现一次的数 |
| a & (-a) | 取最低位的 1 | 树状数组、位运算技巧 |

### ⭐ 只出现一次的数字

```cpp
class Solution {
public:
    int singleNumber(vector<int>& nums) {
        return accumulate(nums.begin(), nums.end(), 0, bit_xor<int>());
    }
};
```

## 二、摩尔投票法

### 核心思想

不同元素互相抵消，最后剩下的就是众数（出现次数 > n/2 的候选）。

```cpp
int majorityElementTemplate(const vector<int>& nums) {
    int candidate = 0, votes = 0;
    for (int x : nums) {
        if (votes == 0) candidate = x;
        votes += x == candidate ? 1 : -1;
    }
    return candidate;
}
```

## 三、荷兰国旗问题（三指针）

### 核心思想

用三个指针（p0, p1, p2）将数组分为三个区域：0 区、1 区（处理区）、2 区。

```cpp
void sortColorsTemplate(vector<int>& nums) {
    int left = 0, current = 0, right = static_cast<int>(nums.size()) - 1;
    while (current <= right) {
        if (nums[current] == 0) swap(nums[left++], nums[current++]);
        else if (nums[current] == 2) swap(nums[current], nums[right--]);
        else ++current;
    }
}
```

## 四、下一个排列

### 核心步骤

```
1. 从右往左找第一个「升序对」(i, i+1)，即 nums[i] < nums[i+1]
2. 从右往左找第一个比 nums[i] 大的元素 nums[j]
3. 交换 nums[i] 和 nums[j]
4. 翻转 i+1 到末尾（使其变为升序/最小排列）
```

```cpp
void nextPermutationTemplate(vector<int>& nums) {
    int i = static_cast<int>(nums.size()) - 2;
    while (i >= 0 && nums[i] >= nums[i + 1]) --i;
    if (i >= 0) {
        int j = static_cast<int>(nums.size()) - 1;
        while (nums[j] <= nums[i]) --j;
        swap(nums[i], nums[j]);
    }
    reverse(nums.begin() + i + 1, nums.end());
}
```

## 五、Floyd 判圈法（双指针找重复数）

把数组看成链表：`nums[i]` 的值表示下一个节点的索引。  
有重复数 = 有环，找环入口 = 找重复数。

```cpp
int findDuplicateTemplate(const vector<int>& nums) {
    int slow = nums[0], fast = nums[nums[0]];
    while (slow != fast) slow = nums[slow], fast = nums[nums[fast]];
    slow = 0;
    while (slow != fast) slow = nums[slow], fast = nums[fast];
    return slow;
}
```

## YXC 模板精编

### 位运算

```cpp
bool kthBit(int value, int k) {
    return (static_cast<unsigned int>(value) >> k) & 1U;
}

int lowbit(int value) {
    return value & -value;
}

int singleNumberTemplate(const vector<int>& nums) {
    int answer = 0;
    for (int x : nums) answer ^= x;
    return answer;
}
```

- **适用题：** [[136-只出现一次的数字|136. 只出现一次的数字]]；位级二分思想也可帮助理解 [[287-寻找重复数|287. 寻找重复数]]。
- **复杂度：** 异或扫描时间 `O(n)`，额外空间 `O(1)`。
- **易错点：** 位移有符号负数前先转无符号；`lowbit(0)` 为 0，循环中要避免对 0 无进展。
