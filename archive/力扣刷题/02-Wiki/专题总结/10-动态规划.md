## 一、本质理解

labuladong 的精辟定义：

> **动态规划 = 穷举 + 记忆化**

### DP 的两个核心问题

| 问题 | 说明 | 解决方式 |
|------|------|----------|
| 如何穷举 | 不重不漏地遍历所有可能的解 | 状态转移方程 |
| 如何聪明地穷举 | 避免重复计算 | 备忘录（memo）/ DP 表 |

### DP 适合的问题特征

| 特征 | 说明 | 反例 |
|------|------|------|
| 最优子结构 | 子问题的最优解能推导出原问题的最优解 | 走迷宫（需要全局信息） |
| 重叠子问题 | 子问题被重复计算 | 斐波那契数列 |
| 无后效性 | 子问题的解一旦确定，不受后续决策影响 | 股票问题（需要状态维度） |

## 二、方法论

### labuladong DP 四步法

```
第一步：确定 base case（最简单情况下的答案）
第二步：确定状态（原问题和子问题中变化的量）
第三步：确定选择（导致状态变化的操作）
第四步：明确 dp 数组/函数的含义
```

### 代码随想录 DP 五部曲

```
第一步：确定 dp 数组以及下标的含义
第二步：确定递推公式（状态转移方程）
第三步：dp 数组如何初始化（base case）
第四步：确定遍历顺序
第五步：举例推导 dp 数组（手动验证）
```

### 两种实现方式

```cpp
int topDown(int state, vector<int>& memo) {
    if (state <= 1) return state;
    if (memo[state] != -1) return memo[state];
    return memo[state] = topDown(state - 1, memo) + topDown(state - 2, memo);
}

int bottomUp(int n) {
    vector<int> dp(max(2, n + 1));
    dp[1] = 1;
    for (int i = 2; i <= n; ++i) dp[i] = dp[i - 1] + dp[i - 2];
    return dp[n];
}
```

## 三、DP 常见模型

### 模型 1：线性 DP（一维）

```cpp
class Solution {
public:
    int climbStairs(int n) {
        int a = 1, b = 1;
        while (n --) tie(a, b) = pair{b, a + b};
        return a;
    }
};
```
### 模型 2：打家劫舍（选或不选）

```cpp
class Solution {
public:
    int rob(vector<int>& nums) {
        int prev2 = 0, prev1 = 0;
        for (int x : nums) {
            int current = max(prev1, prev2 + x);
            prev2 = prev1;
            prev1 = current;
        }
        return prev1;
    }
};
```
### 模型 3：背包 DP

```cpp
bool canPartitionTemplate(const vector<int>& nums) {
    int sum = accumulate(nums.begin(), nums.end(), 0);
    if (sum & 1) return false;
    int target = sum / 2;
    vector<char> dp(target + 1);
    dp[0] = true;
    for (int x : nums)
        for (int capacity = target; capacity >= x; --capacity)
            dp[capacity] = dp[capacity] || dp[capacity - x];
    return dp[target];
}
```
**零钱兑换（完全背包）：**

```cpp
int coinChangeTemplate(const vector<int>& coins, int amount) {
    vector<int> dp(amount + 1, amount + 1);
    dp[0] = 0;
    for (int coin : coins)
        for (int value = coin; value <= amount; ++value)
            dp[value] = min(dp[value], dp[value - coin] + 1);
    return dp[amount] > amount ? -1 : dp[amount];
}
```
### 模型 4：子序列 DP

**LIS 的二分辅助（返回第一个 `>= target` 的位置）：**

```cpp
int lowerBoundIndex(const vector<int>& nums, int target) {
    int left = 0, right = static_cast<int>(nums.size());
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] < target) left = mid + 1;
        else right = mid;
    }
    return left;
}
```
```cpp
int lengthOfLISTemplate(const vector<int>& nums) {
    vector<int> tails;
    for (int x : nums) {
        auto it = lower_bound(tails.begin(), tails.end(), x);
        if (it == tails.end()) tails.push_back(x);
        else *it = x;
    }
    return tails.size();
}
```
### 模型 5：编辑距离

```cpp
class Solution {
public:
    int minDistance(string a, string b) {
        int n = b.size();
        vector<int> dp(n + 1);
        iota(dp.begin(), dp.end(), 0);
        for (int i = 1; i <= a.size(); i ++) {
            int diagonal = dp[0];
            dp[0] = i;
            for (int j = 1; j <= n; j ++) {
                int up = dp[j];
                if (a[i - 1] == b[j - 1]) dp[j] = diagonal;
                else dp[j] = min({dp[j], dp[j - 1], diagonal}) + 1;
                diagonal = up;
            }
        }
        return dp[n];
    }
};
```
### 模型 6：路径 DP

```cpp
int minPathSumTemplate(const vector<vector<int>>& grid) {
    int rows = grid.size(), cols = grid[0].size();
    vector<int> dp(cols, INT_MAX);
    dp[0] = 0;
    for (int i = 0; i < rows; ++i)
        for (int j = 0; j < cols; ++j)
            dp[j] = min(dp[j], j ? dp[j - 1] : INT_MAX) + grid[i][j];
    return dp.back();
}
```

## 四、遍历顺序速查

| 背包类型 | 外层循环 | 内层循环 | 遍历方向 |
|----------|----------|----------|----------|
| 0-1 背包 | 物品 | 容量 | 容量倒序 |
| 完全背包 | 物品 | 容量 | 容量正序 |
| 组合数（求方案数） | 容量 | 物品 | 视情况 |
| 排列数（求方案数） | 容量 | 物品 | 容量在外+正序 |

## 六、易错点与技巧

1. **先想清楚 dp 含义再写代码**：dp[i] 到底代表什么？是"以 i 结尾"还是"前 i 个"？
2. **初始化仔细**：base case 想清楚，特别是边界条件
3. **遍历顺序**：0-1 背包倒序，完全背包正序，这是经典考点
4. **空间优化**：很多二维 DP 可以优化为一维，但新手先写二维再优化
5. **手动验证**：写完后用小数据手动推导一遍，确认 dp 值正确

## 七、复杂度总结

| DP 模型 | 时间复杂度 | 空间复杂度 | 可优化空间 |
|---------|-----------|-----------|-----------|
| 线性 DP | O(n) | O(n) → O(1) |
| 子序列 DP | O(n²) | O(n) |
| 背包 DP | O(n × cap) | O(cap) |
| 二维 DP | O(m × n) | O(m × n) → O(n) |
| 区间 DP | O(n²) | O(n²) |
