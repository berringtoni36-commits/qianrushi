## 一、本质理解

labuladong 将贪心定位为"穷举 + 剪枝"的一种特殊形式——在每一步都选择当前看起来最优的方案。

### 贪心 vs DP

| 对比 | 贪心算法 | 动态规划 |
|------|----------|----------|
| 决策方式 | 只考虑局部最优 | 考虑所有可能 |
| 适用范围 | 满足贪心选择性质 | 更通用 |
| 效率 | O(n) 或 O(n log n) | 通常 O(n²) |
| 难度 | 难在证明"贪心是对的" | 难在找状态转移 |

### 代码随想录的"反例验证法"

> **"如果想不到反例，那贪心策略就是对的。"**

## 二、核心模板

### 买卖股票的最佳时机（维护最低价）

```cpp
class Solution {
public:
    int maxProfit(vector<int>& prices) {
        int ans = 0, minPrice = prices[0];
        for (int price : prices) {
            ans = max(ans, price - minPrice);
            minPrice = min(minPrice, price);
        }
        return ans;
    }
};
```
### 跳跃游戏（维护最远可达位置）

```cpp
class Solution {
public:
    bool canJump(vector<int>& nums) {
        int farthest = 0;
        for (int i = 0; i < nums.size(); i ++) {
            if (i > farthest) return false;
            farthest = max(farthest, i + nums[i]);
        }
        return true;
    }
};
```
### 划分字母区间（区间贪心）

```cpp
class Solution {
public:
    vector<int> partitionLabels(string s) {
        array<int, 26> last{};
        for (int i = 0; i < s.size(); i ++) last[s[i] - 'a'] = i;
        vector<int> ans;
        for (int i = 0, start = 0, end = 0; i < s.size(); i ++) {
            end = max(end, last[s[i] - 'a']);
            if (i == end) ans.push_back(end - start + 1), start = i + 1;
        }
        return ans;
    }
};
```

## 四、易错点与技巧

1. **贪心的核心是策略**：先大胆假设贪心策略，再努力找反例
2. **排序预处理**：很多贪心题需要先排序（区间类、分配类）
3. **局部最优 ≠ 全局最优**：贪心不是万能的，遇到反例就换 DP
4. **边界维护**：跳跃游戏的 max_reach 和区间问题的 end 都是典型技巧
