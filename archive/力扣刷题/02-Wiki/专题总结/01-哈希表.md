## 一、本质理解

哈希表（Hash Table）的本质是 **数组 + 哈希函数**。  
labuladong 将其归类为"数组"的延伸——用哈希函数将 key 映射到数组索引，实现 O(1) 的查找、插入、删除。

**核心思想：空间换时间。** 用额外的内存空间换取更快的查找速度。

---

## 二、四大应用场景

| 场景 | 说明 | 典型题目 |
|------|------|----------|
| **查找** | 快速判断元素是否存在 | 1. 两数之和 |
| **去重** | 判断元素是否重复出现 | 128. 最长连续序列 |
| **计数** | 统计元素出现次数 | 49. 字母异位词分组 |
| **分组** | 按规则将元素归类 | 49. 字母异位词分组、560. 和为 K 的子数组 |

**本质套路：** 什么时候用哈希表？  
→ 当你需要**快速查找某个元素是否出现过**，或者需要**统计某个值的出现次数**时，考虑用哈希表。

## 三、C++ STL 哈希容器对比

| 工具 | 适用场景 | 示例 |
|------|----------|------|
| `unordered_map` | 无序键值映射、平均 O(1) 查找 | `unordered_map<int, int> seen;` |
| `map` | 键有序、O(log n) 查找 | `map<int, int> ordered;` |
| `unordered_set` | 只关心存在性、平均 O(1) 查找 | `unordered_set<int> seen;` |
| `set` | 元素有序、O(log n) 查找 | `set<int> ordered;` |

## 四、核心模板

### 模板 1：两数之和（查找互补元素）

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> pos;
        for (int i = 0; i < nums.size(); i ++) {
            int need = target - nums[i];
            if (pos.count(need)) return {pos[need], i};
            pos[nums[i]] = i;
        }
        return {};
    }
};
```
**变形：** 如果只需要平均 O(1) 判断存在性，用 `unordered_set`；需要元素有序时再用 `set`。

### 模板 2：字母异位词分组（排序分组）

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> groups;
        for (auto& s : strs) {
            string key = s;
            sort(key.begin(), key.end());
            groups[key].push_back(s);
        }
        vector<vector<string>> ans;
        for (auto& [_, group] : groups) ans.push_back(std::move(group));
        return ans;
    }
};
```
**优化：** 用 26 位字符计数编码代替排序（当字符串很长时更快）：

```cpp
class Solution {
public:
    vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> groups;
        for (auto& s : strs) {
            array<int, 26> count{};
            for (char c : s) ++count[c - 'a'];
            string key;
            for (int frequency : count) key += '#' + to_string(frequency);
            groups[key].push_back(s);
        }
        vector<vector<string>> ans;
        for (auto& [_, group] : groups) ans.push_back(std::move(group));
        return ans;
    }
};
```
### 模板 3：最长连续序列（用集合去重 + 找起点）

```cpp
class Solution {
public:
    int longestConsecutive(vector<int>& nums) {
        unordered_set<int> values(nums.begin(), nums.end());
        int ans = 0;
        for (int x : values) if (!values.count(x - 1)) {
            int y = x;
            while (values.count(y)) y ++;
            ans = max(ans, y - x);
        }
        return ans;
    }
};
```
**核心优化：** 只从 `num-1 不在集合中` 的元素开始查找，确保每个元素只被遍历一次，O(n) 时间。

### 模板 4：前缀和 + 哈希表（子数组和问题）

```cpp
class Solution {
public:
    int subarraySum(vector<int>& nums, int k) {
        unordered_map<int, int> count{{0, 1}};
        int ans = 0, sum = 0;
        for (int x : nums) {
            sum += x;
            ans += count[sum - k];
            ++count[sum];
        }
        return ans;
    }
};
```

## 六、易错点与技巧

1. **Key 的选择**：`unordered_map` 的键必须可哈希；字符频次数组可编码为 `string`，或为 `array<int, 26>` 自定义哈希
2. **`unordered_map` vs `map`**：不要求键有序时优先前者；需要有序遍历或稳定最坏复杂度时使用后者
3. **Top K 频次**：先用 `unordered_map` 计数，再用大小为 K 的小根堆或桶排序筛选
4. **集合去重**：`unordered_set(nums.begin(), nums.end())` 比用 unordered_map 去重更简洁高效
5. **边遍历边查**：两数之和类问题中，"边遍历边查"比"先全存再查"更高效

## 七、复杂度总结

| 操作 | 平均时间复杂度 | 最坏时间复杂度 | 空间复杂度 |
|------|---------------|---------------|-----------|
| 查找 | O(1) | O(n) | O(n) |
| 插入 | O(1) | O(n) | O(n) |
| 删除 | O(1) | O(n) | O(n) |

> **注意：** C++ 的 unordered_map 实现经过高度优化，实际性能非常好。最坏情况 O(n) 只在哈希冲突严重时发生。

## YXC 模板精编

### 前缀和 + 哈希表

**适用题：** [[560-和为K的子数组|560. 和为 K 的子数组]]。YXC 原型中的 `S[i]` 表示前 `i` 个元素之和；力扣版边扫描边统计前缀和出现次数，不必保存整个数组。

```cpp
int subarraySum(vector<int>& nums, int k) {
    unordered_map<long long, int> count{{0, 1}};
    long long prefix = 0;
    int answer = 0;
    for (int x : nums) {
        prefix += x;
        if (count.count(prefix - k)) answer += count[prefix - k];
        ++count[prefix];
    }
    return answer;
}
```

- **不变量：** 扫描到当前位置时，`count[s]` 是此前前缀和 `s` 的出现次数。
- **复杂度：** 平均时间 `O(n)`，空间 `O(n)`。
- **易错点：** 必须先放入 `count[0] = 1`；前缀和建议使用 `long long`。
