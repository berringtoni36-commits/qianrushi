最近高强度使用AI编程进行辅助，体验很好，这里直接把在VS Code中使用Codex插件的教程给大家捋一遍，对照看图就行[哇R]
	
一、前置条件
1️⃣ 需要是 Plus / Pro / Business / Edu / Enterprise等会员
2️⃣ 需要🪄，且须开启   服务模式 + TUN 模式
	
二、安装 Codex 插件
3️⃣ 两种方式都可以：
·在 GPT 网页里点击 Codex 跳转
·或者直接在 VS Code 插件市场搜索 Codex
4️⃣ 安装完成后，点击左侧 Codex 插件
→ 使用 GPT 账号登录
→ 跳转网页授权
→ 授权成功后回到 VS Code
看到左侧出现 Codex 面板，说明插件已经正常工作了[哇R]
	
三、不同系统的使用区别
Mac 和 Windows用户：现在都可以直接使用 GPT 桌面版 App，选择
·「代理模式」
·连接 VS Code
·直接读 / 改 / 跑本地项目代码
Windows 用户：根据官方说明，目前属于实验支持
更推荐：
·WSL2（Ubuntu） + VS Code + Codex 插件，稳定性和体验明显更好[派对R]
	
四、Codex 的常用使用方式
① 基于编辑器上下文提问（最常用）
·当前打开的文件
·选中的代码
·@file 引用其他文件
② 三种工作模式（控制自动化程度）
·Chat：最安全，只给建议，不改代码（目前已经没有该功能了）
·Agent（默认）：沙箱模式，可以改代码，但需要你确认
·Agent（Full Access）：高度自动化，适合重构/批量修改（慎用）
③ 推理强度选择
·low：简单问题，速度快
·medium：默认，一般就足够了
·high：复杂系统 / 跨文件分析
④ 云端任务（高级）  长时间任务可以交给云端跑，完成后直接看 diff，一键应用到本地
	
五、补充说明
·基础代码智能补全一般使用微软官方的copilot就足够了
·Codex 更多是用作需要理解整个项目结构的 coding agent
·适合：重构、排错、读老代码、科研项目、工程项目
·各系统体验中，目前 Mac 体验是最好的[赞R]
