# 秋招提前批在即，嵌入式简历分享

作者：糯叽唧大王


![[小红书（RedNote）/。。。。。。。/媒体（Media）/6a38853d00000000220190f2/image-1.jpg]]

秋招提前批马上到了，在六月七月已经有陆陆续续企业开始提前批，为了拿到更好的offer，现在必须马上投递了！八股、项目、实习要狠狠浓缩在简历中[草莓R]
	
下面分享一下我自己的简历写法，同款模版在笔记文件，可以下载[星R][星R]下面分享一些关键点：
	
[一R]关键词加粗（重要）
1. 语言精炼，避免冗长描述。
2. 重点部分用粗体：技能、工具、项目核心技术、解决方案、成果。
例子：STM32 + FreeRTOS 实现多任务调度，这些技术栈要加粗一下
Linux 驱动开发，支持 I2C/SPI 设备
	
[二R]项目部分，不要照搬网上烂大街的项目。
修改或创新后再加入，体现个人贡献。描述重点：
1. 角色：你在项目中具体负责什么
2. 技术点：使用的 MCU/RTOS/Linux/协议等
3. 问题解决：遇到的问题与你的方法
4. 成果：优化效果、性能提升、数据指标
[三R]页数控制
1. 尽量1页，除非经历非常丰富。
2. 精炼内容，只保留与目标岗位高度相关的技能和项目。像个人评价什么的都不要写，找私企技术岗也不用写学生会经历！
	
[四R]简历定制化
1. 针对不同岗位突出不同内容：
- MCU岗位：MCU + RTOS + 硬件接口实操经验
- Linux岗位：Linux应用与驱动开发、网络协议、系统调优经验
2. 每份简历都要让HR/面试官快速看到你的关键能力匹配岗位需求。
	
[五R]视觉优化小技巧（可以直接用我的模板）
1. 分块清晰：技能 / 项目 / 教育 / 实习
2. 用符号或emoji区分小标题：提高可读性
3. 字体加粗、缩进、列表：快速抓住重点信息
4. 突出数字成果：如“提升系统性能 30%”比“优化系统性能”更吸引人
	
[六R]简单来说就是
1. 突出技能 + 项目贡献
2. 精炼语言 + 可视化布局
3. 根据岗位定制内容
