每天用 Codex 最多的操作是什么？
我投查看额度一票。Codex的查看额度操作要多步，重置次数到期时间也不显示，
所以做了个桌面小工具：Quota Float
它是一个轻量桌面悬浮窗，可以直接查看 Codex 额度状态。
能看到：
当前 Codex plan
5 小时额度
每周额度
下次重置时间
额度是否正在消耗
剩余额度健康 / 警告 / 危急状态
平时它会缩成一个小圆点，不占地方；鼠标移上去再展开。
适合经常开着 Codex 写代码、做项目、跑任务的人。
重点是：它只读取本机 Codex Desktop 登录状态，不保存 token、不看聊天记录、没有遥测追踪。
目前支持 Windows / macOS，下载 GitHub Releases 里的压缩包即可使用。
项目名：Quota Float 账户change-42-yhmm那个
地址详见评论区
