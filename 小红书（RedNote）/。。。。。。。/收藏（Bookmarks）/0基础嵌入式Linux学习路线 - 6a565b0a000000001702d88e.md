很多朋友在评论区问技术栈，正好最近在做复习。分享一下，以及有什么疑问在评论区问哟。
我的整体学习顺序是：
C/C++ 与 408基础 → Linux 系统编程 → 开发工具 → Linux应用编程-ARM 与驱动基础 → Linux驱动子系统 → U-Boot → 音视频与嵌入式 AI → mipi驱动
整个过程从研一入学9月持续到第二年暑假 8 月，想要在学历不够情况下第一份就是大厂实习，在每年的9-12月份这个时间点要好好把握，有了第一份实习后面都好说。
最开始还是补 C/C++，因为本科太混了。基本上属于0基础。主要在 B 站找课看。然后把操作系统、计网、计组和数据结构与算法过了一遍，看的就是 B 站上的 408 课程。
这部分刚开始学的时候感觉和嵌入式关系不大，后面接触进程线程、虚拟内存、中断、DMA 和驱动以后，才发现很多东西都绕不开，所以要好好学。
基础过完后开始学 Linux 系统编程，包括 Socket、select、poll、epoll，以及进程、线程这些内容。后面又学了一些 Qt，课程基本都是网上找的。
Makefile、CMake、GDB 和 Shell 也是边写代码边学。个人感觉这些工具不用专门花很长时间看课，先把基本用法弄懂，项目里遇到问题再去查，记得更牢。
再往后开始正式接触 ARM 和 Linux 驱动。
这一阶段主要跟着正点原子学，先后看了中断、字符设备、Platform 总线和设备树，然后继续学了 GPIO、Pinctrl、Input、I²C、SPI、IIO、Regmap 这些驱动子系统。
驱动这块前期确实比较劝退。各种结构体、回调函数和内核接口混在一起，很容易看着看着就不知道代码走到哪里了。我当时的办法就是先照着教程跑起来，再对着内核源码一点点追调用关系。
后面又继续学了 U-Boot，包括框架、编译和简单移植，用的也是正点原子的资料。
除了驱动，还学过一些音视频，包括RTMP 推流。嵌入式 AI 方面，例如RK3588 跑过 YOLO 识别，跟的是讯为电子那套教程。主要是npu mpp 那些外设使用
最后花时间比较多的是 V4L2。买了一个 MIPI 摄像头，下载对应的内核源码，跟着韦东山的视频学 V4L2 驱动框架。前面学的设备树、I²C、Media、内存和中断，到这里基本都能串起来。
整个学习过程中，主要是找了一些开源项目，然后围绕自己学过的内容进行魔改。加功能 替换模块
