一名嵌入式爱好者和ai资源调度博士的日常软件清单：
ChatGPT Codex
VS Code
小绿鲸英文文献阅读器
Zotero
拓竹 3D 打印 / Bambu Studio
嘉立创 EDA
Keil uVision5

我自己一直都挺喜欢嵌入式，软硬件都想自己折腾一点。以前很多代码都得自己写，现在有 AI 之后确实方便很多，效率高了不少。甚至我现在连配图很多时候都是直接丢给 GPT 处理，真的省事。

不过嵌入式和纯软件还是不太一样，很多时候都得自己动手，像焊接、接线、检查、排错这些都少不了。有时候还会用到逻辑分析仪和万用表，虽然麻烦，但把东西一点点做出来的时候真的很有成就感。

博士阶段的正式学习还没开始，所以我现在更多还是在看论文，顺便慢慢把这些软件用顺手。
平时我用的软件还挺杂的，基本都围绕着写代码、看论文、整理文献、做硬件这几件事。这里就随手分享一下我自己最常用的一些软件。

ChatGPT Codex 是我现在用得比较多的一个，平时主要拿来帮我写代码、改代码，也会顺手处理一些文字工作。对我来说它更像是日常工作的一个助手，我负责把方向想清楚，它负责帮我把东西推进去。

VS Code 也是我离不开的一个软件，主要就是用来看代码和写代码。现在我主要接触 STM32、ESP32 和 Qt 工程，STM32 我一般是在 VS Code 里看代码，真正的编译和调试还是交给 Keil；ESP32 的话基本就都在 VS Code 里完成。

看论文我一般会用 小绿鲸英文文献阅读器，阅读和标注都挺方便的。最近也开始觉得 Zotero 特别好用，所以慢慢开始用它来管理文献。

硬件这边我会用 拓竹 的 3D 打印机打印一些好玩的东西，也会打印硬件外壳，还是挺实用的。做 PCB 设计的话，我主要用 嘉立创 EDA。
