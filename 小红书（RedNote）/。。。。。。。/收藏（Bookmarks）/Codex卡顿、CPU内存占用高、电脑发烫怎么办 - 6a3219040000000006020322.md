# Codex卡顿、CPU内存占用高、电脑发烫怎么办

作者：文科AI编辑部


![[小红书（RedNote）/。。。。。。。/媒体（Media）/6a3219040000000006020322/image-1.jpg]]

![[小红书（RedNote）/。。。。。。。/媒体（Media）/6a3219040000000006020322/image-2.jpg]]

排查了很多原因，小红书上查了许久，都不是根本原因。
最后发现最关键的是Git不停扫描巨大的父目录所致。
任务管理器中可以看到有好几个Git for Windows进程一直在运行，占了15%的CPU，总占用率达到35%！关掉后台进程也没用，重启后还是会出现。
	
于是让Codex自己解决了， 并做了全方位优化，比如——
1.清理失效工作区引用
2.裁剪线程列表摘要
3.压缩日志库
4.清理临时缓存和旧备份
5.建立当前工作目录的独立Git边界
6.设置Git向上查找边界
	
现在空闲时Codex内存占用只有0.1%，多任务并行时也只有15%以内，终于不再发烫了！
	
已让Codex写成可复用的经验文档，在笔记下方，需要的可自取，丢给Codex照做即可。↓↓↓
