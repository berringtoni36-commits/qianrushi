# 24届银行跑路转agent开发随笔1.0

作者：我最最高冷


![[小红书（RedNote）/。。。。。。。/媒体（Media）/69a348140000000016008058/image-1.jpg]]

突然有点感慨不知不觉也入职一个月了 agent开发和之前自己手搓的toy完全不一样 业务场景要考虑的东西还蛮多的 感觉还是离不开后端 数据库选型 建表 高并发场景任务的分发消费 封装api的框架选择 数据层的ETL 真的做到业务不知道为什么总感觉用不到RAG 微调这些东西 一个是召回率的问题好像解决不了 另一方面考虑过KG 用过lightRAG效果也并不理想 前后相关逻辑丢失问题并没解决 后面改用postgreSQL 但llm对数据的提取并不到位 做了prompt engineering和few-shot似乎效果也没变好有时候感觉反而更差 提取到的质量也良莠不齐 试了提多轮和进行bm25+向量匹配+路径匹配基于需求问题多路召回填入提取模版再进行清洗验证数据 虽然变好了但也没达到预期 总之就是问题比较多 不过还挺享受一点一点解决问题的过程的 一定会越来越好的
