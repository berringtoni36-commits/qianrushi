我开源了我花费了 5 亿 Tokens 打造的 Obsidian AI 插件，名为 Codian，开源免费！

对于 Codian 这个名称，我赋予其含义，Co+Obsidian，前缀 Co 是共同、一起&合作的意思，放在这里就是人+Agent 一起协作管理 Obsidian。

一、聊天界面
1. 欢迎页加入了动效
2. 聊天窗口支持部分 markdown 语法渲染
3. 聊天窗口支持文件和文件加路径渲染
4. 支持直接拖拽文件及&文件夹到聊天窗口
5. 支持圆点大纲和卡片预览
6. 历史会话支持关键词检索

二、配置界面
配置界面划分为 4 大块:通用、提供商、工作区和关于

1. 通用界面：添加了聊天导航样式和输入框 Markdown 实时预览；删除语言设置，让插件语言和 Obsidian 本体语言保持一致

2. 对 claudian 原有的 5 个提供商进行了重新整合，另外添加了对 Kimi 的支持

3. 对于 claude，支持添加第三方模型服务（后续其他几个提供商也会支持第三方服务）

4. 去除了环境变量这种概念，直接像往常一样输入 base url、apikey 和模型 ID 即可

5. 工作区 用来存放 SKILLs、子代理、MCP 以及 Command
