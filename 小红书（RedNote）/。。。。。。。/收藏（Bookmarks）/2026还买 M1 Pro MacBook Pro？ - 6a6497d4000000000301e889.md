#macbook[话题]# #MPB[话题]# #二手笔记本电脑[话题]#

缘起: 希望有一台完全属于自己的电脑, 做vibe coding, 长续航
选择: 兼顾有限预算, 性能和便携, 3月在海鲜市场6300入手这台14寸M1 Pro 10+16 32G 1T MBP, 虽然外壳有划痕，但是Apple Diagnostic ADP000, 电池循环90次, Power On Hours 200小时, 值得
体验: 32G内存跑日常应用和vibe coding都很流畅, 没有需要硬盘swap的情况, 夏天没开空调的房间也就是掌托比较烫手而已, 一根雷电线连LG UltraFine显示器实现同时供电和4K屏幕扩展, 和iPhone/AirPods全家桶交互方便, 6扬声器系统和XDR屏幕算是附赠的惊喜

2026/7/27，补充验机经验：

通常二手MacBook验机会提到查看ID锁，监管锁，屏幕是否是否原装，电池寿命和重启Command+D跑诊断模式，确认结果是ADP000，但是很少有人提看硬盘通电时间+写入量（通电少，可以从侧面印证用得不是太狠）
brew install smartmontools (安装smartmontools)
sudo smartctl -a /dev/disk0 (查看SSD累计工作小时数/通电次数/数据读写)
会有类似下面的内容(举例而已，也不是我电脑的状态)，把整个输出的结果让AI解读
Power On Hours:            5123
Power Cycles:              428
Data Units Written:        48.6 TB
Data Units Read:           92.1 TB
Percentage Used:           3%
