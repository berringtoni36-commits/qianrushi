# 🔥新手必看！Claude Code十大提效技巧

刚开始用Claude Code的时候，总会觉得跟网页版写代码没啥区别。
新手学会这些技巧，效率直接翻几倍。
	
1️⃣ CLAUDE.md 是灵魂文件
项目根目录放一个 CLAUDE.md，写上技术栈、代码风格、还有禁止操作（比如"不要删文件""不要动package.json"）。Claude 每次启动都会读，省了我50%的沟通成本。
	
2️⃣ /model 随时切模型
简单任务切 Haiku 省钱，硬骨头切 Opus 上火力。一个命令搞定不用重启，我日常80%任务 Sonnet 就够。
	
3️⃣ Shift+Tab 秒接受修改
Claude 改完代码弹出 diff，别傻傻一个个按 y。Shift+Tab 直接全部接受，手速起飞。
	
4️⃣ /compact 长对话续命
聊到一半 token 快爆了？/compact 一键压缩上下文。我有次改大项目聊了2小时，全靠这个撑到最后。
	
5️⃣ 管道模式一把梭
cat error.log | claude -p "分析报错原因"，不用进交互界面，命令行直接出结果。配合脚本简直是自动化神器。
	
6️⃣ Memory 跨会话记忆
Claude Code 会把重要信息存到 ~/.claude/ 下。下次新开会话不用重新介绍项目，它都记着呢。
	
7️⃣ /cost 实时看账单
随时敲 /cost 看当前花了多少。我就是靠这个从"月底看账单心惊肉跳"变成"心里有数"的。
	
8️⃣ Esc 一键刹车
Claude 跑偏了或者改错方向了？按 Esc 立刻中断，不用干等它把错误代码写完再撤销。这个救了我无数次。
	
9️⃣ 多窗口并行干活
开两个终端，一个写前端一个写后端。用 git worktree 隔离工作区互不干扰，效率直接翻倍。
	
🔟 Hooks 自动化流程
提交前自动跑 lint、保存后自动格式化。配一次，爽到项目结束。
	
如果只学一条——学第一条。不会 CLAUDE.md 的人，本质上在浪费 Claude 一半的能力。
