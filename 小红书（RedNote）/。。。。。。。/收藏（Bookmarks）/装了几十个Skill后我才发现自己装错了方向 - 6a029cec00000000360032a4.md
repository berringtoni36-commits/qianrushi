分享一下我自己怎么管理 Claude Code 和 Codex 的 skill。
可能有更好的方案，这只是我目前在用、还算比较顺手的一种。

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

很多人包括我自己，用 Claude Code，又用 Codex，可能还带个 Cursor。

skill 装了一堆。
Claude 的 ~/.claude/skills 里塞十几个。
Codex 的 ~/.codex/skills 又装一遍。 换台电脑，再装一遍。
而且 skill 现在很多是从别人开源仓库 clone 下来的，每个人都会改成自己更顺手的版本。
改完一台机器，剩下几台还得跟着同步一遍。

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

我的做法是 skill、command、agent、CLAUDE.md、settings.json 全部不放在 Claude 或 Codex 自己的目录里。
放在自己一个固定的目录里。
我叫它 Brain，扔在 iCloud 上的 Obsidian 库里。
然后用 symlink 把 Claude 和 Codex 的几个关键路径都指过去。
改一处，所有工具同时生效。

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

这么做主要想解决两件事。
一是多设备每台都装一遍 skill 太烦。
二是 clone 别人 skill 改完之后，要让其他机器也跟上新版本。

让所有工具、所有机器都消费 Brain 这一份就行。
Claude 和 Codex 都是消费方，Brain 才是 source of truth。

~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

落在 Obsidian 库是因为 iCloud 跨设备同步足够满足我的需求，git管理也一样。
工作机改完一个 skill，回家打开 Mac mini，新版本就在那。

新电脑装完 Claude Code，跑一个 setup.sh 把软链建一遍，所有 skill 立刻同步好。
