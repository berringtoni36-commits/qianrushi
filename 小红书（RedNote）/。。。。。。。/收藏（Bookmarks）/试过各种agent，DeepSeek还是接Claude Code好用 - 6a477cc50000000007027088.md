试过各种agent，DeepSeek还是接Claude Code好用

网友们总说都用国产模型了为什么还要用Claude，实际情况就是没法，还是接到Claude中最好用。

我们买了GML和DeepSeek，接到各种Agent中各有各的问题。

Codex:同样的模型，速度慢很多，而且对工具链的调用总是笨笨的不会用，要过程中反复提醒用什么什么工具去干什么什么，太累太笨了。

Trae，Qoder之类的，无法设置上下文大小和推理等级，都是用的默认值。就这一点就只能放弃了。

OpenCode:感觉还可以，短暂尝试没发现问题。

[红色心形R]我的Qoder还在团队套餐里，团队套餐用户不支持自定义模型，所以用的QoderCN尝试，看了评论才知道可以自定义，那就非常好了[红色心形R]
