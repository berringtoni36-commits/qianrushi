谁懂啊。
以前我每次共享屏幕，最怕别人看到我的桌面。
截图、压缩包、临时文件、安装包、各种「最终版」「最终版真的」铺满一整屏。
不是不想整理。
是真的整理不动。
我建过「临时文件」文件夹。 三天后变成「临时文件2」。
我也试过全部拖到 D 盘。 桌面是干净了，但文件也找不到了。
后来我发现，我想要的其实不是删除文件，也不是搬家式整理。
我只是想让它们还在原来的地方，但桌面看起来干净一点。
所以我给自己做了 DoStack。
✨ 毛玻璃覆盖，让 Windows 桌面有一点 macOS 的通透感
📂 虚拟桌面整理，不移动原文件，只是视觉上变清爽
📝 待办 / 看板 / 便签都能放在桌面上，不用打开一堆软件
💊 顶部灵动岛，天气、控制、状态集中在一个地方
🎨 低饱和度配色，不刺眼，也不花哨
我现在桌面还是会乱。
但至少打开电脑的时候，不会被一整屏图标迎面砸到了。
对我来说，桌面不一定要完美。
但它应该让人愿意开始工作。
你们的 Windows 桌面现在是什么状态？
