从零构建-ros智能体机器人第一版-ROS-Camera(核心模块)
1、camera -摄像头驱动模块
功能
- 通过V4L2接口驱动USB摄像头
- 支持MJPEG格式图像采集- 实现动态设备切换和错误恢复
- 提供智能订阅者管理
- 接入ROS通信
技术实现
- 使用V4L2 API进行底层设备控制- 内存映射(mmap)提高数据传输效率
- 多缓冲区机制保证连续采集
- 30Hz固定帧率输出
2、img_decode - 图像解码模块
功能
- 将JPEG压缩图像解码为RGB格式
- 支持硬件加速解码(ARM平台)，在ARM平台使用MPP硬件解码器，x86使用opencv
- 实现图像缩放和格式转换
- 提供智能订阅者管理
技术实现
- ARM平台: MPP硬解码 + RGA硬件缩放
- x86平台: OpenCV软解码 + CPU缩放
- 直接内存操作避免数据拷贝
- 智能订阅者检测自动启停
3、YOLO目标检测模块
功能
- 基于RKNN NPU的YOLOv6目标检测
- 支持多线程推理和后处理
- 提供离线测试模式
- 实现检测结果可视化
技术实现
- 三线程架构: 推理线程、后处理线程、检查线程- 队列机制: 使用线程安全队列传递数据
- 硬件加速: RGA图像缩放 + RKNN NPU推理
- 后处理: 多尺度检测 + NMS非极大值抑制
-检测类别：人员检测 (person)、车辆检测 (car, truck, bus等)、动物检测 (cat, dog, horse等)、日常物品检测 (bottle, cup, book等)
