我做了一个简历 skill，叫 resume-builder。

之前帮人改简历改了很多次，每次都是同一套流程，追问经历细节，补量化数据，STAR 句式重写。改完内容对方问排版怎么办，Word 对不齐，在线网站导出要会员。

✅ 包含啥 📌 5 套 A4 模板，compact / classic / modern / timeline / minimal，同一份内容随时切

📌 7 种配色 + 自定义色值，classic 始终黑白保证 ATS 兼容 📌 STAR / XYZ 句式润色，追问你的背景、行动和可量化结果，不编造经历

📌 JD 匹配分析，拿具体 JD 检查你的命中项和缺失项，调整内容顺序和措辞

📌 多种输入方式，CSV 表格 / Markdown 旧简历 / 对话沟通都行

📌 全程本地离线渲染，嵌入字体，PDF 文字可复制可搜索 ⚠️
