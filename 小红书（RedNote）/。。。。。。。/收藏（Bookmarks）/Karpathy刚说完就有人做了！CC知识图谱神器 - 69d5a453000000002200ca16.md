![[小红书（RedNote）/。。。。。。。/媒体（Media）/69d5a453000000002200ca16/image-1.jpg|520]]

Karpathy推文刚发48小时！神器Graphify就上线了：Claude Code里输入一行命令，把任意文件夹秒变可查询知识图谱+Obsidian vault，研究/代码效率直接起飞！

刷到这个刚开源的宝藏项目，完美对标Karpathy最新知识库工作流：

Graphify核心就是把「raw文件夹」直接变成智能知识图谱：
1/ 扔进去任何文件夹（代码、论文、PDF、图片、markdown）
2/ Claude Code里敲/graphify .（或指定路径）
3/ 自动输出：交互式知识图谱（graph.html）、Obsidian vault（带backlinks）、wiki入口index.md、GRAPH_REPORT.md

还能直接问：
1/ “这个函数被谁调用了？”
2/ “这两个概念怎么关联的？”
3/ “项目里最重要的节点是啥？”

超硬核亮点：
1/ 支持13种编程语言（Python/TS/Go/Rust/Java…）+ PDF + 图片（Claude Vision解析图表）
2/ 两步处理：本地tree-sitter AST解析代码 + Claude并行提取语义，完全不用向量数据库
3/ 71.5x token节省！后续查询只读紧凑graph.json，不用每次啃raw文件
4/ 自动watch/git hook，文件改动秒更新图谱
5/ 额外输出：SVG、GraphML、Neo4j、纯文本wiki，随便玩

仓库：https://github.com/safishamsi/graphify
安装超简单：pip install graphifyy && graphify install
• 然后在Claude Code里直接/graphify 你的文件夹路径

适用人群：
1/ 每天用Claude Code撸代码/读论文/管项目的开发者
2/ 想把散乱资料变成“第二大脑”的研究党
3/ 爱折腾Obsidian + LLM知识库的玩家

小Tips（实测版）：
1/ 第一次跑会花点token建图，后续查询飞快
2/ 加--obsidian直接生成完整Obsidian vault
3/ 想一直开启：graphify claude install自动hook，Claude以后默认读GRAPH_REPORT.md
4/ 支持/graphify add https://arxiv.org/...直接塞论文
