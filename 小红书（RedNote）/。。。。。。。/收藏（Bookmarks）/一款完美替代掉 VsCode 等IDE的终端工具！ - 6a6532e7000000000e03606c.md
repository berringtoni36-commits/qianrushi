你应该听过 Typora，那款 Markdown 编辑器工具。

AI Agent时代，我们可以让 Agent 管理/操作我们电脑里的一切，收集资料、整理文件，这些AI都可以替我们完成。

人释放出来了，当消息发送给AI时，我们需要等待或切到其它任务去做。它们可能分散在不同的目录/文件夹下。有些并非代码，却需要看看它的目录结构。

不愿给终端弄个插件而使用 VsCode（因为可以直接 code . 命令打开）。

一个月前 Typora 团队出了一款 otty 完美覆盖/替代掉我苦于多个项目跳转 / 切换 / 预览目录结构，同时又能解决 Zed 这款 Rust 所写轻量编辑器的 Git 管理不够好问题。

这次，可以直接用 otty 替代掉了。

在处理任务时，它会显示在转圈，任务完成后显示蓝色圆圈。相比 VsCode / Zed 终端黑盒般需要我们去查看方便和省心太多了！

目前，这框软件只有 Mac 支持，Windows、Linux 平台 coming soon.

这款软件比较极客，如果愿意折腾，不用怕，把它切换成中文，慢慢研究、常用命令会了后也是非常方便的。

我昨晚接触了这款软件后，已经把默认终端和 VsCode 都替换掉了，包括 Obsidian 都不用打开了。
