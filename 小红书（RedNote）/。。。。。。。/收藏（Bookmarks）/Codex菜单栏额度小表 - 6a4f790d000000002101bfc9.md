用Codex 给 Codex 搓了个菜单栏额度小表 ⚡️
最近用 Codex 比较多，经常写着写着就想看一眼：

额度还剩多少？
还能用多久？
什么时候恢复？

所以 vibe coding 了一个 macOS 菜单栏小工具，叫 Codex Meter。

它会把 Codex 额度直接放到右上角菜单栏里，像电量一样常驻显示：

81% | 1h34m

点开之后还能看到会话剩余时间、周额度、恢复时间，也支持手动刷新、低额度提醒和语音播报。

相比原生提示，它更适合高频使用场景：不用切回 Codex，也不用等撞到限制，看一眼菜单栏就知道还能不能继续冲。

项目是从真实痛点出发做的小工具，轻量、直观、常驻，属于一个纯 vibe coding 小项目。

已开源：
https://github.com/HappyChenchen/codex-meter
