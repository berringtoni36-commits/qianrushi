之前视频里很多人问的Codex自动投简历workflow，我整理到GitHub开源了！
项目叫 ApplyPilot。
先说清楚它不是“用了就能拿 offer”的工具，也不是让 AI 替你到处乱投。我更想做的是，把我自己的找工投递流程拆出来，变成一套别人也能装进 Codex / 其他AI Agent 里复用的 Skill。

第一次安装install，它不会直接开始投简历，而是先做 onboarding。大概花不到10 分钟，先把基础信息、目标岗位、投递偏好、sponsorship、relocation、EEO 这类申请表里经常遇到的问题问清楚。
我建议第一次只做 lead-finding-only 或 trial run。也就是先让它跑通一遍流程，看看还缺哪些权限、文件、个人信息或规则。真正提交前，它会停下来让你确认，不会一上来就直接 submit

我还把投递分成了海投和精投两种模式
海投模式适合批量筛岗，用已有简历版本快速推进。
精投模式更适合高匹配岗位，AI 会先给简历修改建议，等你确认方向之后，再逐步自动化。

每个岗位也会进入 dashboard： Pending / Skipped / Blocked / Needs user / Submitted
后面它也会复盘投递里反复出现的卡点，把这些 repeated blockers 慢慢变成规则，用得越久，它会越像一套适合你自己的求职 workflow。

GitHub： https://github.com/yvonnehe772/applypilot
强烈建议用之前先读README
有需要的话会录完整实操视频，欢迎大家 star / fork / 提 issue
