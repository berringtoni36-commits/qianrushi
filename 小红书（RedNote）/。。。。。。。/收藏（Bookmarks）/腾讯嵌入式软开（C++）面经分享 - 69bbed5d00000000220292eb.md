# 腾讯嵌入式软开（C++）面经分享

作者：嵌入式老番茄


![[小红书（RedNote）/。。。。。。。/媒体（Media）/69bbed5d00000000220292eb/image-1.jpg]]

面试官技术功底扎实，态度温和有礼貌，全程开摄像头无压迫感，提问均围绕简历填写的技能点展开，深挖技术本质与底层原理，极少超纲提问，面试体验极佳。
	
面试核心以简历对应技能点的八股考察为主，项目细节提问较少。以下可直接对照个人简历技能点做针对性准备，参考性极强。
	
一、C++ 核心基础
介绍 C++ 的智能指针，常用类型有哪些？分别讲解实现原理，不同类型指针的核心区别
std::move 的作用是什么？底层如何实现？讲解左值和右值的核心区别，std::move 属于左值还是右值
C++ lambda 表达式的捕获方式有哪些？日常开发最常用哪种？捕获的变量在外部释放后会出现什么问题
日常开发常用的 C++ STL 容器有哪些？分别讲解 vector、map、unordered_map 的本质、底层实现与核心特点
	
二、数据结构核心考点
红黑树和平衡二叉树（AVL 树）的核心区别
unordered_map 的哈希冲突是如何解决的？
如何判断一个单链表是否存在环？
	
三、面向对象与程序稳定性
讲解面向对象的三大特性，以及多态的底层实现原理，虚函数表的本质是什么
开发中是否遇到过程序崩溃（Crash）的情况？导致程序崩溃的常见原因有哪些
	
四、操作系统与多线程 / IO
多线程环境下，如何保证共享资源的线程安全？什么是死锁？死锁产生的核心原因是什么
阻塞 IO 和非阻塞 IO 的核心区别是什么？谈谈对非阻塞 IO 的理解
是否自己实现过线程池？讲解线程池的核心结构与实现原理
操作系统中，线程切换的底层实现原理是什么
	
五、嵌入式硬件与项目实操
项目中使用的 ESP32 单片机，主频和内存是多少？单核还是双核？如何把任务绑定到指定核心上
是否使用过看门狗？看门狗的核心作用是什么
项目中使用的传感器是什么型号？需要处理几路数据？如何保证多路数据的同步处理
是否使用过环形缓冲区（Ring Buffer）？讲解其实现原理
