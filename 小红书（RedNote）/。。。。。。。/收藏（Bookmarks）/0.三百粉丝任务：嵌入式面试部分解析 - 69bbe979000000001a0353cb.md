# 0.三百粉丝任务：嵌入式面试部分解析

作者：Frank嵌入式就业培训


![[小红书（RedNote）/。。。。。。。/媒体（Media）/69bbe979000000001a0353cb/image-1.jpg]]

好快啊，300粉丝了
	
要上点强度了！
一家之言，探讨一下
《面试的艺术》
	
回答几个最常被问的问题
	
1.面试究竟什么最重要？
	
下面就是我的回答
	
项目含金量＞面试表现（表达、逻辑、沟通）＞技术深度＞学历＞八股（但是这是基础）
	
八股确实要背，但八股不会让你脱颖而出，有含金量的项目才会。
什么叫含金量？
不是你写了多少行代码，而是：
实验室核心项目
公司关键模块
或者你参与的开源项目
甚至是你实习里沾边的核心功能
你能讲清楚，那就是你的项目。
	
不会被“拆穿”吗？放心，不会。
被问住了说明你讲得不够清晰，不够深入，下次就能答上来。
校招和高考不一样——
校招考不对答案，你能无限次模拟考试。
	
2.面试前还有什么事是我们需要准备的？
	
面试前一定要做的事有
查公司的业务
看产品线
在自我介绍结尾说出你对业务的思考
	
面试官听到你做了功课，好感度直接加分
应届生的水平是相似的（大都很水）
所以态度就很重要（很多人忽视）
	
3.面试究竟要以一个什么状态？
	
面试时，把面试官当朋友
不要像背诵一样答题，不要“一问一答”。
把你的项目当故事讲，
不会的问题，把你的思考过程讲出来。
就像朋友问你：“你昨天吃啥？”
你可以说：“好像是在家吃的，我妈做的，还挺香，你也吃过那个菜。”
而不是：“不知道……那个……我……我忘了……”
逻辑清楚 + 表达自然，比答上来更重要。
	
🏁 最后
今年市场虽然难，但机会真的不会亏欠有准备的人。
	
以上是面试技巧不相信就看个乐子
	
这也只是我众多思考中的一小点
我讲我的关于面试的所有思考汇总成了一门课
目前我的所有学生都通过这门课得到了自己的答案
