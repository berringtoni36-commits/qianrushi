[二R]项目概述
ADASim是一个轻量级仿真测试平台。针对传统仿真软件（如 Carla, Apollo）极为庞大、环境配置困难、对硬件要求苛刻的痛点，ADASim 采用 C++ 底座引擎 + Python 算法大脑 的软硬解耦架构。

6. 无需硬件成本，虚拟机即可

[四R]项目架构
①数据引擎：基于无限滚动沙盒缓存技术，提供高频数据泵与无缝的时光倒流回放体验。
②渲染引擎：纯内存驱动的高性能 2D 绘图管线，采用榨干 CPU/GPU 性能，承载十万级点云无卡顿。
③物理引擎：内置经典的车辆运动学自行车模型，支持闭环物理推演，也支持算法层面进一步DIY。
④通信网关：内置基于 Qt 的异步 TCP/UDP 网络层，负责数据的全双工透传与 JSON 报文装卸。
⑥Python规控：独立运行的算法节点，通过 TCP Socket 与底座进行高频心跳通信。
	
项目环绕多个知识点，真实项目背景不怕烂大街，车企、机器人纵向项目，轻松拿下对应offer，也通用于大部分的Linux应用岗位，可进一步DIY开发
