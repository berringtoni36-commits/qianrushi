最近咨询有点爆，好多姐妹问我怎么转岗 AI Agent。其实我这段时间真忙炸了(基本10-11)，不过既然大家感兴趣，我就把当时的决定和现在的复盘摊开来讲讲，希望能给想动的姐妹一点参考。
	
# 1. 关于我的老底
目前阿里 ai agent 技术专家，带着 3 个同学攻坚 Shopping Agent，目前日均 7w 调用数。大学那会儿刷题拿过 ACM-ICPC 银，所以算法底子这块确实没丢。校招来的阿里 3 年多 Java 后端，也就是大家说的 CRUD，但好在是在核心链路，千万级并发的大促也扛过几次。今年初裸转组切到 AI Agent 方向，现在带着个小团队在攻坚(目前日均也有5w多的调用量了)。Python 现在也是天天写。
	
# 2. 基础部分：别被那些名词唬住
面试其实没大家想得那么恐怖，但 Bar 也不低，所以不能掉以轻心。
Agent 其实门槛比你想象的要低。你不需要成为算法专家，但要懂得怎么用，怎么架构。比如：
- LangChain 的 Chain、Agent、Memory 怎么组合使用、MCP
- Agent构建：ReAct、Plan-And-Execute、Reflection、Tool Use、Multi-Agent Collaboration
- Agent架构模式：SubAgents、Router、Hierarchical、Network、Workflow等
- Prompt Engineering 的核心技巧（思维链、少样本、角色设定等等）、上下文工程（上下文压缩、滑动窗口、Rerank 优化）
- RAG（检索增强生成）完整链路怎么搭建
- 怎么调试 Agent 输出，优化推理质量等等
	
# 一些唠叨
春节前我也是准备了好久的 AI 赛道的八股文和梳理了我工作的项目，抱着尝试的心态，投了字节的 2-2。最终好在没白熬几个大夜，hr 给了 40 的涨幅，挺开心的了。但因为老板、环境、发展等等诸多因素决定原地不动吧，先看看组织今年的"考虑"~
	
最后想说，转岗/面试没有完全准备好的时候，我都是差不多就冲，在干中学最快，我最后也是通过八股来快速巩固自己的知识体系，都是这样过来的😌
	
希望这些分享对大家有一些帮助，有问题评论区见，看到都会回~
