发现一个 YC 孵化的宝藏 Skill——Graphify，67K 程序员已经在用了 👇
用法简单到离谱：
/graphify .
就这一条命令，你整个项目——代码、数据库 Schema、文档图谱。
✨ 它牛在哪
1️⃣ 上帝视角
自动找到最核心的枢纽节点，标记跨文件的隐码影响了哪个
2️⃣ 带置信度标签  每条关系标注INFERRED（推断），不瞎猜
3️⃣ 20+ AI 平台
Claude Code / Cursor / Codex / Gemini CLI 全支持，一条 graphify install 注册。
4️⃣ 输出三个文件
graph.html（浏览器打开直接拖拽探索） + GRAPH_REPORTgraph.json（完整数据可反复查询）
📦 三秒安装
uv tool install graphifyy   # 装包
graphify ins 手
/graphify .                 # 在项目里生成图谱
🎯 适合谁：
接手老项目看不懂架构的 / 需要给团队做技术文档的 / 代码库太大 grep 不动了的
