# 嵌入式上岸包来啦

大家好，我是沐一。这篇文主要是介绍一下我的《沐一的嵌入式上岸包》。
先来介绍一下我的情况，我是双2硕，无论文，一段两个月的小厂实习，一段三个月的手机厂实习，主要投递了嵌入式linux应用/驱动开发（音视频），操作系统开发，和isp三个方向。秋招海投型选手，大概投了150+公司，约面40+公司，最后拿了16个offer。最高薪资在50w+，目前也是在等鹅的校招礼盒。
	
《上岸包》当中的主体内容是我的面经整理，我统计了我自己面试记录的共37家公司，总超过七十场面试的记录，包含了自己在过程中觉得一些重要的内容，做了解释，这个共近八万字。这部分面经因为我是海投型选手，所以不全是嵌入式的面经，我自己秋招投递的岗位可能一半是和camera、isp这类方向相关的（因为我的实习经历），所以提供了《纯面经》类似试读的版本，这个也在橱窗当中，大家可以看一下。
有面经的公司列表在商品介绍当中，大家可以点开链接看一下
	
除此以外，这段时间和很多同学交流，我把一些问题比较多的也写成了文档，之前部分同学拿到过标注为（小红书版）的飞书文档，内容会有些出入，这部分写的更为详细一些，目前包括：
0、完整秋招面经
1、个人面试时间参考
2、面试时间记录模板--可复制
3、个人嵌入式学习时间线参考
4、嵌入式linux介绍和资源总结
5、面试自我介绍参考
6、研二上零基础我会怎么做
7、嵌入式 Linux 开发重点引申：面经真题佐证
8、嵌入式比赛 == 求职加分利器？ 研究生备战指南来了
9、嵌入式进阶： 学完 Linux 应用 / 驱动后，如何上手 Camera / 音视频开发——科普篇
	
后续也会持续进行内容的更新，下一步更新计划是音视频开发的学习路线。接下来可能会随着更新内容的增加，做一些价格方面的调整。
最后，非常感谢大家这段时间和我的分享和大家的信任，因为这一部分内容是最开始在微信试卖的，和大家聊了很多，得到了很多正反馈后，才敢放到了小红书上。
最后的最后，希望大家都能获得心仪的offer~道阻且长，行则将至。
