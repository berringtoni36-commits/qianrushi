最近，我给自己的 Obsidian 做了两个 Skill
❶ 它现在能做什么？
我在小红书、YouTube或普通网页上看到有用的内容后，可以直接剪藏进 Obsidian

Skill 会读取内容，整理出一句话总结、核心知识点、创作角度和原始来源，再按照主题放进我的素材库。
如果视频有可读取的转写稿，它也会继续整理口播内容

❷ 我为什么要做它？
以前我收藏了很多内容，但真正要写东西时，还是想不起自己看过什么

小红书收藏越来越多，真正沉淀下来的素材和知识却不成体系

❸ 我想补上“收藏”后面的步骤
收藏内容
→ 剪藏进 Obsidian
→ Skill 自动整理
→ 按照主题归类
→ 写内容时重新调用

❹ 为什么不按照平台建文件夹？
因为以后找资料时，我想找的是“AI”“产品经理”或者“内容创作”，而不是回忆这条内容当时来自哪个平台。平台只作为来源，主题才决定它放在哪里

❺ 这套流程是怎么做出来的？
→ 先用现成工具
我一开始使用了官方 Web Clipper，但发现剪藏后的格式不符合自己的需求

→ 然后和 Codex 一点点调整
包括笔记格式、图片处理、视频转写、分类规则和失败状态。哪里不好用，我就回来继续改

→最后把流程打包
几个零散的想法，慢慢变成了两个 Codex Skills、一个 Obsidian 本地插件，以及一套自动整理流程

❻ 大家也可以安装
我已经把项目公开，具体安装步骤放在最后一张图里。
GitHub 搜索：JessieSun-vibe/obsidian-knowledge-capture，目前支持小红书、YouTube和普通网页。

其中「网页知识自动沉淀」是项目自带的本地插件，不需要去 Obsidian 社区市场搜索。

它现在肯定还不完美，但以前收藏完就消失的内容，终于可以进入自己的知识库，变成以后还能继续使用的素材。

如果你有需要了，可下载安装测试喔！
