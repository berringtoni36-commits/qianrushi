做了一个 pdf2md-agent-skill，可以把 PDF、Word、PPT、Excel 等文档整理成 Markdown。它会按页处理普通文本、数学公式和扫描内容，也能改善双栏论文的阅读顺序，方便后续交给 Claude Code 或 Codex 阅读、总结和提取信息。ps：主要是特殊格式分流＋OCR识别，对于国产的非多模态模型可以用，对于论文特殊格式做了适配，对于多模态模型也可以省token。  #skill分享[话题]#
