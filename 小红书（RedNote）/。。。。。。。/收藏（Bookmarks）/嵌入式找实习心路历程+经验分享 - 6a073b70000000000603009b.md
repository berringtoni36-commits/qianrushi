回看这两个多月，心态经历了“盲目自信 ➡️ 备受打击 ➡️ 摆烂消沉 ➡️ 认清现实 ➡️ 触底反弹”的全过程。
	
📊 2026 嵌入式暑期实习复盘
今年嵌入式软件的求职环境，竞争算是一般激烈。结合自身和身边同学的经历，总结出以下几点：
1. 关于学历与能力
学历歧视依然存在，但明显在减弱，目前是 能力 ≥ 学历。
学历是门槛： 本硕只要有一个是 985 或 211，基本都能拿到大部分中大厂的面试邀请。
能力是上限： 我认识几个专业能力极强的双非硕士同学，今年都拿到了非常好的中大厂 Offer；而“双九”或者项目含金量高的同学，基本属于不愁 Offer 的状态，很少有0offer的（除非运气极差），要是有双九的小伙伴但是还没offer，不妨看看是不是自己只投大厂期望过高或者还是根本没进入找实习的状态。
	
2. 考察重点的排序
不同体量的公司，面试侧重点完全不同：
中小厂： 重点问 项目 + 八股。LeetCode 基本不问。
大厂： 核心看 项目 + 八股 + 手撕 LeetCode + 底层数据结构。手撕是硬性要求，写不出来大概率直接挂。
	
总结下来，决定你能不能拿 Offer 的因素：
运气>>学历>=实力
有时候眼缘（运气）真的比实力更重要
	
💡 感受
找实习、找工作，最核心的是信心和方向。在这里分享一条很明显的暴论：
找准方向 + 无限时间 + 持续学习 = 能完成任何事
	
最后，看到小红书上针对想转行嵌入式的同学，给两句客观的建议：
👍 如果你是传统理工科（机械、自动化、电子等）： 虽然专业不好找工作，但只要对嵌入式有强烈的兴趣、能吃苦、能专注，转过来其实很快，毕竟工科的基础课是共通的。如果本硕学校还可以，好好做两个有含金量的项目，进大厂的概率非常高。但是薪资这方面肯定是不如互联网的。
	
👎 如果你是纯文科，或者对硬件/底层完全不感兴趣：强烈劝退！嵌入式要补的基础实在太多太难太杂。没有强烈的兴趣，学起来会极其痛苦。这类同学可以看看 Java 或者最近大火的 Agent 开发或者其他行业，比如销售（做好了是真赚钱）、管理、产品经理这类，上手难度和就业机会真比嵌入式友好太多。并且进互联网的薪资也很高。
	
最后，希望大家都能找到满意的暑期实习。
PS：六月份有很多大佬会释放一批中大厂实习，伙伴们可以好好把握机会
