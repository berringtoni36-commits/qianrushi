今年机器人行业确实很火，有不少嵌入式岗位
	
火爆的表现，就是岗位拿offer更容易。已经有不少粉丝，靠我的那个嵌入式项目，拿到了机器人行业的实习。毕竟我那个项目的本来就是 ROS 机器人相关，和不少公司的业务比较接近
	
这也让很多研0、研一的同学跃跃欲试，想进入机器人行业，但是却搞不懂学啥。所以想从招聘需求出发，聊一聊应该学什么
	
机器人嵌入式岗位，可以分成两类：
一类是MCU下位机方向
一类是Linux上位机方向
	
1️⃣ MCU 方向的机器人嵌入式岗位（图2～5）
这类岗位一般主要做下位机。简单来说，就是上位机发出指令，比如前进、控制电机转速，然后 MCU 负责把这些指令真正执行出来
常见工作有：
电机控制、编码器读取、PID 调参、CAN、传感器采集、RTOS、底盘控制等
建议重点学：
C 语言、STM32、RTOS、UART/I2C/CAN、PWM、PID
这就是把 MCU 常见技术栈用到机器人场景里。路线很明确：
先把 STM32、通信、PID这些基础学扎实，再把项目往机器人传感器采集、上位机通信这些场景里靠。这样进可以投机器人，退也可以投其他 MCU 岗位，性价比会更高
	
2️⃣ Linux 方向的机器人嵌入式岗位（图6～7）
这类岗位更偏上位机。它是运行在嵌入式 Linux 平台上，负责机器人更高层的功能。
常见工作包括：
ROS节点开发、相机/雷达接入、导航建图、路径规划、算法部署等。
比如机器人怎么建图、怎么定位、怎么规划路线
建议重点学：
C++、Python、Linux 基础、ROS、SLAM
这个方向就是很多同学常刷到的会ROS。但这里也要提醒一句：不是说你会一点 Linux 命令，写过几个进程线程，就能胜任机器人 Linux 岗。机器人方向的 Linux，重点不是Linux本身，而是 Linux + ROS + 机器人业务。你得知道节点之间怎么通信，机器人怎么定位、建图、导航，怎么和 MCU 下位机通信。
	
3️⃣ 想投机器人，项目一定要贴业务场景
现在因为一时的爆火，机器人行业的嵌入式门槛还比较低，但未来肯定是越来越卷的。所以如果真想走机器人这个行业的，你的嵌入式项目一定要贴合机器人的业务场景。尤其是Linux方向，因为门槛更高，要求也会更高
机器人公司招你，更想看的是你能不能把业务做出来。所以项目最好真的和机器人有关
