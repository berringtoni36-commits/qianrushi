最近把我自己的 AI Skill 管理工具整理出来并开源了，名字叫 kunkun SkillHub。
做它的原因很简单：Claude Code / Codex 用久以后，本机 Skill 会越来越多。有的在全局目录，有的挂在项目里，有的来自插件缓存，也有一些可能已经断链。以前想确认一个 Skill 的用途、来源、适配软件和安装位置，经常要翻文件夹，或者靠记忆判断。
所以我做了一个本机优先的桌面管理台。它不是单纯“列文件”，而是把 Skill 当成可以长期维护的资产：
扫描 Claude Code / Codex / Agents / 插件缓存里的 Skill
统计总数、使用情况、未使用项和异常项
标注适配软件：Claude Code、Codex，或 Claude Code / Desktop
区分全局、项目级、插件级和外部来源
展示下载来源、更新链接、安装位置、真实路径和使用记录
把断链、无 frontmatter、不可读等异常状态单独筛出来
删除前做预检，软链只删入口，默认进 macOS 废纸篓
我现在最喜欢它的一点是：它把“我电脑里到底装了哪些 AI 技能”变成了一个可视化资产面板。一个 Skill 为什么装、从哪里来、适合哪个工具、有没有风险，都能被看见。
技术上是 Rust scanner-core + Tauri 2 + 零依赖静态前端。数据优先在本机处理，前端没有文件系统权限，磁盘访问统一收敛到 Tauri 后端 command。
