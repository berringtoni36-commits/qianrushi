# 我开源了自己在用的嵌入式知识学习skill

作者：梦嘉的硬件笔记


![[小红书（RedNote）/。。。。。。。/媒体（Media）/6a21377d000000002202c653/image-1.jpg]]

最近我做了一个用于嵌入式知识学习的skill，叫 engineering-learning-skill
并非普通的提示词，也不只是让 AI 解释得更清楚一点。
我想做的是一个真正偏导师式学习的 Skill，专门针对嵌入式和硬件学习场景：
当你说想学一个概念时，它不会只甩给你一段定义，而是先让你感受到「没有这个东西会有多痛」让你先建立对于这个东西的感知和心智模型，再用物理类比建立直觉、给最小可读代码、让你在纸上手动追踪执行过程、最后要求你闭卷重写。
里面设计的核心流程是：
动机建立 → 类比建模 → 最小代码 → 手动追踪 → 费曼检测 → 故意破坏 → 闭卷重建 → 知识链
参考的是下面这些心理学和教育学理论：
📌 费曼学习法（Feynman Technique）
物理学家费曼的核心观点：如果你不能用简单的话解释它，你根本没学会它。所以这个 Skill 会在中途强制让你"不看资料，用自己的话回答4个问题"，答不出来的地方就是真正的盲区。
📌 心智模型（Mental Models）
Charlie Munger 和认知心理学都强调：学新概念先要找到它在已知世界里的"锚"。所以每个概念在给代码之前，都先给你一个物理类比——DMA 是「雇了搬运工，CPU 不用自己搬数据」，互斥量是「加油站厕所只有一把钥匙」。
📌 主动回忆（Active Recall）
认知心理学里有大量实验证明：反复阅读的效果远不如"合上书，逼自己回忆"。所以这个 Skill 的最后一步是闭卷重写——你能写出来的才是真的你的。
📌 刻意练习（Deliberate Practice）
Anders Ericsson 的研究指出：在舒适区练习没用，要在错误边界练习。所以有一整步是「故意破坏代码」——把关键行删掉或改错，看它怎么崩、为什么崩。
	
这4个理论组合起来，就是这个 Skill 的核心流程：
动机建立 → 类比建模 → 最小代码 → 手动追踪 → 费曼检测 → 故意破坏 → 闭卷重建 → 知识链
覆盖场景：
环形缓冲区 / 中断与 ISR / DMA / 互斥量与信号量 /
UART SPI I²C CAN 协议 / FreeRTOS / U-Boot /
任何你看完感觉懂了但写不出来的东西
简单说，它想解决的问题是：
别再让 AI 只陪你把概念过一遍，尽量让它真的陪你学会用。
