前两次做了撰写修改简历以及模拟面试都skill，这次新做了一个适合中国industr面试的面试复盘skill！把这场面试从面试官视角复盘

✅ 包含啥
📌 5 套企业性质规则：大厂 / 创业公司 / 国企央企 / 银行金融 / 外企
同一个动作在五类公司里含义完全相反：大厂两周没消息基本可以往下推进别的了，国企两周则是是常态，创业公司慢跟你没关系纯粹是流程不确定，外企的"we'll be in touch"约等于没说。每套都附一份客套话清单，哪些话不能当信号读[暗中观察R]

📌 12 套岗位规则：
运营 / 产品 / 数据分析 / 市场营销 / 财务 / 审计 / HR / 销售 / 开发 / 法务 / 战略咨询 / 设计
企业性质决定面试官怎么读你的回答，岗位决定他往哪里追问。同一句"数据提升了30%"，运营岗被追对照组和大盘，财务岗被追口径和准则，法务岗根本不问这个。每个岗位都有高频追问链条，一层层往下追问到大部分人会断的位置。

📌 还包含
同样连问三轮，有的在核实真伪，有的其实是在给你台阶，有的只是固定题本的规定动作。这三种混着看，一场正常面试能被你读成翻车现场。[偷笑R]中英文都能用，英文面把语言问题和内容问题分开处理

✅ 跟其他AI复盘工具的区别
不是"给你打个分说哪里可以更好"那种。所有推断都要写清楚依据是哪一句、哪个追问，而且必须给出另一种解释，不把猜测说成事实
你的感觉 vs 材料显示的情况分开列面完人的自我评估极不准，你觉得砸穿了的那题常常没事，你自我感觉良好的那题才是真问题
