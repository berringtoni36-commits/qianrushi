用 Claude Code 的应该都有这体验:找一个合适的 Skill,有时候比用它还费劲。
今年 Skill 生态涨得太快,GitHub 上一搜几百上千个,但没分类、没指引。想找个趁手的,得一个个点进去啃英文 README,看完还得自己琢磨能不能解决问题。一圈下来,找 Skill 的时间比用的时间还多。
我实在烦了,自己 vibe coding 了个网站:SkillHot。
把 GitHub 上 1500 多个开源 Agent Skills、配套工具和热门项目,按 UI 设计、编程开发、办公效率、内容创作、数据分析这些真实场景,分成 14 类,每天按活跃度自动更新👇
四个模块: · 发现｜本周新发现、精选合集、随机漫游;点卡片右侧滑出详情(中文简介、适配 Claude/Gemini/OpenCode、用法) · 榜单｜按分类筛,三种排序:综合热度(我自己调的权重,不只看 Stars,还算更新频率和活跃度)、Stars、最近更新 · 分类｜14 个场景,每类有介绍和项目数 · 话题｜按 GitHub Topics 聚了 100 来个,跨领域的好东西也能顺着串到
看中的先收藏,想装直接复制安装命令,想看源码一键跳 GitHub。
纯免费,自己做着用顺手就分享出来。搜 SkillHot,或我主页入口直达。想看哪个方向的 Skills,评论区告诉我。
