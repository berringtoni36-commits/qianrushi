Anthropic官方一口气出了7种Claude Code自定义方式，从最轻量的CLAUDE.md到最重的System Prompt追加，每种方式控制着不同的维度：加载时机、持久性、权威等级。

这7种方式分别是：CLAUDE.md（始终加载的项目记忆）、Rules（触发式规则）、Skills（自动发现技能包）、Subagents（独立上下文专家）、Hooks（代码执行拦截钩子）、Output Styles（输出格式控制）、System Prompt追加（最高权威）。

核心逻辑就三句话：
1. 上下文是稀缺资源——能用触发式加载就不用常驻加载，能委派给Subagent就不在主对话里做。
2. 权威等级很重要——强制规则放System Prompt，建议放CLAUDE.md，规范放Rules。放错层级等于白写。
3. 长对话会"丢人"——CLAUDE.md的内容在长会话中会漂移，关键检查点用Hooks自动兜底。

个人觉得最实用的是Subagent：大代码库探索、文档查询这类token炸弹任务，派给Subagent干完吐结果，主对话干干净净。Claude Code自己的系统提示也在用Subagent查文档。

Claude Code的自定义不是"越多越好"，而是在对的地方放对的指令。控制上下文，就是控制成本和质量。
