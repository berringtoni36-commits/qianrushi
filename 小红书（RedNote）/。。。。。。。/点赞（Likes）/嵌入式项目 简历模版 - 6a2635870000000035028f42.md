去年26届已经上岸的一个xd

不能实习 学历也不占优

那就需要把技术栈学穿 基本全栈，最后 拿了x AI芯片初创 小ssp

面试过 都知道 大厂 对于学历卡的很死，所以 学历不高的xdm 可以多看看初创，机会更多一些

简历上的三个项目

基本是博主带着review的，他自己动手能力也不错

一步一步 从最基本的 开源项目复现

到 魔改

到 性能调优

这次把 项目简历模版 都开源出来

供xdm参考

其实还有很多可以魔改的

1. rtos项目 可以 porting 到zephyr rtos

2. 驱动项目

camera 可以引入 四路/八路真实视频流读取，假设内存cover不住的情况下，可以做memory swap / cost down

显示 往 display drm driver这边靠 拒绝传统fb

cpu 可以引入dvfs接口，往cpufreq/cpuidle/hotplug靠

另外 26届很多传统驱动的技术的xd 如果 有学历 有大厂实习，秋招 很多OC了 AI芯片 / gpu / infra岗位，想要蹭风口，这么转可能更合理一些。

3. 应用层

通信基架 可以改为 轻量级 dds，更为迎合今年具身智能中间件的需求，大家多去看看 开源dds的源码架构 底层的 zero copy机制 发布订阅 qos等

音视频 可以引入 音频 录制 与 播放，去做 音视频 同步，流媒体 可以做 多协议适配，rtmp/webrtc等。

音视频本身偏业务，安防监控制造业这边薪资一般，想要高薪 要往互联网/消费电子那边靠，比如 多学点 渲染 / ffmpeg底层 编解码 /gstreamer等，不过 互联网大厂 比如 快手 字节 这种的音视频 播放器岗位，学历 深度 要求高 hc偏少。

大家自行balance，其实 博主觉得 双非本硕 学音视频 能去 海康 也算是不错的选择，毕竟 康子 今年暑期 29硕 也直接会挂[doge][点赞R]

AI部署 除了call api完成业务，更应该 关注 量化后精度衰减 推理卡死 内存占用 等维度

既然做了部署，就应该知道 部署的hc主要集中在那边，主要在 车企 具身智能 和 芯片原厂的npu软开
