🌳543.二叉树的直径
核心：**最长路径=左子树深度+右子树深度**
1. 递归算每个节点左右树高度
2. 实时更新左右相加的最大值就是直径
3.还要+1
迭代法：层序遍历老套路每层加depth+1,返回depth就行。

🌸101.对称二叉树
1.构造对比函数compare(left,right)
2. 左右为空（true），左空/右空，左右值不等
3. inside = compre(left->right,right->left);outside = compare(left->left,right->right); return inside && outside
4. 实现函数同样逻辑判断判一遍，然后调用compare

📎23.合并K个升序链表（分治）
1. 先写mergeTwoLists()
2. 先判空，非空继续
3. 直到lists.size() >1 进入循环，构造一个tempLists作为存储的结果，两个一组遍历lists（l1 =list[i],l2=list[i+1])，每次合并后存入tempList,
4.循环完毕后更新lists，最后退出循环后返回lists[0]
