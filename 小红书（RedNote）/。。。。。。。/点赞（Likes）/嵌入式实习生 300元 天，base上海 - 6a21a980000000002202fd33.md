【团队介绍】
团队从事智能传感与场景化应用相关产品的研发，工作涵盖产品开发、验证及落地配套等环节。
【岗位职责】
1. 协助研发团队完成测试、调试及相关记录整理工作。
2. 协助样机与相关产品的检查、验证及问题反馈。
3. 协助资料整理、数据汇总及日常研发协同事务。
4. 遵守实验室与现场安全管理规定，按时完成工作安排。
5. 遵守公司规章制度，严格按照作业指导书工作，积极查找安全隐患，及时汇报安全隐患和事故，提出安全合理化建议，通过不断改进，创造安全健康的工作环境。
【任职要求】
1. 26届27届本科及以上学历在读，电子信息、计算机、自动化等相关专业。
2. 实习时长不少于 3 个月，每周至少 3 个工作日到岗。
3. 具备电工电子等相关课程基础，了解基本实验操作与实验室安全规范。
4. 动手能力强，做事细致，记录完整，能够按要求完成测试与整理工作。
5. 逻辑清晰、责任心强，具备良好的书面沟通与跨团队协作能力。
6. 能熟练使用常用办公软件进行数据整理与文档编写；能阅读简单英文技术资料。
【优先条件】
1. 有课程设计、学科竞赛、实验室项目或研发相关实习经历。
2. 有电子、自动化或智能硬件相关产品调试、测试或联调经历。
3. 熟悉常用办公软件，能独立整理数据并撰写简要报告。
4. 对智能传感、场景化应用或工业智能化方向有学习兴趣与实践经历。
