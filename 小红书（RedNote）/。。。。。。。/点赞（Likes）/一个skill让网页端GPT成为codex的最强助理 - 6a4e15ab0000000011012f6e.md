最近做了一个 Skill，解决的是我自己用 Codex 时一个很真实的问题：
项目一复杂，很多额度和上下文其实都消耗在“整理材料、查文件位置、做初步判断、反复解释项目背景”这些事情上。
但网页端 ChatGPT / Pro 明明也有很强的推理能力，却和本地 Codex 工作流是割裂的。
所以我做了一个桥接 Skill： 把网页端 ChatGPT 接到 Codex 旁边，让它变成一个项目外接助理。
它主要有两档：
第一档，把 Pro 变成项目咨询专家。 Codex 会自动整理一份项目咨询包，包括项目结构、关键文件、当前问题、风险点和需要判断的地方。你可以把这份材料交给网页端 Pro，让它先做一次高质量判断，再把结论拿回 Codex 落地执行。
第二档，把 ChatGPT Web 变成 Codex 的外接入口。 通过连接器和 MCP，它可以在受控权限下读取项目、检查文件、给出建议，再由 Codex 继续执行具体修改。#howto入门codex[话题]# #howto入门vibecoding[话题]# #REDSkill[话题]#  #skill[话题]# #GPT[话题]# #howto用好AI[话题]# #AIGC[话题]# #skillhub[话题]#
