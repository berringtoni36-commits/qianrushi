现在，Zread 不只能在线读开源仓库，也可以直接解析你的本地项目了[派对R]

这次我们一起发布了两个新能力：
1️⃣ Zread CLI
把本地项目生成一套可读的解析文档，帮助你更快理解项目结构、核心模块和运行逻辑。
2️⃣ Zread Skill
让 AI 更自然地学会使用 Zread CLI，基于生成好的文档去理解代码仓库，而不是一上来就盲读整个仓库。

使用方式也很简单：
在项目目录下输入 zread，CLI 会根据当前状态提示下一步操作，比如登录、生成文档，或者直接打开已有文档。
配合 Skill，AI 也能使用 --stdio 模式帮你操作 CLI 理解你的项目。

从在线仓库解析，到本地项目解析，再到让 AI 学会使用这套能力， Zread 正在变成一个更完整的代码阅读入口
欢迎体验 Zread CLI + Skill 👉 https://zread.ai/cli
