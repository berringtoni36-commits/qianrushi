# 小红书索引自动更新说明

## 当前状态

已配置并启用 Obsidian 本地插件：`RedNote Indexer`（插件 ID：`rednote-indexer`）。插件在 Obsidian 内部监听原始收藏、点赞、发布和专辑文件的新增和修改事件，因此可以正常写回当前 Vault；不依赖 macOS 后台任务权限。

它监听以下原始同步目录：

- `小红书（RedNote）/。。。。。。。/收藏（Bookmarks）`
- `小红书（RedNote）/。。。。。。。/点赞（Likes）`
- `小红书（RedNote）/。。。。。。。/我的发布（Posts）`
- `小红书（RedNote）/。。。。。。。/专辑（Albums）`

当同步插件新增或更新笔记时，插件会合并 2.5 秒内的连续文件事件，然后运行本地格式化器并重新读取全部收藏和点赞，完成以下动作：

- 为原始文章增加统一的文章信息卡、正文层级、图片尺寸和折叠评论区。
- 为专辑索引增加专辑信息卡和收录内容层级。
- 按嵌入式、常用 Skill、好玩的 AI、辅助内容分类。
- 合并收藏与点赞的重复 `resourceId`，但不删除任何原文件。
- 更新 Skill 与本机用户级 `SKILL.md` 的只读匹配状态。
- 刷新核心精选、备查内容、待清理和人工复核清单。
- 刷新“最新 30 条收藏”快捷页：按 `syncedAt`（同步进入 Vault 的时间）倒序显示最近 30 条收藏；新内容进入后，旧内容只会从这个快捷页退出，原始笔记仍保留。

整理结果入口：[[小红书精选导航|小红书精选导航]]。

## 安全边界

索引器只改写小红书目录内的 Markdown 展示结构，并生成 `小红书（RedNote）/。。。。。。。/整理层` 下的整理页；不移动、不删除文章，不修改媒体，也不修改第三方 `multi-source-sync` 插件。正文、图片、视频、评论和原文链接均保留。

## 手动刷新

如果需要立即刷新，可以在 vault 根目录运行：

```bash
python3 .rednote_generate.py
```

如果需要查看失败原因，可以打开 Obsidian 开发者工具（`Cmd+Option+I`）查看 `RedNote Indexer` 日志。
