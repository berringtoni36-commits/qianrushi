## 完整代码浏览清单

### Qt 上位机

- `main()`：创建应用对象并进入 Qt 事件循环。
- `MainWindow` 构造/析构：初始化 UI、定时器、进程和图表资源。
- `on_Open_triggered()`、`on_Stop_triggered()`、`on_Select_triggered()`：用户动作入口。
- `readFrame()`、`MatImageToQt()`：采集帧与显示格式转换。
- `yolop_process()`、`readBashStandardOutputInfo()`：外部推理进程的启动与输出读取。
- `InitChart()`、`timerTimeOut()`、`receivedData_cpu()`、`receivedDate_mem()`：资源监控链。
- `on_LegendMarkerClicked()`：图例交互。

### LIME

- `_init_IllumMap()`：归一化、通道拆分、初始光照图和变量初始化。
- `getMax()`：从多通道图像得到 `T_hat`。
- `derivative()` / `Dev()`：构造梯度相关量。
- `solveT()`：在 ADMM 中更新主变量 `T`。
- `getReal()`、`Mat2Vec()`、`reshape1D()`：频域/矩阵形状和数据布局辅助。
- `solveG()`、`solveZ()`、`solveU()`：完成一轮辅助变量和惩罚系数更新。
- `weightStrategy()`：计算边缘感知权重。
- `optIllumMap()`：组织迭代、收敛和变量更新顺序。
- `enhance()`：安全归一化、逐通道增强与结果合并。

### Unet / NCNN

- `main()` 中依次核对：读图、补边、resize、归一化、HWC→CHW、NCNN 输入、模型加载、推理、`argmax`、去 padding、可视化。

### LSTR / ONNX Runtime

- 构造阶段：环境、session、输入输出节点和模型资源。
- 预处理：图像 tensor 与全零 `mask_tensor`。
- `Run()`：推理执行和输出 tensor 读取。
- 后处理：`pred_logits` 筛选、`pred_curves` 解析、`log_space.bin` 采样、绿色区域构造。

## 手写追踪题

| 模块 | 闭卷任务 | 必须写出的边界/依赖 |
|---|---|---|
| Qt | 点击开始按钮后，写出信号、槽、`QProcess`、输出回调和显示更新的先后顺序 | 推理不能阻塞 UI 事件循环 |
| LIME | 用 2×2 像素和 2×2 `T` 手算一个通道的 `I/T` | `T` 接近 0 时会发生什么 |
| ADMM | 画出 `T_hat/W → solveT → T → solveG → G → solveZ → Z → solveU → u` | 哪些是旧值，哪一步依赖本轮新值 |
| NEON | 追踪 4 个 float 从 `vld1q_f32` 到 `vmaxq_f32` 再到 `vst1q_f32` | 图像宽度不是 4 的倍数时如何处理 |
| OpenMP | 把 4×4 图像划成四块，标记可并行和不能并行的循环 | 写区域是否重叠，累加是否需要归约 |
| Unet | 写出一张 HWC 图片到最终 mask 的完整链 | 补边区域为什么必须去掉 |
| LSTR | 从 `pred_logits` 选有效车道，再用 `pred_curves + log_space` 生成点 | 模型输出和绿色显示区域分别由谁产生 |

## 破坏测试：先预测，再改代码

| 故意破坏 | 预期症状 | 要定位的根因 |
|---|---|---|
| 在 UI 主线程直接跑推理 | 窗口卡顿、按钮失去响应 | 事件循环被重任务占用 |
| 删除 `normalize(T, 0.2, 1)` | 过亮、噪声放大、除零风险 | 光照图缺少安全下界 |
| 把 `solveG()` 放到 `solveT()` 前面 | ADMM 迭代语义改变、可能不收敛 | 更新顺序和变量依赖被破坏 |
| 去掉 HWC→CHW | 模型能运行但结果异常 | 输入布局与模型约定不一致 |
| 不去 padding | 边缘出现伪车道或尺寸错位 | 预处理几何变换没有逆变换 |
| 对有写冲突的循环直接加 OpenMP | 结果不稳定、每次不同 | 数据竞争或归约错误 |
| 忽略 NEON 尾部元素 | 某些宽度越界或最后几列错误 | 向量宽度与实际长度不匹配 |
| 把绿色区域说成 LSTR 模型输出 | 面试解释错位 | 后处理生成的显示结果被误归因 |
