本页为Linux视觉感知处理系统的开发环境搭建提供完整指南。文档涵盖从零开始的环境配置、各模块的编译步骤以及运行验证方法，帮助开发者快速搭建开发环境并成功运行系统。

## 系统模块概览

本系统由四个核心模块组成，每个模块采用不同的技术栈和构建系统：

| 模块 | 功能 | 技术栈 | 构建系统 | 主要依赖 |
|------|------|--------|----------|----------|
| **Qt上位机程序** | 用户界面、摄像头采集、结果展示 | C++11, Qt 5.12.8 | qmake | OpenCV, Qt Multimedia/Charts |
| **LIME算法** | 低照度图像增强 | C++14, OpenCV | CMake | OpenCV |
| **Unet NCNN** | 语义分割车道线检测 | C++11, NCNN | CMake | OpenCV, NCNN, OpenMP |
| **LSTR ONNX** | 参数化车道线检测 | C++11, ONNX Runtime | CMake | OpenCV, ONNX Runtime, OpenMP |

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L1-L83)

## 开发环境要求

### 硬件平台
本项目主要面向**ARM aarch64架构**的Linux开发板（如树莓派、Jetson系列）。`.pro`文件中链接了`/usr/lib/aarch64-linux-gnu/`路径的库文件，表明目标平台为64位ARM处理器。

Sources: [1102demo3.pro](1102demo3.pro#L15-L22)

### 操作系统
推荐使用**Ubuntu 18.04/20.04 LTS**（aarch64版本），系统需要预装基本的开发工具链。

### 基础依赖
```bash
sudo apt-get update
sudo apt-get install build-essential cmake git wget
sudo apt-get install autoconf automake libtool curl make g++ unzip
sudo apt-get install ffmpeg  # 视频帧采集所需
```

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L25-L30)

## 依赖库安装指南

### OpenCV 4.7.0 安装

```bash
# 下载OpenCV 4.7.0源码
wget -O opencv-4.7.0.zip https://github.com/opencv/opencv/archive/4.7.0.zip
unzip opencv-4.7.0.zip
cd opencv-4.7.0

# 配置与编译
./configure
make -j8  # 根据CPU核心数调整并行编译线程数

# 安装到系统目录
sudo make install
```

安装完成后，OpenCV库文件位于`/usr/local/lib`，头文件位于`/usr/local/include/opencv4`。Qt项目的`.pro`文件中已配置这些路径。

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L3-L12)

### Qt 5.12.8 安装

本项目使用Qt 5.12.8，并需要额外的QtCharts和QtMultimedia模块：

```bash
# 从Qt官网下载qt-everywhere-src-5.12.8源码包
wget https://download.qt.io/official_releases/qt/5.12/5.12.8/single/qt-everywhere-src-5.12.8.tar.xz
tar xf qt-everywhere-src-5.12.8.tar.xz
cd qt-everywhere-src-5.12.8

# 配置（根据实际需求调整选项）
./configure -prefix /opt/qt5.12.8 -skip qtdoc -skip qtdeclarative

# 编译与安装
make -j8
sudo make install
```

**重要提示**：需要单独编译qtchart和qtmultimedia子模块，确保Qt项目的多媒体和图表功能正常。

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L39-L46)

### NCNN 框架安装

NCNN是腾讯开源的高性能神经网络推理框架：

```bash
# 安装protobuf依赖
git clone https://github.com/google/protobuf.git
cd protobuf
git submodule update --init --recursive
./autogen.sh
./configure
make
make check
sudo make install
sudo ldconfig

# 编译NCNN
git clone https://github.com/Tencent/ncnn
cd ncnn
mkdir -p build && cd build
cmake ..
make -j4
```

Unet_NCNN模块中已包含预编译的NCNN库（位于`lib`目录），如无特殊需求可直接使用。

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L14-L30)

### ONNX Runtime 安装

LSTR模型使用ONNX格式，需要ONNX Runtime推理引擎：

```bash
# 克隆ONNX Runtime（务必使用--recursive）
git clone --recursive https://github.com/Microsoft/onnxruntime
cd onnxruntime

# 编译（ARM平台可能需要额外配置）
./build.sh --config RelWithDebInfo --build_wheel --update --build
```

**注意**：直接下载预编译包可能导致运行时缺少依赖文件，建议从源码编译。

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L32-L38)

## 各模块编译与运行

### 1. LIME算法编译（基础版与优化版）

LIME算法有两个版本：基础版和NEON+OpenMP优化版。两者编译方式相同：

```bash
# 进入LIME算法目录（以优化版为例）
cd "图像预处理（加速前+加速后）/Lime_NEON+OpenMP"

# 创建构建目录并编译
mkdir -p build && cd build
cmake ..
make

# 运行测试
./lime
```

**优化版特有依赖**：`Lime_NEON+OpenMP`版本需要OpenMP支持，CMakeLists.txt中已配置自动检测。

测试图片位于`data`子目录，可在源代码中修改图片路径进行测试。

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L56-L62), [Lime_NEON+OpenMP/CMakeLists.txt](projects/linux视觉感知项目/源码/图像预处理（加速前+加速后）/Lime_NEON+OpenMP/CMakeLists.txt#L1-L41)

### 2. Unet NCNN 语义分割模块

```bash
cd "卷积神经网络/卷积神经网络/Unet_NCNN"
mkdir -p build && cd build
cmake ..
make

# 运行推理（参数为输入图片路径）
./unet_ncnn ../images/0.jpg
```

模型文件位于`models`目录，测试图片位于`images`目录。

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L63-L68), [Unet_NCNN/CMakeLists.txt](projects/linux视觉感知项目/源码/卷积神经网络/卷积神经网络/Unet_NCNN/CMakeLists.txt#L1-L30)

### 3. LSTR ONNX 车道线检测模块

```bash
cd "卷积神经网络/卷积神经网络/LSTR_ONNX"
mkdir -p build && cd build
cmake ..
make

# 运行检测
./LSTR
```

ONNX模型文件`lstr_360x640.onnx`和日志空间文件`log_space.bin`位于项目根目录。

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L69-L74), [LSTR_ONNX/CMakeLists.txt](projects/linux视觉感知项目/源码/卷积神经网络/卷积神经网络/LSTR_ONNX/CMakeLists.txt#L1-L20)

### 4. Qt上位机程序编译

Qt项目使用qmake构建系统：

```bash
cd "上位机程序/Lane_Detection"

# 确保Qt环境变量已设置（假设安装在/opt/qt5.12.8）
export PATH=/opt/qt5.12.8/bin:$PATH
export LD_LIBRARY_PATH=/opt/qt5.12.8/lib:$LD_LIBRARY_PATH

# 生成Makefile并编译
qmake 1102demo3.pro
make

# 运行上位机程序
./camera_test
```

**关键配置说明**：
- 摄像头采集的图片保存在`frames`目录
- 本地视频文件位于`LSTR/videos`目录
- 识别结果保存在`LSTR/result`目录
- 背景图片资源位于`resources`目录

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L48-L55), [1102demo3.pro](1102demo3.pro#L1-L41)

## 文件路径配置说明

由于开发板环境限制，项目中部分路径使用**绝对路径**。实际部署时需要根据项目位置调整：

| 路径用途 | 相对路径示例 | 说明 |
|----------|--------------|------|
| 摄像头采集图片 | `上位机程序/Lane_Detection/frames/` | 采集的帧图片存储位置 |
| 本地视频文件 | `上位机程序/Lane_Detection/LSTR/videos/` | 测试用视频文件 |
| 识别结果输出 | `上位机程序/Lane_Detection/LSTR/result/` | 车道线检测结果图片 |
| 界面背景图片 | `上位机程序/Lane_Detection/resources/` | Qt界面资源文件 |
| LSTR推理命令 | `cd /项目路径/LSTR/build && ./LSTR ../videos/frames/` | QProcess调用的终端命令 |

**重要**：修改`mainwindow.cpp`中的`yolop_process`函数可更新LSTR调用命令。

Sources: [readme.txt](projects/linux视觉感知项目/源码/readme.txt#L76-L83)

## 环境验证与故障排查

### 验证步骤
1. **OpenCV验证**：运行LIME程序，检查是否成功处理测试图片
2. **NCNN验证**：运行Unet程序，查看语义分割结果
3. **ONNX验证**：运行LSTR程序，检查车道线检测输出
4. **Qt验证**：启动上位机程序，测试摄像头采集和界面显示

### 常见问题
**问题1：OpenCV库找不到**
```bash
# 检查库路径
ls /usr/local/lib/libopencv_*
# 更新动态链接库缓存
sudo ldconfig
```

**问题2：Qt程序编译失败**
```bash
# 检查Qt版本和模块
qmake --version
qmake -query QT_INSTALL_MODULES
```

**问题3：NCNN/ONNX Runtime链接错误**
确保`lib`目录下的`.so`文件存在，或重新编译依赖库。
