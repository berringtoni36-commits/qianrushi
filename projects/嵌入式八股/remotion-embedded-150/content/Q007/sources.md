# Q007 来源与事实核对

## 原始题目

来源：`2. 嵌入式高频八股150题/01 C-C++基础（1-25题）.md`，第 7 题“sizeof 和 strlen 有什么区别？”。原题主结论是：`sizeof` 关注内存大小，`strlen` 关注字符串长度；二进制数据中可能含 `0x00`，不能用 `strlen`。

## 核对结论

- `sizeof` 是 C/C++ 运算符，结果表示对象或类型的大小，单位是字节；数组对象的结果包含数组全部元素和字符数组字面量自动附带的结尾 `\\0`。
- `strlen` 是 `<string.h>` / `<cstring>` 提供的字符串函数，从首字符开始扫描，遇到第一个 `\\0` 停止，返回不包含 `\\0` 的字符数。
- `char str[] = "abc"` 时，`sizeof(str) == 4`，`strlen(str) == 3`。
- `char *p = str` 后，`sizeof(p)` 是指针变量大小，具体宽度由目标平台和 ABI 决定；`strlen(p)` 仍然是 3，因为它仍指向同一串以 `\\0` 结尾的字符。
- 二进制缓冲区中的 `0x00` 可以是有效数据，`strlen` 会提前停止；传输、DMA 和协议帧应使用显式长度、硬件计数器或协议字段。
- “`sizeof` 一定在编译期完成”需要补充边界：普通对象和类型通常可在翻译期确定；C 的变长数组（VLA）场景可以在运行时计算。

## 原题表述修正

原题把“空结构体”作为 C/C++ 的直接对比。ISO C 不定义空结构体这一标准语法，部分编译器把它作为扩展；C++ 的空类对象必须具有非零大小以保证不同对象可区分。视频只保留这个追问的边界提醒，不把 GCC 扩展当成 ISO C 结论。
