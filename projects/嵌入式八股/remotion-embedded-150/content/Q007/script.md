# Q007 脚本：sizeof 和 strlen 有什么区别？

## 核心目标

把“对象占用多少字节”和“C 字符串有多少字符”彻底分开，并能在 `char[]`、`char *`、二进制缓冲区和 DMA 接收场景中选对长度来源。

## 屏幕叙事

1. 主动回忆：sizeof 和 strlen 分别在数什么？
2. 答案地图：sizeof 看字节数，strlen 看 `\\0` 之前的字符数，底层缓冲区使用显式长度。
3. 字符串轨迹：`char str[] = "abc"` 时，`sizeof(str) = 4`，`strlen(str) = 3`；交给 `char *p` 后，`strlen(p)` 仍为 3，但 `sizeof(p)` 只得到指针大小。
4. 二进制轨迹：`{0x41, 0x00, 0x42}` 的真实长度是 3，`strlen` 会在 `0x00` 处停止，只得到 1；发送时传 `payload + len`。
5. 易错边界：函数参数数组退化、VLA 的运行时 `sizeof`、ISO C 不定义空结构体、C++ 空类对象的非零大小。
6. 面试追问：计算时机、数组和指针结果、二进制边界、DMA/协议长度。
7. 最终复述：用四句把主规则和嵌入式边界说完整。

## 标准复述

`sizeof` 是运算符，关注对象或类型占用的字节数；`strlen` 是运行时字符串函数，扫描到 `\\0` 为止且不把 `\\0` 计入长度。`char str[] = "abc"` 时，`sizeof(str)` 是 4、`strlen(str)` 是 3；`char *p = str` 后，`sizeof(p)` 是指针变量大小，`strlen(p)` 仍为 3。二进制、DMA 和协议帧不能用 `strlen` 猜长度，应使用显式长度或硬件计数器。
