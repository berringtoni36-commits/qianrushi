# Q004 来源与事实核对

## 原始题目

来源：`2. 嵌入式高频八股150题/01 C-C++基础（1-25题）.md`，第 4 题“extern 关键字有什么作用？”。原题核心表述是：`extern` 声明变量或函数定义在别的文件中，是多文件工程共享符号的关键手段。

## 核对结论

- `int g_count = 0;` 是定义，创建实体并分配存储；`extern int g_count;` 是声明，告诉编译器符号存在，通常不分配该实体的存储。
- 一个工程应由合适的源文件提供定义，头文件提供声明，其他编译单元通过包含头文件使用。
- 编译器分别处理源文件生成目标文件，链接器负责把跨文件的同名符号匹配起来。
- 头文件直接放置带初始化的全局定义，容易在多重包含或多个编译单元下造成重复定义。
- 只有声明没有任何定义会在链接阶段产生未定义符号；多个源文件提供同名定义会产生重复定义诊断。
- C++ 普通函数可能发生 name mangling；`extern "C"` 要求 C++ 使用 C 的链接约定，常用于 C/C++ 混合接口。
- `extern` 解决的是符号可见性和链接协作，不会自动降低全局变量带来的模块耦合和隐藏修改路径。
