# Q005：指针和数组有什么区别？

| 核心目标 | 让学习者分清数组空间、指针地址、数组退化和函数参数边界 |

## 核心回答

数组是一段连续内存块，指针是保存地址的变量。数组名在很多表达式中会调整为指向首元素的指针，但数组本体并没有因此变成可改指向的指针变量。

回答时从四个角度展开：

1. 本质：数组拥有一段连续空间，指针变量只保存一个地址。
2. `sizeof`：数组得到整体大小，指针得到指针变量大小，具体宽度看目标平台。
3. 赋值：数组不能整体赋值，指针可以改指向。
4. 函数参数：`int buf[]` 会按 `int *` 处理，函数需要额外接收长度。
