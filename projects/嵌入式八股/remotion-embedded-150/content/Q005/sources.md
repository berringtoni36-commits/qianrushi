# Q005 来源与事实核对

## 原始题目

来源：`2. 嵌入式高频八股150题/01 C-C++基础（1-25题）.md`，第 5 题“指针和数组有什么区别？”。原题核心表述是：数组是一段连续内存块，指针是存储地址的变量，数组名会在很多表达式中退化为指针，但本质不同。

## 核对结论

- 数组拥有自己的连续存储空间，指针变量本身保存一个地址。
- `sizeof(arr)` 在数组仍保持数组类型的作用域内得到整体大小；`sizeof(p)` 得到指针变量大小，宽度由目标平台决定。
- 数组不能整体赋值，指针可以改指向其他地址。
- C 函数参数中的数组声明会调整为指针参数，函数体内不能从该参数本身推回调用方原数组长度。
- `int *p[5]` 是包含 5 个 `int*` 的指针数组；`int (*p)[5]` 是指向含 5 个 `int` 的数组的指针。
- 嵌入式缓冲区接口应将指针与长度一起传递，不能依赖函数参数里的 `sizeof` 猜长度。

视频使用 `sizeof(int *)` 表达指针大小，避免把 32 位或 64 位的单一数值误说成所有目标平台都相同。
