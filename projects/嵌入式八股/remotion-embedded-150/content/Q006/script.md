# Q006：指针和引用有什么区别？

## 元数据

| 项目 | 内容 |
|---|---|
| 题号 | Q006 |
| 难度 | 中等，6/10 |
| 目标时长 | 240 秒以内 |
| 视觉模板 | pointer-reference-state |
| 核心目标 | 通过同一组 `a`、`b`、`p`、`r` 状态分清空值、改指向、初始化和不可换绑 |

## 核心回答

指针是存地址的变量，可以为空，也可以改为指向另一个对象；引用是对象的别名，定义时必须绑定有效对象，绑定后不能通过普通赋值更换绑定。多数实现会用类似指针的机制表示引用，但实现方式不能替代语言层面的语义。
