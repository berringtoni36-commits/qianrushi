# Q011 事实核对与来源记录

## 原题来源

- 原始笔记：2. 嵌入式高频八股150题/01 C-C++基础（1-25题）.md
- 对应章节：第 11 题：delete 和 delete[] 有什么区别？
- 原文核心句：delete 释放单个对象，delete[] 释放数组，混用是未定义行为。

## 语义核对

1. delete-expression 用于释放由单对象 new-expression 创建的对象；delete[]-expression 用于释放由数组 new-expression 创建的数组。
2. 对类对象执行删除表达式时，先结束对象生命周期，再释放相应存储；数组删除需要对数组元素逐个执行析构，元素按逆序结束生命周期。
3. 将 new 与 delete[]、new[] 与 delete、new 与 free 等接口混用属于未定义行为。视频使用标准术语，不承诺“只析构第一个”或“一定马上崩溃”。
4. 删除一个对象不会自动修改调用方的指针变量。删除后指针若继续保存旧地址就是悬空指针；将其置为 nullptr 是常用的防误用措施。
5. 对空指针执行 delete 不产生释放动作，因此 delete nullptr 本身安全。
6. 嵌入式建议是工程约束而非 C++ 语言保证：静态分配、固定块池、启动阶段一次分配、失败处理和清晰所有权有助于控制碎片、容量和时延。
