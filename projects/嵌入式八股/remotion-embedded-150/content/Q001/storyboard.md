# Q001 分镜

| 场景 | 时间 | 主要任务 | 画面状态 |
|---|---:|---|---|
| Opening | 0:00-0:20 | 主动回忆与路线预览 | 先显示问题，再揭示三个入口 |
| Roles | 0:20-0:34 | 建立答案地图 | 生命周期、可见性、共享依次出现 |
| Local static | 0:34-1:24 | 追踪确定性代码执行 | `cnt` 从 0 初始化，三次调用输出 1/2/3 |
| File scope | 1:24-1:56 | 解释内部链接 | `module.c` 可访问，`main.c` 的 `extern` 链接失败 |
| C++ member | 1:56-2:32 | 解释类成员共享 | 两个对象出现，`Device::count` 只有一份并变为 2 |
| Memory | 2:32-3:16 | 建立内存布局 | 栈、堆、`.bss`、`.data`、`.text` 分层高亮 |
| Follow-ups | 3:16-4:12 | 练习四个面试追问 | 每题先回答 5 秒，再显示标准说法 |
| Final recall | 4:12-4:41 | 无提示复述 | 四个问题逐一揭晓，右侧保留一句话总纲 |

## 关键帧验收点

- `0`：开头问题与倒计时可读，路线卡处于待揭示状态。
- `7 秒`：路线卡出现，三个判断入口完整。
- 局部 static：第一次调用后的 `cnt = 1`、第二次 `2`、第三次 `3` 都必须与高亮行和输出文本同步。
- 文件作用域：内部链接墙出现后，`main.c` 的错误提示才出现。
- C++ 成员：第二个对象出现时共享计数变为 `2`，连接线指向同一份类存储。
- 内存布局：`.data` 与 `.bss` 对比时，两张代码卡片同时可见且内容不互相矛盾。
- 每个追问：倒计时归零后才显示答案，答案淡入不晚于本题剩余时长。
- 结尾：每个问题在答案出现前保持可独立复述，最后一帧仍能读出三大作用总结。
