# Q001：static 关键字有哪些作用？

## 核心回答

`static` 在这道题里要从三个入口回答：

1. 修饰局部变量：作用域仍在函数内，但生命周期延长到整个程序运行期，且只初始化一次。
2. 修饰文件作用域的全局变量或函数：形成内部链接，只在当前编译单元可见。
3. C++ 修饰类数据成员：数据属于类本身，所有对象共享同一份。

## 屏幕复习顺序

主动回忆 → 三作用地图 → 局部变量代码执行 → 文件内部链接 → C++ 静态成员共享 → 栈/堆/.data/.bss → 面试追问 → 四句复述。

## 必须保持一致的事实

- 局部 `static` 不在栈上，属于静态存储区。
- `static int x = 10;` 归入 `.data`，`static int y;` 归入 `.bss`，具体布局仍由目标平台和工具链实现细节决定。
- “只文件可见”对应的是内部链接属性，不是把普通局部变量的块作用域搬到了文件作用域。
- 静态数据成员的类内定义规则与 C++ 标准版本有关：传统写法通常需要类外定义；C++17 起可以使用 `inline static` 类内定义。
- `static` 本身不提供线程安全；并发访问仍需要合适的同步或原子操作。
