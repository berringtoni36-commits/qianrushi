# Q001 来源与事实核对

## 原始题目

来源：`2. 嵌入式高频八股150题/01 C-C++基础（1-25题）.md`，第 1 题“static 关键字有哪些作用？”。

## 核对结论

- C 语言中，文件作用域的 `static` 对象具有内部链接；块作用域的 `static` 对象具有静态存储期，块作用域不变。
- C++ 中，静态数据成员属于类而不是某个对象；其定义和类内初始化规则取决于声明形式与语言标准版本。
- 已初始化和未初始化的静态存储对象在常见 ELF/嵌入式工具链中通常分别映射到 `.data` 与 `.bss`，但具体段名和启动细节属于实现/工具链约定，因此视频用“常见映射”表达，不把它说成所有平台唯一布局。
- `static` 不等价于线程安全。并发读写仍需锁、临界区或原子操作。

## 参考依据

- ISO C 术语：storage duration、linkage、scope 的定义，以及 `static` 对象声明规则。
- ISO C++ 术语：static data member、inline variable 和类外定义规则。
- GNU GCC/ld 常见 ELF 启动布局：`.data` 的初值装载与 `.bss` 的清零属于工具链和启动代码的常见实现。

可复核的公开规范页面：C++ 当前工作草案的声明/定义规则与静态存储期章节，以及 GNU `ld` 的 linker-script 示例。正式脚本只使用这些规范能稳定支持的表述，不把某一台机器的段地址当成语言保证。

本视频不展示依赖具体芯片型号的地址数值，只展示稳定的语言语义和常见嵌入式内存分区关系。
