# Q002 来源与事实核对

## 原始题目

来源：`2. 嵌入式高频八股150题/01 C-C++基础（1-25题）.md`，第 2 题“const 关键字有什么作用？”。原题的核心表述是：`const` 表达只读语义，约束数据不被修改，让接口意图更清晰，并由编译器辅助检查。

## 核对结论

- `const int MAX = 100` 通过该名字不能修改对象。
- `const int *p` 允许改变指针指向，但不能通过 `p` 修改所指内容。
- `int * const p` 不允许改变指针指向，但可以通过 `p` 修改所指内容。
- `const int * const p` 同时约束指针和所指内容。
- `const` 函数参数表达被调用函数不会通过该参数修改调用方数据；它是接口约束，不是运行时锁。
- 只读数组在常见嵌入式工具链中可能被放入 Flash 或其他只读区，但实际段布局由目标平台、编译器、链接脚本和启动代码决定，视频没有把它说成语言保证。
- `const` 与 `#define` 的差异按类型检查、作用域、调试信息和预处理阶段文本替换来表达。
- 如果对象本来就是 `const`，通过 `const_cast` 得到的非 const 指针后再写入该对象属于未定义行为；视频用 `undefined.cpp` 明确这是 C++ 示例。
- `const` 不提供原子性、互斥、内存序或线程安全保证。
