大家好，我是蟹老板~

ADC 看上去只是一个基础的模块，实则牵扯模拟电路、数字时序、噪声抑制、PCB布局一整套知识体系。

高端仪器、通信设备、工业采集、消费电子的精度上限，很多时候并不靠主控芯片算力，而是靠ADC的性能兜底。

## 一、ADC 基础

### 1.1 ADC的定义与基本作用

ADC 是 Analog-to-Digital Converter 的缩写，中文叫模数转换器。

说白了就是一个翻译官，负责把连续变化的模拟电压或电流转换成数字系统能够处理的离散码值。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-001.jpg]]

### 1.2 模拟信号与数字信号的区别

模拟信号在时间和幅度上通常都是连续的。数字信号则是完全离散的状态。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-002.jpg]]

### 1.3 ADC在电子系统中的位置

ADC在模拟电路和数字电路的交界位置。这个位置既是系统信号的入口，也是模拟噪声和数字干扰的交汇点。传感器采集到的物理量（温度、压力、光强）先变成电压或电流，然后进入ADC。ADC输出的数字码再交给MCU或DSP做处理、运算、存储、传输。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-003.jpg]]

## 二、ADC 工作原理

### 2.1 ADC转换的完整流程

一次 ADC 转换会经历采样、保持、量化和编码阶段。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-004.jpg]]

### 2.2 信号采样与采样保持

采样就是个“定时拍照”的动作。ADC内部有个采样开关，每隔固定时间闭合一下，让输入信号给保持电容充个电。电容上的电压就是当前时刻的信号值。

但有个问题——电容充完电之后，得把电压稳住让量化电路慢慢处理。这就轮到保持电路出场了。保持电路本质上就是个高阻抗缓冲器，把电容上的电压“锁住”，不让它随着时间漏掉。采样和保持通常做成一个整体，叫采样保持电路（S&H）或跟踪保持电路（T&H）。

采样保持电路有个坑爹的参数叫**孔径时间**——从采样指令发出到采样开关真正断开之间的延迟。如果输入信号变化很快，这个延迟会导致采到的电压和理论值有偏差。孔径时间越短越好，高速ADC对这个参数极其敏感。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-005.jpg]]

### 2.3 模拟信号量化

量化就是把连续幅度映射到有限等级。

一个 3 位 ADC 只有 8 个等级。输入信号无论多精细，最终都只能落到其中一个码值上。位数越高，可用等级越多，量化台阶越细。

理想量化步长可以表示为：

```
LSB = VFS / 2^N
```

有些数据手册或具体传输函数会使用 `2^N - 1` 作为码值跨度。工程中不要死背一个分母，得看厂商如何定义端点和满量程码。

以 12 位、3.3V 满量程为例，理想 LSB 约为：

```
LSB = 3.3V / 4096    ≈ 0.8057mV
```

这并不代表 ADC 能准确测出 0.8057mV 的变化。

它只代表理想码宽。真实可分辨的小信号还会受到噪声、INL、DNL、参考源和前端电路影响。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-006.jpg]]

### 2.4 数字编码与输出格式

量化完成后，ADC 会输出对应数字码。

单极性 ADC 常用自然二进制。0V 对应全 0，接近满量程时对应全 1。双极性 ADC 更常使用偏移二进制或二进制补码。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-007.jpg]]

以一个 16 位双极性 ADC 为例，输入范围为 −10V 到 +10V。

偏移二进制下，−10V 附近对应 `0x0000`，0V 附近对应 `0x8000`，+10V 附近对应 `0xFFFF`。

二进制补码下，0V 对应 `0x0000`，正满量程接近 `0x7FFF`，负满量程对应 `0x8000`。

编码格式读错以后，波形常常会出现莫名其妙的直流偏移或半幅翻转。

### 2.5 量化误差的产生原因

模拟输入只能被映射到最近的量化等级，因此输出码对应的电压和真实输入之间存在误差。

理想 ADC 的量化误差通常位于负半个 LSB 到正半个 LSB 之间。

```
-0.5 LSB ≤ Eq ≤ +0.5 LSB
```

在满足一定条件时，量化误差可以近似看成与信号不相关的均匀白噪声。理想 N 位 ADC 对满幅正弦波的信噪比近似为：

```
SNRideal ≈ 6.02N + 1.76 dB
```

12 位 ADC 的理论 SNR 大约是 74dB，16 位约为 98dB。

现实中通常达不到。热噪声、时钟抖动、非线性和参考电压噪声都会继续往里添堵。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-008.jpg]]

### 2.6 奈奎斯特采样定理

奈奎斯特采样定理说，若要无失真地恢复一个带限信号，采样频率必须大于信号最高频率的两倍。

```
Fs > 2 × Fmax
```

这条定理经常被简化成采样率是信号频率两倍就够了。理论上没错，工程上却不太够用。

假设你要采集一个 10kHz 正弦波，采样率用 20.1kSPS。数学上满足条件，但每周期只有略多于两个点，波形看着十分寒酸。滤波器的过渡带也几乎没地方放。

实际系统通常会留出更大余量。波形显示、瞬态分析和数字滤波都需要更多采样点。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-009.jpg]]

### 2.7 混叠现象与抗混叠滤波

当输入中存在超过 `Fs/2` 的频率分量时，这些高频信号会折叠到低频区域，形成混叠。

比如采样率为 100kSPS，输入中存在 70kHz 干扰。它可能在数字域里表现成 30kHz 分量。

```
Falias = |Fin - k × Fs|
```

最麻烦的地方在于，一旦混叠发生，后续数字滤波通常无法分辨这个 30kHz 到底是真实信号，还是 70kHz 折叠下来的冒牌货。

所以 ADC 前面需要模拟抗混叠滤波器。

滤波器不用把奈奎斯特频率之外的东西彻底消灭，但要把它们压低到系统允许的水平。分辨率越高，阻带抑制往往越难做。16 位系统想要维持 90dB 以上动态性能，随手放个一阶 RC 通常是不够的。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-010.jpg]]

## 三、ADC的主要架构分类

### 3.1 Flash ADC（并行比较型）

Flash ADC 是速度派。

一个 N 位 Flash ADC 理论上需要 `2^N - 1` 个比较器。所有比较器同时比较输入电压和不同阈值，编码器再把温度计码转换成二进制码。

8 位 Flash ADC 需要 255 个比较器。10 位就要 1023 个。位数继续增加，面积、功耗和输入电容都会迅速膨胀。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-011.jpg]]

### 3.2 SAR ADC（逐次逼近型）

SAR ADC 是工程项目里的常客。

它内部通常包含采样保持电路、比较器、DAC 和逐次逼近寄存器。转换过程类似二分查找。

先试最高位。内部 DAC 生成半量程电压，比较输入比它高还是低。然后保留或清除最高位，再试下一位。N 位 ADC 通常需要 N 次左右比较。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-012.jpg]]

### 3.3 Sigma-Delta ADC（Σ-Δ型）

Sigma-Delta ADC 喜欢用速度换精度。

它通过很高的内部采样率对信号进行过采样，再利用调制器把量化噪声推向高频，数字滤波器负责滤除高频噪声并降低输出数据率。

核心关键词有三个：过采样、噪声整形、数字抽取滤波。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-013.jpg]]

### 3.4 Pipeline ADC（流水线型）

Pipeline ADC 把高位转换拆分成多个级。

每一级完成少量位的判断，再把残差信号放大后传给下一级。多个采样点可以同时处于不同流水级中，因此吞吐率很高。

它常见于几十 MSPS 到数 GSPS 的中高速、高分辨率采集系统，例如通信基站、医学成像、频谱仪和高速数据采集卡。

Pipeline ADC 的分辨率通常高于纯 Flash，速度又明显高于传统 SAR。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-014.jpg]]

### 3.5 Dual-Slope ADC（双积分型）

双积分 ADC 是慢工出细活的代表。

它先对未知输入电压积分一段固定时间，再用已知参考电压反向积分，直到积分器输出回到零。反向积分所需时间与输入电压成比例。

这种架构对电阻、电容的绝对值不太敏感，而且能够很好地抑制周期性干扰。数字万用表尤其喜欢它。

假设积分时间选成 20ms，就能覆盖一个完整的 50Hz 工频周期。正负工频噪声在积分中会相互抵消。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-015.jpg]]

### 3.6 Folding ADC（折叠型）

Folding ADC 通过折叠电路把大范围输入映射成重复的小范围波形，再用较少的比较器判断细分位置，同时结合粗量化结果恢复完整码值。

它可以看成 Flash 思路的一种优化。

## 四、ADC的静态性能指标

静态指标决定ADC的直流采集精度，也就是稳态下的测量准确度。

### 4.1 分辨率与位数

分辨率表示 ADC 能够输出多少个离散码。

N 位 ADC 理论上有 `2^N` 个码值。12 位有 4096 个，16 位有 65536 个，24 位有 16777216 个。

位数高，只能说明量化台阶细。它不直接等于准确度。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-019.jpg]]

### 4.2 满量程输入范围

满量程输入范围定义 ADC 可以正常转换的输入电压区间。

单极性输入可能是 0V 至 2.5V、0V 至 5V。差分 ADC 可能允许 `±Vref` 的差分输入，同时要求每个输入引脚处于规定共模范围内。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-020.jpg]]

### 4.3 最低有效位LSB

LSB 是 Least Significant Bit，也就是最低有效位。

它对应理想传输曲线中最小的码宽。

```
LSB = 输入范围 / 2^N
```

±10V、16 位 ADC 的总跨度为 20V，理想 LSB 约为 305.18μV。

```
LSB = 20V / 65536    ≈ 305.18μV
```

别把 LSB 和最小可测信号画等号。

当输入噪声达到 5LSB 时，一个 LSB 的变化会被淹没。通过平均可能恢复部分分辨能力，但前提是噪声特性允许，而且系统响应时间能接受。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-021.jpg]]

### 4.4 偏置误差

偏置误差描述实际传输曲线相对于理想曲线的整体平移。

理想情况下，输入位于零点或规定的首个码跳变位置时，输出应落在预期码值。实际 ADC 可能偏高或偏低。

偏置误差通常可以通过系统校准消除。

```
float adc_remove_offset(uint16_t raw, float offset_code){    return (float)raw - offset_code;}
```

问题在于偏置会随温度、时间和电源变化。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-022.jpg]]

### 4.5 增益误差

去除偏置误差后，实际满量程斜率和理想斜率之间的差异叫增益误差。

比如理想输入 2.5V 应输出满量程码，实际到 2.48V 就满了，或者输入达到 2.5V 仍差几十个码，这都可能包含增益误差。

两点校准通常能同时修正偏置和增益。

```
typedef struct{    float gain;    float offset;} adc_calibration_t;float adc_apply_calibration(float raw_code,                            const adc_calibration_t *cal){    return raw_code * cal->gain + cal->offset;}
```

校准能修正直线的平移和斜率，却修不好弯曲。INL 仍然在那里。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-023.jpg]]

### 4.6 微分非线性DNL

DNL 描述每一个实际码宽相对于理想 1LSB 码宽的偏差。

```
DNL[k] = 实际码宽[k] / 理想LSB - 1
```

某个码的 DNL 为 +0.5LSB，意味着它比理想码宽宽了 50%。DNL 为 −0.8LSB，说明码宽只剩理想值的 20%。

当 DNL 小于或等于 −1LSB 时，可能出现失码。输入慢慢增加，某个数字码却永远不会出现。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-024.jpg]]

### 4.7 积分非线性INL

INL 描述实际码跳变位置相对于理想直线的最大偏差。

它反映整个 ADC 传输曲线到底有多弯。

INL 的定义可能基于端点拟合，也可能基于最佳拟合直线。不同定义算出来的数字并不完全相同，比较器件时必须确认条件。

偏置和增益可以通过两点校准处理。INL 属于更深层的非线性，普通线性校准拿它没什么办法。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-025.jpg]]

### 4.8 单调性与失码

单调性表示输入持续增大时，ADC 输出码不会反向减小。

对于闭环控制系统，单调性非常重要。输入明明上升，输出码却突然下降，控制器可能做出错误动作。

DNL 大于 −1LSB 通常可以保证无失码。很多高精度 DAC 或 ADC 会明确给出单调性保证。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-026.jpg]]

### 4.9 绝对精度与相对精度

绝对精度关注测量值与真实物理值之间的误差。

它包含 ADC 偏置、增益、INL、参考源误差、前端电阻误差、运放误差和温漂等整条链路问题。

相对精度更关注去除偏置和增益之后，传输曲线与理想直线的接近程度，常与 INL 联系在一起。

做系统指标时，不能只抄 ADC 数据手册里的精度。

传感器 0.5% 误差、基准源 20ppm/℃、电阻网络 0.1%、运放失调 50μV，这些都会进入总误差预算。ADC 自己再漂亮，也架不住队友集体摆烂。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-027.jpg]]

## 五、ADC的动态性能指标

### 5.1 采样率与转换速率

采样率表示 ADC 每秒获取多少个样本，常用单位有 SPS、kSPS、MSPS 和 GSPS。

有些器件的采样率和输出数据率并不相同。Sigma-Delta ADC 内部调制器可能以几 MHz 工作，经过数字抽取滤波后，最终每秒只输出几百或几千个结果。

多通道扫描 ADC 还要考虑总吞吐率如何分给各通道。

一个 1MSPS 的 ADC 扫描 10 个通道，不代表每个通道都有 1MSPS。理想均分也只有 100kSPS，还没算通道切换后的建立时间。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-028.jpg]]

### 5.2 信噪比SNR

SNR 是信号功率与噪声功率之比。

计算时通常排除直流分量和谐波，只统计噪声底。

```
SNR = 10 × log10(Psignal / Pnoise)
```

也可以用电压有效值表示。

```
SNR = 20 × log10(Vsignal_rms / Vnoise_rms)
```

输入幅度会影响 SNR。测试通常使用接近满量程但不削顶的正弦波，例如 −0.5dBFS 或 −1dBFS。

数据手册写着 90dB，你用 −20dBFS 输入去测，结果自然不会一样。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-029.jpg]]

### 5.3 信号噪声失真比SINAD

SINAD 把噪声和谐波失真都算进分母。

```
SINAD = 10 × log10(    Psignal / (Pnoise + Pdistortion))
```

SNR 只关心噪声，SINAD 更接近整个转换结果的综合质量。

如果 ADC 噪声很低，但二次谐波和三次谐波很大，SNR 可能仍然好看，SINAD 会把问题揭出来。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-030.jpg]]

### 5.4 有效位数ENOB

ENOB 通过 SINAD 换算 ADC 实际等效位数。

```
ENOB = (SINAD - 1.76) / 6.02
```

一个标称 16 位 ADC，若实测 SINAD 为 86dB，那么 ENOB 大约为 14 位。

```
ENOB = (86 - 1.76) / 6.02     ≈ 13.99 bit
```

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-031.jpg]]

### 5.5 总谐波失真THD

THD 表示各次谐波功率之和与基波功率的比值。

```
THD = 10 × log10(    (P2 + P3 + ... + Pn) / P1)
```

用 dB 表示时通常是负数。−100dB 比 −70dB 好。

ADC 的 THD 会受到输入频率、输入幅度、驱动器线性度、电源和时钟影响。高频大幅度输入最容易把问题打出来。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-032.jpg]]

### 5.6 无杂散动态范围SFDR

SFDR 是基波幅度与最大杂散分量之间的差值。

最大杂散可能是谐波，也可能是时钟耦合、电源纹波、交调产物或其他非谐波杂散。

通信系统尤其关心 SFDR。一个小信号附近如果站着很高的杂散，接收机就可能分不清目标和假信号。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-033.jpg]]

### 5.7 动态范围DR

动态范围描述最大不失真信号与噪声底之间的范围。

不同厂商可能采用略有差异的测试定义。音频 ADC 常用 A 计权动态范围，高精度 ADC 可能给出短接输入时的噪声和有效分辨率。

动态范围越大，系统同时处理强弱信号的能力越强。

不过动态范围高并不自动代表直流准确度高。一个音频 ADC 的动态范围可以超过 110dB，它未必适合拿来测精密直流电压。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-034.jpg]]

### 5.8 模拟输入带宽

模拟输入带宽描述 ADC 前端能够接收多高频率的信号。

它可能远高于奈奎斯特频率。

例如一个 100MSPS ADC 的第一奈奎斯特区只有 0MHz 至 50MHz，但模拟输入带宽可能达到数百 MHz。这样就可以进行欠采样，把更高频带直接折叠到目标数字频段。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-035.jpg]]

### 5.9 孔径延迟与孔径抖动

孔径延迟表示采样时钟有效边沿与实际采样时刻之间的固定延迟。

固定延迟通常可以在系统中补偿。真正麻烦的是孔径抖动，也就是采样时刻的不确定性。

输入信号变化越快，时间误差引起的电压误差越大。

由抖动限制的理论 SNR 可以估算为：

```
SNRjitter = -20 × log10(    2π × Fin × σt)
```

`Fin` 是输入频率，`σt` 是总 RMS 时间抖动。

当输入频率为 100MHz、目标 SNR 为 74dB 时，可容许总抖动已经进入亚皮秒级。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-036.jpg]]

### 5.10 建立时间与转换延迟

建立时间表示输入发生变化后，ADC 或前端电路达到目标精度所需的时间。

多路复用系统尤其要关心通道切换建立。高阻传感器直接接 SAR ADC，前后通道电压差又很大，前几次采样可能都不可信。

转换延迟表示采样发生后，数字结果需要多久才可用。

SAR ADC 的延迟通常较低。Pipeline ADC 有固定流水延迟。Sigma-Delta ADC 受数字滤波影响，延迟可能达到多个输出周期。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-037.jpg]]

## 六、ADC中的噪声与误差

### 6.1 量化噪声

理想量化误差的均方根值约为：

```
Vq_rms = LSB / √12
```

它构成理想 ADC 的基础噪声。

增加位数能够降低量化噪声。过采样和数字滤波也可以把宽带量化噪声分散到更宽频带，再保留目标带宽内的一部分。

可问题来了。真实系统里，量化噪声往往不是最大噪声源。热噪声、参考源和前端运放可能早就把它盖住了。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-038.jpg]]

### 6.2 热噪声

电阻会产生热噪声，其均方根电压与电阻、温度和带宽有关。

```
Vn = √(4kTRB)
```

`k` 是玻尔兹曼常数，`T` 是绝对温度，`R` 是电阻，`B` 是噪声带宽。

阻值越大，带宽越宽，热噪声越高。

设计精密 ADC 前端时，不能只看运放电压噪声。反馈电阻、滤波电阻和传感器源阻抗都会贡献噪声。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-039.jpg]]

### 6.3 参考电压噪声

ADC 的输出结果本质上是输入电压与参考电压的比值。

参考电压一抖，转换比例就跟着抖。

当输入接近满量程时，参考源噪声的影响尤其明显。低输入电平时，它的绝对影响相对小一些。

高分辨率系统通常会给参考源单独做滤波和去耦。某些 SAR ADC 的参考引脚会在转换期间吸取脉冲电流，还需要低阻抗缓冲和较大的储能电容。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-040.jpg]]

### 6.4 时钟抖动误差

时钟抖动对低频慢信号影响可能不大，对高频输入却十分致命。

系统总抖动通常包括时钟源抖动、时钟缓冲器抖动、PCB 耦合和 ADC 内部孔径抖动。

它们可按均方根方式合成。

```
σtotal = √(    σclock² +    σbuffer² +    σadc²)
```

高速采集板上，时钟线旁边跑一组高速数据，或者时钟电源和开关电源共用一段脏回路，都可能让频谱底噪抬高。

这种问题软件滤波很难救。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-041.jpg]]

### 6.5 电源噪声与地噪声

ADC 经常同时拥有模拟电源和数字电源。

数字接口切换会产生瞬态电流。若电源阻抗或地回路处理不好，这些电流会耦合进模拟核心。

电源纹波还可能在频谱上形成固定杂散。例如 500kHz 开关电源及其谐波，常常能在 FFT 里露头。

去耦电容不能只看总容量。小封装、低寄生和靠近引脚更重要。

一个 100nF 电容离电源脚 5cm，效果可能还不如一个 10nF 电容贴在脚边。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-042.jpg]]

### 6.6 输入驱动误差

SAR ADC 的开关电容输入会给驱动器带来动态负载。

运放输出可能在采样瞬间产生回冲，随后需要重新建立。若运放带宽不足、压摆率不够或驱动容性负载不稳定，转换结果就会出问题。

常见处理方式是在运放和 ADC 之间加入小电阻，再在 ADC 输入端放置电容，形成电荷桶和低通网络。

```
运放输出 ── Riso ── ADC输入                    │                    C                    │                   GND
```

R 太小，运放可能不稳定。R 太大，建立时间又不够。C 太小，不能有效吸收采样回冲。C 太大，驱动负担增加。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-043.jpg]]

### 6.7 PCB布局引入的误差

原理图正确不代表 PCB 正确。

高速数字线穿过模拟输入下方，开关电源电感贴着参考源，ADC 时钟绕板半圈，去耦电容回地又细又长，这些都会制造问题。

高阻节点还容易受到漏电和污染影响。潮湿、助焊剂残留和板面灰尘都可能让皮安级输入开始漂。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-044.jpg]]

### 6.8 过采样与平均滤波降噪

对白噪声占主导的系统，多次独立采样求平均可以降低随机噪声。

平均 M 次后，噪声标准差理论上下降到原来的：

```
1 / √M
```

每增加约 4 倍采样次数，理想情况下可以获得约 1 位额外分辨能力。

```
额外位数 ≈ 0.5 × log2(M)
```

下面是一段简单的滑动平均代码。

```
#define AVG_SIZE 32typedef struct{    uint32_t sum;    uint16_t buffer[AVG_SIZE];    uint16_t index;} moving_average_t;uint16_t moving_average_update(moving_average_t *f,                               uint16_t sample){    f->sum -= f->buffer[f->index];    f->buffer[f->index] = sample;    f->sum += sample;    f->index++;    if (f->index >= AVG_SIZE)    {        f->index = 0;    }    return (uint16_t)(f->sum / AVG_SIZE);}
```

平均不能消除固定偏置、增益误差和低频漂移。周期性干扰如果刚好和采样同步，平均后甚至可能纹丝不动。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-045.jpg]]

## 七、ADC参考电压与输入接口

### 7.1 参考电压的作用

参考电压决定 ADC 的转换标尺。

同一个输入电压，在不同参考电压下会得到不同码值。参考电压越低，理想 LSB 越小，但输入范围也会缩小。

参考源的误差通常会直接变成系统增益误差。

假设 2.500V 参考源实际为 2.505V，误差约为 0.2%。如果系统没有校准，ADC 计算出来的电压也会带着类似比例误差。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-046.jpg]]

### 7.2 内部参考与外部参考

内部参考使用方便，器件少，启动流程简单。很多 MCU ADC 和中低速独立 ADC 都带内部基准。

外部参考在精度、温漂、噪声或驱动能力上通常更灵活。高精度系统常使用专用基准芯片，再配合缓冲器和滤波网络。

内部参考不一定差，外部参考也不一定自动变好。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-047.jpg]]

### 7.3 单端输入与差分输入

单端输入测量输入引脚相对于地的电压。

它简单，适合低成本和共地系统，但更容易受到地电位差和共模干扰影响。

差分输入测量两个输入引脚之间的电压差。

```
Vdiff = Vin+ - Vin-
```

差分方式能抑制同时耦合到两根线上的共模噪声。很多高性能 ADC 使用全差分输入，以获得更好的动态范围和偶次失真抑制。

差分不代表两个引脚可以随便飘。每个引脚都必须满足规定的绝对输入范围和共模范围。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-048.jpg]]

### 7.4 单极性输入与双极性输入

单极性输入只能处理一个方向的电压，例如 0V 至 5V。

双极性输入可以处理正负信号，例如 −10V 至 +10V 或 ±Vref。

部分 ADC 原生支持真正的负电压输入。更多低压 ADC 实际上要求输入引脚始终位于电源轨之间，只是通过差分和共模偏置表达正负差分量。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-049.jpg]]

### 7.5 ADC输入阻抗特性

有些 ADC 输入表现为近似电阻。另一些，尤其 SAR ADC，呈现开关电容特性。

数据手册可能给出静态输入阻抗、输入漏电流和等效采样电容。只看一个“1MΩ”常常不够，因为动态采样瞬间的电流远大于静态平均值。

高阻传感器需要缓冲。电阻分压网络也不能一味追求大阻值省电。

当分压输出阻抗太高时，ADC 采样电容不能及时充电，结果会偏低或依赖前一个通道。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-050.jpg]]

### 7.6 输入驱动电路设计

输入驱动电路通常承担缓冲、放大、衰减、偏置和滤波任务。

设计时需要检查下面这些能力。

运放输入共模范围是否覆盖传感器输出。输出摆幅能否到达 ADC 要求。带宽和压摆率是否足够。输出噪声是否低。建立时间是否满足 N 位精度。驱动 ADC 电容负载时是否稳定。

一个粗略的建立要求可以写成：

```
误差比例 < 1 / 2^(N+1)
```

16 位半 LSB 建立要求约为满量程的百万分之七点六。看着就让人头大，对吧。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-051.jpg]]

### 7.7 运算放大器与ADC的匹配

选运放不能只看增益带宽积。

低频精密 ADC 更关心失调、漂移、1/f 噪声和输入偏置电流。高速 ADC 更关心宽带噪声、失真、压摆率和稳定时间。差分 ADC 可能需要专用全差分放大器。

运放输出范围也要留余量。所谓轨到轨输出，通常也不代表在任何负载下都能完美贴住电源轨。

最稳妥的做法是看 ADC 厂商推荐驱动电路，再结合自己的输入频率、幅度和采样率做仿真与实测。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-052.jpg]]

## 八、ADC数据输出与数字接口

### 8.1 并行数据接口

并行接口一次可以传输多个数据位。

12 位或 16 位 ADC 可能直接提供对应数量的数据线，再搭配时钟、数据有效和溢出信号。

它延迟低、吞吐率高，逻辑也直观。缺点是引脚多、布线多、同步切换噪声大。

高速并行接口需要关注走线等长、建立保持时间和 FPGA 输入时序。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-053.jpg]]

### 8.2 SPI串行接口

SPI 是中低速 ADC 最常见的数字接口之一。

典型信号包括 SCLK、CS、MISO，有些器件还需要 MOSI 配置寄存器，并提供 DRDY 或 BUSY 引脚。

读取代码如下：

```
uint16_t adc_spi_read(void){    uint8_t rx[2];    adc_cs_low();    rx[0] = spi_transfer(0x00);    rx[1] = spi_transfer(0x00);    adc_cs_high();    return ((uint16_t)rx[0] << 8) | rx[1];}
```

真实器件可能还有状态位、符号扩展、CRC 和流水数据。别只看“SPI 兼容”四个字就以为协议都一样。

### 8.3 I²C接口

I²C 只需要时钟和数据两根线，还能挂多个设备，适合低速传感器和监控 ADC。

它的缺点是速度有限，协议开销相对大，对上拉电阻和总线电容敏感。

很多电源监控芯片和低速多通道 ADC 使用 I²C。采样率只有几百 SPS 时，I²C 已经够用。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-054.jpg]]

### 8.4 LVDS高速接口

LVDS 使用低摆幅差分信号，适合高速并行或串行数据传输。

它相比单端 CMOS 接口具有更低的电磁辐射和更好的高速信号完整性。高速 ADC 常输出多组 LVDS 数据和随路时钟。

接收端需要处理位对齐、字对齐和通道偏斜。FPGA 中通常会使用专用 DDR 输入和延迟校准资源。

LVDS 线对要控制差分阻抗，保持紧耦合，避免跨越参考平面分割。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-055.jpg]]

### 8.5 JESD204高速串行接口

JESD204 是高速 ADC 和 DAC 常见的串行接口标准。

它使用高速 SerDes 通道传输数据，能够显著减少引脚数量。多个转换器还可以实现确定性延迟和同步采样。

JESD204B 和 JESD204C 在高速通信、雷达和多通道采集系统中非常常见。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-056.jpg]]

### 8.6 原码、偏移二进制与二进制补码

自然二进制适合单极性输入。

偏移二进制常用于双极性 ADC。中点码代表零输入。

二进制补码则便于数字系统直接进行有符号运算。

将 16 位偏移二进制转换为补码，最简单的方法通常是翻转最高位。

```
int16_t offset_binary_to_twos_complement(uint16_t code){    return (int16_t)(code ^ 0x8000U);}
```

若 ADC 实际只有 14 位却封装在 16 位数据中，还要确认数据是左对齐还是右对齐。这个细节漏掉，数值能差四倍。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-057.jpg]]

### 8.7 ADC数据读取时序

读取 ADC 不能只关心 SPI 最高频率。

还需要看片选建立时间、时钟极性、采样边沿、数据有效延迟、BUSY 信号和转换启动方式。

某些 SAR ADC 在 CNV 上升沿采样，转换期间可读取上一次结果。某些器件要求转换期间保持数字接口安静。Sigma-Delta ADC 则常用 DRDY 下降沿表示新数据可读。

高速系统建议使用定时器触发、DMA 和硬件同步，少让 CPU 手动抖 GPIO。

```
void adc_dma_callback(const uint16_t *buffer, size_t count){    for (size_t i = 0; i < count; ++i)    {        process_sample(buffer[i]);    }}
```

采样时间轴一旦交给中断延迟和操作系统调度，抖动就会变得很难控制。

## 十、ADC应用电路设计

### 10.1 ADC前端信号调理

前端信号调理要把传感器输出转换到 ADC 最舒服的范围。

小信号需要放大，大信号需要衰减，双极性信号可能需要偏置，强干扰环境还需要保护和滤波。

假设传感器输出 0V 至 100mV，ADC 输入范围为 0V 至 2.5V，可以设计约 25 倍增益。

传感器误差、运放输出摆幅和瞬态都需要余量，实际可能选 20 倍或 22 倍。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-061.jpg]]

### 10.2 抗混叠滤波器设计

抗混叠滤波器需要在目标带宽内保持足够平坦，在奈奎斯特频率之外提供所需衰减。

简单系统可以使用一阶 RC。

```
Fc = 1 / (2πRC)
```

更高要求可能需要二阶或多阶有源滤波器。

滤波器截止频率不能机械地设成 `Fs/2`。在截止点处，一阶滤波器只有约 3dB 衰减，根本谈不上抗混叠。

应根据目标信号带宽、过渡带和阻带抑制反推阶数。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-062.jpg]]

### 10.3 参考电压电路设计

参考源要远离高噪声数字区域和开关节点。

参考引脚附近通常需要按数据手册放置去耦电容。电容类型、容量和 ESR 可能影响稳定性。

对于动态参考负载，可以使用参考缓冲器。缓冲器要具备低噪声、低失调和驱动大电容的稳定性。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-063.jpg]]

### 10.4 电源去耦与滤波

每个电源引脚附近都应放置局部去耦。

常见组合是 100nF 高频陶瓷电容配合 1μF 至 10μF 的储能电容，具体值按数据手册调整。

电容到引脚和地的路径应短而宽。高频去耦回路面积越小越好。

高性能 ADC 常用低噪声 LDO 供电。开关电源可以提供前级效率，再通过 LDO 或滤波网络做二次净化。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-064.jpg]]

### 10.5 模拟地与数字地处理

模拟地和数字地不是简单切开就完事。

盲目分割地平面，可能迫使高速数字回流绕远路，反而制造更严重的辐射和串扰。

更实用的思路是保持连续低阻抗地平面，通过器件布局控制电流路径。模拟区和数字区在空间上分开，让数字回流不要穿过敏感模拟区域。

ADC 芯片的 AGND 和 DGND 如何连接，建议优先参考厂商布局建议。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-065.jpg]]

### 10.6 PCB布局与布线原则

ADC、驱动器、参考源和去耦器件应尽量靠近。

差分输入保持对称和紧耦合。参考线避开高速时钟。敏感输入不要与数字总线长距离平行。

采样时钟走线要短，保持连续参考平面，减少过孔和支路。高速接口需要控制阻抗和终端。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-066.jpg]]

### 10.7 时钟电路设计

高速 ADC 时钟需要低相位噪声和低抖动。

时钟源、PLL、分频器和缓冲器都会贡献抖动。差分时钟通常具有更好的共模抑制和边沿完整性。

时钟幅度、共模电压和终端方式要符合 ADC 输入要求。

低速精密系统也别完全忽略时钟。数字时钟边沿如果正好耦合到模拟输入，仍会产生固定干扰。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-067.jpg]]

### 10.8 多通道ADC设计注意事项

多通道系统要考虑通道间串扰、切换建立和同步性。

内部多路复用 ADC 往往共享一个采样电容。高阻输入通道之间切换时，残余电荷会造成误差。

可以延长采样时间、降低源阻抗、加入缓冲器或丢弃切换后的第一次结果。

需要严格同步的多通道系统，最好使用同时采样 ADC，而不是高速轮询单个 ADC。软件补时间差能救一部分，但对相位测量和保护系统不一定够。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-068.jpg]]

## 十一、ADC性能测试方法

### 11.1 直流静态性能测试

静态测试需要稳定、低噪声、可精确调节的直流源。

通过缓慢扫描输入电压，记录 ADC 输出码，可以测量偏置、增益和传输曲线。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-069.jpg]]

### 11.2 DNL与INL测试

DNL 和 INL 可以通过精密斜坡法或直方图法测试。

斜坡法用高度线性的慢斜坡覆盖整个输入范围，测量每个码跳变位置。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-070.jpg]]

### 11.3 正弦波动态测试

动态测试通常输入低失真正弦波，采集一段连续样本后做频谱分析。

输入幅度一般接近满量程，但留出避免削顶的余量。

信号源失真必须优于 ADC，否则测到的是信号源。必要时使用高品质带通滤波器清理信号源谐波。

采样时钟和信号源还要考虑相干采样关系。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-071.jpg]]

### 11.4 FFT频谱分析

FFT 能把时域采样数据转换到频域。

采样点数越多，频率分辨率越细。

```
Δf = Fs / NFFT
```

非相干采样会导致频谱泄漏，需要使用窗函数。常见窗包括 Hann、Blackman-Harris 和 Flat Top。

下面是一段简化的 Python 分析代码。

```
import numpy as npdef analyze_adc(samples: np.ndarray, fs: float):    samples = np.asarray(samples, dtype=np.float64)    samples = samples - np.mean(samples)    window = np.blackman(len(samples))    coherent_gain = np.sum(window) / len(window)    spectrum = np.fft.rfft(samples * window)    magnitude = np.abs(spectrum) / (        len(samples) * coherent_gain    )    frequency = np.fft.rfftfreq(        len(samples),        d=1.0 / fs    )    magnitude_db = 20.0 * np.log10(        np.maximum(magnitude, 1e-20)    )    return frequency, magnitude_db
```

真正计算 SNR、THD 和 SINAD 时，还要处理窗函数等效噪声带宽、基波裙带、谐波落点和直流分量。不是找最大峰值减一下那么简单。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-072.jpg]]

### 11.5 SNR、SINAD与THD计算

先找出基波频点及其附近能量，再识别二次、三次等谐波。

噪声功率通常排除直流、基波和谐波。SINAD 则保留噪声和失真。

```
SNR   = 10log10(Pfund / Pnoise)THD   = 10log10(Pharmonics / Pfund)SINAD = 10log10(    Pfund / (Pnoise + Pharmonics))
```

谐波超过奈奎斯特频率后会折叠回来，计算频点时要做频率映射。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-073.jpg]]

### 11.6 ENOB测试方法

ENOB 通常由实测 SINAD 计算。

```
ENOB = (SINAD - 1.76) / 6.02
```

测试报告必须同时注明输入频率、采样率、输入幅度、采样点数、窗函数和电源条件。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-074.jpg]]

### 11.7 直方图测试法

固定直流输入时采集大量样本，可以观察噪声分布和码值稳定性。

若输入位于某个码中心，理想低噪声系统可能只出现少数几个码。根据标准差可以估算输入等效噪声和无噪声分辨率。

正弦直方图还能用于估算 DNL。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-075.jpg]]

## 十二、ADC常见问题与优化方法

### 12.1 采样数据跳动

数据跳动可能来自真实输入噪声、参考源、电源、地噪声、量化噪声或软件读取错误。

可以先把输入短接到稳定电压，观察码值分布。再分别替换外部信号源、参考源和电源。

若最低几位随机跳动但分布稳定，这可能是正常噪声。若跳动具有固定周期，就要检查开关电源、工频和数字任务周期。

![[assets/embedded-interview/图解 ADC：工作原理、架构分类与核心性能指标/img-076.jpg]]

### 12.2 输出码值偏差

固定偏差通常与偏置、参考电压、前端增益和地电位差有关。

先用高精度万用表直接测 ADC 引脚电压和参考电压，不要只相信上游节点。

再核对编码格式、位对齐和转换公式。

```
float adc_code_to_voltage(uint16_t code,                          float vref){    return ((float)code * vref) / 65535.0f;}
```

对于 16 位单极性理想端点映射，上式常用。但具体芯片到底除以 65535 还是 65536，仍要看传输函数定义。

### 12.3 满量程无法达到

满量程达不到，可能是运放输出摆幅不够，也可能是 ADC 输入本来就不允许贴近电源轨。

参考电压误差、分压比例、保护电阻压降和内部 PGA 配置也会影响范围。检查Vref实际值是否等于标称值。如果Vref偏低，输出码当然到不了顶。

有些 ADC 把过量程区域预留给内部数字滤波和校准，因此标称输入范围与理想满码位置并非完全一致。

### 12.4 采样波形失真

采样出来的波形和原始信号形状不一样——可能是混叠、可能是驱动运放带宽不够、可能是采样保持建立时间不够。

先检查采样率是否满足奈奎斯特。再检查抗混叠滤波器是否正常工作。最后用示波器看ADC输入引脚——采样瞬间电压有没有被拉偏。

### 12.5 高频输入性能下降

高频下SNR/ENOB急剧下降。大概率是孔径抖动或驱动运放带宽不够。孔径抖动在高频下影响最大。换低抖动的时钟源。驱动运放的带宽要远高于信号频率。

### 12.6 多通道串扰

一个通道的信号窜到另一个通道。PCB走线耦合、地阻抗耦合、芯片内部耦合都有可能。模拟信号线之间要拉开距离、加地线隔离。地平面要完整。多通道ADC的模拟输入引脚之间加小电容可以抑制串扰。

### 12.7 ADC噪声过大的排查方法

系统性排查噪声：

1. 1. 短路ADC输入——测输出噪声
2. 2. 换低噪声电源——排除电源噪声
3. 3. 换低噪声参考——排除参考噪声
4. 4. 换低抖动时钟——排除时钟抖动
5. 5. 换低噪声前级运放——排除驱动噪声

一步步排除，找到噪声源头。

### 12.8 提升ADC测量精度的方法

硬件层面：低噪声电源、低噪声参考、低抖动时钟、好PCB布局、好抗混叠滤波。

软件层面：过采样+平均滤波、数字校准（偏置/增益校正）、数字滤波。
